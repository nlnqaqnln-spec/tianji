# 十年大运与小流年推算

## R — 原文 (Reading)

> 「命好不如限好：十年大运（看三方四正）为主，小流年（只要看本宫和对宫）为辅。
> 未来十年无大运，大限在前十年。未来一年无大运，大限在前一年。」
>
> — 倪海厦《天纪》· 原则 p22（大运流年），源文件 04-紫微斗数笔记 / 05-紫微详解

补充原文要点（同条 p22）：十年大运由命宫起点，阳男阴女顺行 / 阴男阳女逆行，
按纳音局数（水2 / 木3 / 金4 / 土5 / 火6）定几岁起运，每十年走一宫；
小流年排法：从戌宫起子，按「戌→未→辰→丑」顺序，男顺女逆；
单星独守十年大运且无吉星化解 → 大凶/代表死限。

## I — 方法论骨架 (Interpretation)

本卡解决的是「时间」维度：命盘讲的是「你天生是什么样」，大运流年讲的是「哪十年、哪一年
会发生什么」。判断分两层，权重不同：

- **十年大运（主）**——先定起点与走向：以命宫为起点，阳男阴女顺行、阴男阳女逆行，
  按纳音局数（水2木3金4土5火6）定「几岁起运」，之后每十年换一宫。
  每步大运**看三方四正**（不是只看本宫），得到这十年的整体趋势。
- **小流年（辅）**——每年一宫，**只看本宫与对宫**即可，作为「当年插曲」补充细节。

两条关键判断法：

1. **命好不如限好**：命盘再好，若走到坏限也难顺；反之命平但限好也能起来。
   典型如「十年大运财星旺 + 当年小流年撞天空地劫」→ 十年赚钱、当年却耗财。
2. **「无大运」回推法**：未来十年看不到大运 → 大限实际在前十年；
   未来一年无大运 → 大限在前一年。这是断「关键限」落在哪里的回推技巧。

- **四离四绝日**：春分/秋分/夏至/冬至前一日为四离日，立春/立夏/立秋/立冬前一日为四绝日——此八天大凶，诸事不宜（笔记第6页/详解第23页）
- **小儿夭折判断**：小儿无天真表现、善知人意主夭，有大人像主夭，主七岁前的运（笔记第6页）
- **百岁流年图**（详解第57-58页）：面部各位置按年龄流转——1-7岁耳/天轮，8-14岁额，15-24岁眉眼间，25-30岁鼻，31-34岁人中，35-40岁口唇，41-50岁眼周额角，51-60岁口唇线，61-70岁下巴，71-80岁腮颐，81-100岁地阁。可参证tianji-mianxiang卡定位具体年龄的面相吉凶

## A1 — 应用示例 (Application Example)

### 书中的应用（reported_case，来源 05-紫微详解.md）

**案例 c02 — 民国54年十月二十八辰时男命**
- **问题**: 大限走到哪里、那十年吉凶如何。
- **方法的使用**: ① 定大限宫位：大限 23–32 落在夫妻宫；② 用大运看三方四正，
  夫妻宫为廉贞+贪狼落陷（半空折翅格）→ 该步大运「无大运」，婚姻大凶；
  ③ 接续看 33–42 → 未来十年无大运。
- **结论**: 23–32 婚姻大凶、无子女、双方战斗不止；33–42 亦无大运。
- **结果（原书交代）**: 流年 32 岁妻子自杀（落在 23–32 这步大限内）。

**案例 c01 — 民国50年三月初五戌时女命（贪狼武官格）**
- **方法的使用**: 看大限 34–43 所在宫 → 福德宫显示太阳化忌。
- **结论**: 34–43 这步大限「丈夫有劫」（太阳代表父/夫/子，太阳化忌 → 夫有灾）。
- **结果（原书交代）**: 记为寡宿星应验的夫劫；化解为厕所不在房中间、厨房不在西北角，可缓死夫之劫。

**案例 c11 — 紫微在辰命在辰男命（15 例之 6）**
- **方法的使用**: 33 岁求测 → 查小限在子，落化忌 → 断「诸事不顺、心想不成」。
- **说明**: 三例展示「大限定十年趋势 + 小限/流年定当年插曲」的双层用法，均为原书命例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 问「我这十年大运怎么样」「大限走到哪了」「今年运势如何」
2. 关心某一具体年份（如「明年」「今年」）的吉凶起伏
3. 命盘整体平顺，但想知道「哪段时候最难/最好」
4. 已看完全局，要把结论落到「什么时候发生」

### 语言信号（中英双写）

- 中文：「大运怎么样」「大限」「流年运势」「今年运势」「什么时候最顺/最差」「十年运势」
- 英文：`decade luck` / `dayun / daxian` / `annual fortune` / `this year`s luck` / `ten-year cycle`

### 与相邻 skill 的区分（初稿）

- 与 `tianji-ziwei-pandu`（三方四正判读）的区别：判读卡定「天生格局与大方向」，
  本卡管「时间落点」——判读流程的时间维度分支。
- 与 `tianji-sihua`（四化）的区别：本卡用四化落宫作为大限/流年的吉凶依据，但不负责解释四化本身。
- 与 `tianji-qise-shengsi`（气色时限）的区别：气色卡给「节气级」短期窗口，
  本卡给「十年 + 当年」两级中长期框架，时间尺度不同。

## E — 可执行步骤 (Execution)

**输入契约**
- 必需：命宫所在宫位；性别 + 生年阴阳（定顺逆：阳男阴女顺 / 阴男阳女逆）；
  纳音局数（水2/木3/金4/土5/火6）；求测当前年龄。
- 缺失局数或顺逆信息时 → 先排盘确定，**不得静默猜值**。
- 适用条件：已完成排盘且已知命宫位置。

1. **定起运与顺逆** — 据局数定「几岁起运」，据性别+生年阴阳定顺逆。
   - 完成标准：明确写出「自 X 岁起运，每十年一宫，顺/逆行」。
2. **排各步大限** — 自命宫起逐宫推出每步大限（如 3–12、13–22 …）。
   - 完成标准：列出求测年龄所处的大限宫位，并标出相邻前后各一步。
3. **断十年趋势** — 对所落大限宫**取三方四正**合看星曜与四化。
   - 完成标准：给出该十年的整体趋势（吉/凶/平）+ 主导星曜/四化。
   - 判停点：若「未来十年无大运」→ 按原文回推至前十年，明确标注「大限在前十年」。
4. **断当年插曲** — 排小流年（戌起子、戌未辰丑、男顺女逆），**只看本宫与对宫**。
   - 完成标准：给出当年吉凶，并说明相较十年趋势是加剧还是缓和。
5. **合判** — 套「命好不如限好」原则，说明「十年趋势 × 当年」的组合结论（如十年赚、当年耗）。
   - 完成标准：输出双层结论，避免只看一年或以十年概一年。

**输出契约**
- 结构化输出：`起运岁数/顺逆 → 各步大限宫 → 当前大限（含三方四正）→ 当年小流年（本宫+对宫）→ 双层合判`。
- 时间单位约定：大限以「岁–岁」区间表示，流年以年份/岁数表示；小流年排法照原文「戌起子、戌未辰丑、男顺女逆」。
- 完成标准：每一步都能回溯 p22 原文；给出的年份区间可自行复算核对。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 尚未排盘、不知命宫位置与局数时。
- 只问星性/格局/六亲（分别走 shisi-zhuxing / ziwei-geju / liuqin-gong）。
- 要求精确到日的预测——本卡只给「十年+当年」两级，不给日级；但四离四绝日（8天大凶日）可作为当日避凶参考

### 失败模式（原书警告）
- **只看小流年、不看大运**：原文明确「命好不如限好」，本卡以十年为主、当年为辅，颠倒主次会误判。
- 把「单星独守大运、无吉星化解」轻描淡写——原文判为大凶/死限级。
- 忘记「无大运回推法」，把关键限错置到未来，漏掉真正的前一个限。

### 作者盲点 / 时代局限
- 岁数分界、闰月等历法细节影响起运岁数，原文排盘规则（润月按下月、晚子时算前一日）须先落实，
  否则大限整体位移。
- 「死限」类判语属命理推演，不可作事实性预言；涉及健康/生死须转就医，涉及安全须求助专业。

### 邻近方法论
- `tianji-ziwei-pandu`（主流程）；`tianji-sihua`（大限/流年的判定依据）；
  `tianji-qise-shengsi`（更短的时间窗口）；`tianji-ziwei-paipan`（起运岁数前置）。
