# 观人术·识小人

## R — 原文 (Reading)

> 「君子（人才）难进易出；庸才易进易出；小人易进难出。」
>
> — 04-紫微斗数笔记 第2页（单元 u19）

> 「语无伦次，未言先笑→心生毒计；眼珠闪动→心术不好；四白眼→横死，杀人；三角眼→心存诡计。」
> 「讲话时左边眉毛直纹向上，两面三刀相，看不到的小人相。」
>
> — 04-紫微斗数笔记 第12页；01-天机道【天纪/09归纳总结】相术总结（xz28/xz53）（单元 u19）

## I — 方法论骨架 (Interpretation)

这套方法把「识人」拆成两层：**先分类型，再核对特征**。

**第一层：进-出二维分型（功能性判据）**
- **君子/人才**：难进易出——初始门槛高、不易亲近或说服，但一旦建立关系就稳定可靠，离开时干脆坦然。相书对应「言简刚中」（说话扼要有条理）。
- **庸才**：易进易出——容易亲近也容易离开，随波逐流，无独特价值。
- **小人**：易进难出——容易接近、极难摆脱。
- **关键界定**：原文的「小人」**不是道德标签，而是功能性定义——「能害到你的人就是小人」**。最危险的小人往往是亲近之人（亲情/爱情/友情让你自愿被其影响）。

**第二层：特征清单（逐项核对）**
- 神态类：未言先笑/无事而笑、语无伦次、眼珠闪动频繁、说话换脸。
- 眼形类：四白眼（横死/杀人）、三角眼（心存诡计）、三白眼、目带凶光（坐过牢）。
- 骨相类：命门（鬓角下方）讲话时有突骨跳动＝反骨/必背叛。
- 眉相类：讲话时左眉直纹向上穿印堂（两面三刀）、乱眉、断眉。
- 口舌类：唇不蔽齿+舌舔唇口（善巫之人）、吹火嘴+左眉竖纹（尖酸刻薄）、鸟啄（可共患难不可共享乐）。
- 声音类：声不洪亮、阴柔如女子（声、神、气最重要）。

一句话：**先用「难进易出 / 易进难出」给对方定档，再用量化特征清单逐项核对**，特征命中越多、风险越高。核心用途是**帮自己保持距离**，而非给他人定罪。

## A1 — 书中的应用 (Past Application)

> 以下为原书案例/反例（ce11、ce12、ce14 等），原书多以规则与警示形式给出，命主后续原文多未说明。

### 案例 1: 未言先笑 + 命门反骨（两面三刀）
- **来源**: ce14（05-紫微详解 第12页；04-紫微斗数笔记 第9页）
- **问题**: 对方「未言先笑」、眼珠闪动，讲话时观察命门处有骨骼突起跳动
- **方法的使用**: 未言先笑+眼珠闪动＝心生毒计；命门突骨＝反骨；左眉直纹向上＝两面三刀相 → 逐项核对命中
- **结论**: 属「易进难出」的奴才型小人——表面最亲近、背后捅刀子；「此人必反，汉奸」
- **结果**: 原文以警示规则给出，未说明具体命主后续。

### 案例 2: 四白眼 + 浓眉（横死/杀人相）
- **来源**: ce11（05-紫微详解 第12页）
- **问题**: 黑眼珠四周大量露白（四白眼），且眉毛很浓
- **方法的使用**: 按特征清单判四白眼＝横死杀人，浓眉＝小人相（天府星对应面相）；原文明确「不要跟三角眼人、四白眼人、浓眉人来往」
- **结论**: 交往有性命之危，属最高风险档
- **结果**: 原书以警示语给出，未附命主后续。

### 案例 3: 三角眼（心存诡计）
- **来源**: ce12（05-紫微详解 第12页）
- **问题**: 眼形呈明显三角（上宽下尖）
- **方法的使用**: 判「心存诡计」；若叠加未言先笑/眼珠闪动即典型小人
- **结论**: 共事必被算计，「易进难出」，难得摆脱
- **结果**: 原书规则形式，命主后续未说明。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **新结识一个人，直觉不对**：「这人见面就笑，感觉怪怪的」「第一印象不舒服」
2. **合伙/共事前评估**：「要不要跟这个人合作/借钱给他」
3. **想摆脱某人**：「有个人缠着我很难甩掉」
4. **识人方法学习**：「怎么看出一个人可信不可信」「面相上怎么分辨小人」
5. **团队/管理参考**：「怎么判断下属/同事是人才还是混子」

### 语言信号

- "识人 / 看人 / 观人术 / 识小人 / 两面三刀 / 反骨 / 未言先笑 / 三角眼 / 四白眼"
- "这个人靠不靠得住 / 能不能深交 / 要不要合作"
- "how to read people", "is this person trustworthy", "spot a bad actor / backstabber", "trustworthiness"

### 与相邻 skill 的区分（初稿）

- 与 `tianji-mianxiang`（面相十二宫）的区别：本卡是**行为+神态+骨相的小人特征清单，服务于交往风险评估**；面相十二宫是**宫位对应的静态吉凶体系**（哪一宫代表什么、纹路主什么命），核心是算命而非识人。
- 与 `tianji-xingti-fenlei`（三停/五形人）的区别：本卡看**特征与行为信号**（动态、局部）；形体分类看**整体先天层次**。
- 与命理类（紫微主星判人）的区别：本卡为**无工具即时观察**；紫微判人需命盘。

- 与 `tianji-mianxiang`：本卡专攻**人际风险识别**（小人特征清单）；十二宫是通用宫位诊断。问"这人靠不靠谱"→ 本卡。

## E — 可执行步骤 (Execution)

**输入契约**（必需字段）：
- `观察对象关系`（字符串：陌生人/同事/合伙人/亲友/下属）
- `可观察信号`（可多选枚举，至少一项）：
  - 神态：未言先笑 / 无事而笑 / 语无伦次 / 眼珠闪动 / 说话换脸
  - 眼形：四白眼 / 三角眼 / 三白眼 / 目带凶光
  - 骨相：命门讲话时突骨跳动（反骨）
  - 眉相：左眉直纹向上 / 乱眉 / 断眉
  - 口舌：唇不蔽齿+舌舔唇口 / 吹火嘴+左眉竖纹 / 鸟啄
  - 声音：声不洪亮、阴柔如女子
- 缺失项（如无法当面观察神态）：明确告知「本卡部分判据需当面动态观察（如命门突骨、眼珠闪动），仅凭静态照片只能做有限判断」。

**步骤**：

1. **先分「进-出」类型**
   - 完成标准：给出君子（难进易出）/ 庸才（易进易出）/ 小人（易进难出）之一，并说明依据（交往中的进入与退出难度）。
   - 说明：类型判断依据**行为模式**，不是单看脸。

2. **逐项核对特征清单**
   - 完成标准：把 `可观察信号` 逐项对照原文清单，列出**命中项**与**未命中项**。
   - 判停点 A：若命中项为 0 → 输出「无典型小人特征」，结束。

3. **叠加计分**
   - 完成标准：按命中数分档 —— 1 项＝提示；2-3 项＝需留意；≥4 项或含「四白眼/命门反骨」＝高危。
   - 说明：此为台湾题**约定**（原文给清单未给分档权重），已在输出中标注为约定。

4. **输出交往风险级别 + 行动建议**
   - 完成标准：给出风险级别（低/提示/留意/高危）与**具体的自我保护动作**（如：先小额试合作、保留证据、避免深度财务绑定、拉开距离）。

**输出契约**（结构化）：
- `类型（进-出）` / `命中特征清单` / `未命中特征` / `风险级别` / `建议动作` / `方法约定说明` / `免责声明（必含）`
- 完成标准：各字段非空；结论表述为「交往风险提示」，**不写「此人是坏人/罪犯」**这类定性。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **⚠️ 不可用于外貌歧视**：不得以「三角眼/四白眼/浓眉/唇不蔽齿」等相貌特征，对他人做道德评判、人格定性或社会排斥。相貌与品性无科学因果关系，以貌取人即是歧视。
- **⚠️ 不可替代背景调查**：涉及雇佣、合伙、婚配、借贷等重大决策时，必须走**正规背景调查、信用与资质核实**，本卡不能作为决策依据。
- **⚠️ 不可作为法律取证**：「此人必反」「小人相」等不具任何法律效力，不得用于举报、诉讼、追责或作为证据。
- **心理投射场景**：用户因焦虑/被害妄想而大量套用小人特征时，应先安抚，避免强化其猜疑。

### 强制免责声明（本卡必写）

> 本卡内容为传统相术文化记录，**仅供文化参考**。面相特征与人的品行、可信度之间没有经过验证的因果关系。**不得**用于外貌歧视、替代背景调查或作为法律取证。涉及合作、雇佣、婚配等现实决策，请依据事实、契约与正式调查渠道。

### 作者在书中警告的失败模式

- **只认脸不认行为**：原文的分型第一层是「进-出」行为判据，脸只是辅助；只看脸会误判（原文自己也说面相「看不到的小人」最危险，反而说明单靠脸不足）。
- **把「小人」道德化**：原文定义为功能性（能害到你的人），若当成「坏人」标签去攻击他人，违反原意。
- **忽略「亲近者最危险」**：原文强调受害者多自愿被亲近者影响——只防陌生人是抓错重点。

### 作者的盲点 / 时代局限（据 BOOK_OVERVIEW 批判）

- **面相歧视与刻板化（重点）**：原文的「小人面相清单」极易被用于以貌取人、地域/性别歧视；「女子面大骨粗声沙」「非处女面相」等条带有强烈传统偏见与人身污名化，本卡不采纳其价值判断，仅作文化记录。
- **不可证伪**：这些特征无法统计验证；判断错误时可归因于「观察不到位」。
- **性别偏见**：多条特征针对女性（素髎骨、人中、面大骨粗），属时代局限。
- **样本偏差**：案例为作者自述，无对照组。
