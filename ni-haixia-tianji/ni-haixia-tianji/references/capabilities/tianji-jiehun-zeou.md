# 结婚择偶与婚姻凶象化解

## R — 原文 (Reading)

> "如果先天命中一世夫妻→选八字契合的人结婚；如果先天命中二婚命→选八字不契合的人结婚。八字合的人在一起会让人感觉很顺眼，脸很像。"
>
> — 《天纪》04-紫微斗数笔记 / 05-紫微详解 合婚段（p38）

> "坊间破解婚姻凶法：伴侣是二婚/伴侣长或小7岁以上。合婚年龄差规则：女命太阳落陷→嫁大7岁以上/二婚夫（正常婚姻反而凶）。"
>
> — 同上（p38）

> "女命太阳落陷+化忌+红鸾同宫+住西北→无夫无子。"
>
> — 同上（p38）

## I — 方法论骨架 (Interpretation)

这条规则要解决一个很反直觉的问题：**当命里婚姻凶（二婚、克夫、难成婚）时，该怎么择偶、怎么化解？** 骨架如下：

- **第一原则（反直觉）**：择偶要看八字合不合，但**结论与常识相反**——先天是"一世夫妻命"的人，要选**八字契合**的对象（顺其吉）；先天是"二婚命"的人，反而要选**八字不合**的对象（用相冲相克去制衡，避免把凶运再放大）。原书说八字合的人"相处顺眼，脸越长越像"。
- **年龄差规则**：女命太阳落陷（＝夫星弱）时，**正常婚姻反而凶**，宜嫁**大七岁以上或小七岁**的丈夫，或嫁**二婚夫**。这是把命里的"婚凶"用择偶条件去对冲。
- **夫妻对应格**（判断"和什么样的人配"）：男命看自己某宫的星＝伴侣对应宫的星。父母宫星＝伴侣命宫星→母子格；命宫星＝伴侣父母宫星→父女格；兄弟宫星＝伴侣命宫星→兄弟格；朋友宫星＝伴侣命宫星→朋友格，用以判断两人关系模式。
- **最凶组合预警**：女命"太阳落陷 + 化忌 + 红鸾同宫 + 住西北角" → **无夫无子**，是需要重点化解的组合。
- **化解口径统一**：与 `tianji-shengong-huajie` 一致——化解靠改方位 + 改择偶条件，不靠符咒或买风水物品。

## A1 — 应用示例 (Application Example)

### 案例 1: 男命半空折翅的婚姻化解（c02，reported_case，来源 05-紫微详解.md）
- **出处 / 输入**: 民国 54 年十月二十八辰时男命（阴男），夫妻宫廉贞+贪狼落陷。
- **问题**: 夫妻宫廉贪落陷→半空折翅格，30 岁左右婚姻大凶、无子女、双方战斗不止。
- **方法怎么执行**: 先识别婚姻凶格 → 按合婚规则给化解方向。
- **结论 / 化解（原书给出）**: ①娶二婚妻（离过婚的）；②娶大七岁以上或小七岁的妻子；③阳宅调整。
- **结果**: 原文记"流年 32 岁妻子感觉人生乏味选择自杀"；**未说明**化解是否被采纳及后续验证。

### 案例 2: 女命雄宿朝垣格与桃花（c05，reported_case，来源 05-紫微详解.md）
- **出处 / 输入**: 民国 56 年正月初二卯时女命（阴女），廉贞在申、贪狼在寅。
- **方法怎么执行**: 雄宿朝垣格→出将入相，但"后期必毁于桃花"；文曲文昌会太阴→桃花（杨贵妃格）。
- **结论**: 女命文曲文昌会太阴→桃花格；雄宿朝垣者见美女眼睛眯成缝（好色特征）。
- **结果**: 原文以"毁于桃花"警示断；**未说明**独立第三方验证。

### 案例 3: 女命太阳落陷类婚凶（c09，reported_case，来源 05-紫微详解.md）
- **出处 / 输入**: 民国 46 年十一月十五午时女命，破军在午入命。
- **方法怎么执行**: 太阳被巨门化忌冲→夫星受冲；隔角煞→离婚象；阳宅西北角厕所缺丈夫位。
- **结论**: 婚凶连环（33 岁丧夫、44 岁再婚、51 岁再丧夫）；化解方向＝调整阳宅方位。
- **结果**: 原文以丧夫年限断；**未说明**化解后的验证。

> 说明：以上均为原书转述命例，结论与被引原文一致；原书对化解的**实际应验未交代**，故标"未说明"。

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①性别；②女命须有太阳落陷与否（判择偶年龄差）；③夫妻宫星曜与亮度；④生年四化（是否有化忌、落宫）；⑤红鸾天喜所在宫；⑥可选：阳宅西北/东南方位信息、本人是否已确定对象及其八字。判"八字合不合"须先有双方八字，缺则先索要，不得静默假设。

**输出契约**：结构化结论，含①婚姻吉凶定性（一世夫妻 / 二婚 / 婚姻凶 / 无夫无子风险）、②择偶条件建议（八字合 or 不合、年龄差、是否择二婚夫）、③化解动作（方位调整 + 择偶条件调整）、④危险组合预警（如太阳落陷+化忌+红鸾+住西北）。每条须标注依据。

1. **判婚姻基本盘**
   - 完成标准: 读夫妻宫 + 生年四化 + 红鸾天喜落宫，判先天属"一世夫妻命"还是"二婚 / 婚姻凶命"。
2. **定择偶八字方向（反直觉核心）**
   - 完成标准: 一世夫妻命→建议**八字契合**；二婚 / 婚姻凶命→建议**八字不合**；说明理由（制衡）。
3. **女命查太阳、定年龄差（判停）**
   - 完成标准: 女命查太阳是否落陷；落陷→输出"宜嫁大七岁以上或小七岁，或嫁二婚夫"。**判停点**：此项仅对女命执行；男命跳过。
4. **查危险组合**
   - 完成标准: 检查是否"太阳落陷 + 化忌 + 红鸾同宫 + 住西北角"四条齐备；齐备→输出"无夫无子"预警并给化解方向。
5. **输出化解与提示**
   - 完成标准: 给出阳宅方位调整方向（转 `tianji-yangzhai-mingwei` 做具体判定）+ 择偶条件调整；声明"化解不靠符咒 / 买物"；提示合婚须有双方八字，缺则不得下"合 / 不合"结论。

## B — 边界 (Boundary) ★

> **本卡属命理/合婚内容，仅供文化参考，不构成事实判断。**

### 不要在以下情况使用此 skill

- 用户只想判婚姻关系好坏——走 `tianji-liuqin-gong`（诊断）。
- 缺任一方八字却要断"合不合"——先索要，不得静默假设。
- 用户问的是财运 / 事业——不属本卡。

### 作者在书中警告的失败模式

- **套用常识择偶**——常识是"找八字合的"，但对二婚命的人恰恰要反过来选八字不合的；用错方向会加重凶象。
- **忽略太阳落陷的年龄差规则**——女命太阳落陷若按常规婚配，反主更凶。
- **漏查危险组合**——"太阳落陷+化忌+红鸾+西北"四齐是最凶婚象，漏掉等于漏报。

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **"选八字不合的人结婚才安全"缺乏实证**：属反直觉经验规则，无独立验证，现代婚姻适配性判断难以复现。
- **"二婚夫""偏房"等判语带旧时代婚姻语境**，含再婚污名化倾向，现代须去除价值判断、只保留"择偶条件调整"的中性内核。
- **性别角色刻板**："女命太阳落陷→嫁大七岁以上/二婚夫"预设女性处于被选择位，现代需中性化处理。
- **"无夫无子"是重断语**：不应作为确定性预言输出，须标注为风险提示。
- **阳宅方位与婚姻的因果链无第三方验证**。

### 容易混淆的邻近方法论

- 与 `tianji-liuqin-gong` 区分: 本卡给处方（选谁），六亲宫卡给诊断（关系如何）。
- 与 `tianji-ziwei-geju` 区分: 本卡处理婚姻择偶策略，格局卡处理婚姻形态判定。
- 与 `tianji-shengong-huajie` 区分: 本卡是婚姻专用化解，后者是通用三层化忌化解。
