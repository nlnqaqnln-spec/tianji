# 金钱卦起课法（六铜板起卦）

## R — 原文 (Reading)

> "第一个要准备一个竹筒，里面一般来说我用铜板……我们来设定的时候一般人头的部分是阳，
> 数字的那面是阴……我们准备六个铜板，在摇的时候我们放在竹筒里摇，摇的时候一定摇5到6下以上，
> 一定要有顺序，如果顺序不好这个卦就作废了……上面是上，这是下，由下往上看。"
> — 01-天机道 占卜段（原文第28449行附近）

> "很慎重，不会乱起课，第一要有必要的时机，第二个心无杂念的起课，千万不要玩……
> 卜以决疑，不疑何卜？"
> — 01-天机道 占卜段（起课禁忌）

> "我们的占卜的过程中我们用解释的过程是用图解释的，不是用文字解释。"
> — 01-天机道 占卜段

## I — 方法论骨架 (Interpretation)

金钱卦起课是《天纪》占卜体系的**前置工具**：它只负责"把问题变成一卦"，
断卦要另配卦义与六神。操作骨架是"备器—定心—摇卦—出卦—记爻—成卦"六步。

工具是竹筒＋六枚铜板（古钱或现代钱币皆可）。阴阳设定：**人头面＝阳，数字面＝阴**，
"一个铜板是分阴阳"。摇卦必须放在竹筒里摇、**至少摇 5–6 下**，且**必须有顺序**——
"顺序不好这个卦就作废了"。出卦时把六枚排成一排，规定上面为"上"、下面为"下"，
记录时**由下往上看**，逐枚看是人是字（人头记阳、数字记阴），六爻既得即成卦。

本派解卦"用图解释，不是用文字"。起课有强约束：心要诚、不玩卜（"卜卦是问鬼神"）、
**一天不超过三卦**、只有重大事情才用、**卜以决疑，不疑何卜**（没有疑虑不占）、
起课要"有必要的时机＋心无杂念"。原文另举反例警示：朋友晚上"玩卜"问"周围还有什么人"，
一丢六爻皆阴，其人惊惧而走，倪师从此不再为其卜。

## A1 — 应用示例 (Application Example)

**原书给出完整照例（起课流程照例）。**

- **输入**：准备一个竹筒与六枚铜板，就一件有疑虑的事项起课。
- **方法怎么执行**：
  1. 备器：竹筒内放六枚铜板；
  2. 定心：心诚、无杂念，选必要时机（不玩卜）；
  3. 摇卦：竹筒内摇 **5–6 下以上**，须有顺序；
  4. 出卦：六枚排成一排；
  5. 记爻：设上为上、下为下，**由下往上**逐枚看人/字；
  6. 成卦：人头记阳、数字记阴，逐爻成象——"你看到第一个是人头，人头是阳，阳阳，阴，就出来了"。
- **结果说明**：六爻既得即所起之课，本派以"图"解卦；断卦需另配卦义与六神（原文未在本段
  给出断卦结论，故**未说明**）。

## E — 可执行步骤 (Execution)

**必需输入**：一个明确的待占事项（最好重大且当事人确实有疑虑）；工具＝竹筒＋六枚铜板
（或等价硬币，约定正面/数字面对应阳/阴）。缺工具可用等价硬币，但须先声明阴阳约定。
**缺失信息处理**：若当事人无明确疑虑 → 依"卜以决疑，不疑何卜"应先劝停，不静默起课。

1. **前置校验**
   - 完成标准：确认①事项重大 ②当事人有真实疑虑 ③当日未超 3 卦 ④无"玩卜"心态；
     任一不满足则**判停**并说明原因（不占）。

2. **备器与定阴阳**
   - 完成标准：竹筒＋六枚铜板就位；明确"人头面＝阳、数字面＝阴"。

3. **摇卦**
   - 完成标准：在竹筒内摇，**至少 5–6 下以上**，动作连续有顺序。
   - 判停点：若摇动无顺序/中断，依原文"顺序不好这个卦就作废"，须重摇。

4. **排出并记爻**
   - 完成标准：六枚排成一排；规定上为上、下为下；**由下往上**逐枚判定人/字。

5. **成卦**
   - 完成标准：逐爻记阳/阴，得六爻成卦；按本派约定"以图解卦"，写出卦象（六爻图）。

6. **移交断卦**
   - 完成标准：明示起课已完成，断卦需配卦义（人间道64卦）与六神；本卡不单独给断语。

**输出契约**：一份起课记录 = 「六爻（由下往上，阳/阴）+ 卦象图 + 起课时间与事项摘要 +
（如需）应配合的断卦能力说明」。缺"由下往上六爻记录"即视为未完成。
**约定说明**："至少5–6下""一天≤3卦"为原书约定，非可量化实证标准，依原文执行。

## B — 边界 (Boundary) ★

> **本卡属占卜内容，仅供文化参考，不构成事实判断。**

### 不要在以下情况使用

- 无实际疑虑、随手测试——原文明确"不疑何卜""不玩卜"。
- 用占卜结果替代医疗、法律、财务等专业决策。
- 需要客观事实/数据的问题——占卜不作证据。

### 作者在书中警告的失败模式

- **玩卜**：把卜卦当游戏（原文举"问周围还有什么人、六爻皆阴、其人惊走"的反例，
  倪师断言"不知进退的人最好不要做朋友"）。
- **乱起课**：无必要时机、心有杂念而起课。
- **一天超 3 卦**：原文个人上限，超则不许。
- **顺序不对**：摇卦无顺序则该卦作废。

### 作者的盲点 / 时代局限

- "心诚则准""问鬼神"属信念性主张，无法客观验证。
- "5–6 下以上""≤3 卦"为经验约定，非实证标准。
- 本段**未展开断卦**（只讲起课），单独起课不构成完整能力——断卦须另配卦义与六神，
  B 段在此显式声明依赖，避免被当完整占断能力调用。

### 容易混淆的邻近方法论

- `tianji-liushen-zhanguan`／`tianji-liushen-yingyong`——断象读法；本卡只起卦。
- `tianji-xiaoliuren`——月日时取数落宫，不用铜板。
- `tianji-sizhu-minggua`——八字排命卦，非占卜起课。
