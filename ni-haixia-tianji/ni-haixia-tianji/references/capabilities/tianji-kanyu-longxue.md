# 堪舆学（龙穴砂水与立向）

## R — 原文 (Reading)

> "龙会结穴，一定有几个先决条件。第一个，一定要有左右有水……第二个要有砂……出水口这两边一定要有砂……然后还要有案山……第五个就是龙虎抱，左边有龙，右边有虎。"

>

> "坎龙坤兔震山猴，巽鸡乾马兑蛇头，艮虎离猪为曜煞，墓宅逢之一且休。"
>
> — 01-天机道【天纪/05堪舆学】3.八煞黄泉（ky15）

## I — 方法论骨架 (Interpretation)

堪舆学是独立于地脉道（阳宅名位）的**室外风水体系**，处理"龙穴砂水"的寻穴与立向。整体判断分三层：

**第一层·结穴与藏风纳气。** 判一地为龙穴须齐备五条件：左右有水（两水在明堂汇合出海）、出水口两侧有砂（动物形砂为佳）、有近案山、有远朝山、有龙虎环抱。总原则是"藏风纳气"——龙势下来、两旁龙虎高起环抱、风不易吹入者吉；当风山顶者凶。判龙取"生与情"二字：山秃石荒无生气、草木雄秀有生气（草秀主文、树雄主武）；水九曲回转入明堂为"有情"、直来直去为"无情"。

**第二层·取穴与来水。** 朝山取穴法："上不过眼，下不过心"——站山脚对案山，使案山由眼看去略高于眼、由胸对去略高于胸，人之正后方即穴位。来水四原则：清、有曲、无声（有声为悲吟水主绝后）、不见水来不见水去；须活水。另辨假穴（顺水回头、水从后而来即假穴）、凹风（一侧低陷风灌入即破藏风纳气）。
- **金城局**：三面环抱圆合，穴在圆心方向最理想；水口交叉为朱雀（主口舌/官讼）
- **九曲入明堂出天子**：来水九曲入明堂=出天子（体系内断语，缺现代实证）
- **平中一突**：明堂平地突出一圆形小山（圆圆肥肥=富星砂），阳宅/阴宅立向朝之→大富

**第三层·立向与分房。** 罗经二十四山分阴阳龙（带红为阳龙、无红为阴龙），阳龙立阳向、阴龙立阴向（净龙）。忌八煞黄泉（坎龙不立辰向、坤龙不立卯向……）与八路黄泉来去水。定穴用穿山 72 龙（测来龙）、透地 60 龙（定龙气入口），下葬须落"珠宝线"。分房宫位法判发福房份与年限（青龙长房、白虎次房、明堂中房；一条支脉管十年）。
- **天星四贵**：亥/巽/艮三方各有来龙聚一地为大贵，可做国都——原文未展开六秀三吉四环

## E — 可执行步骤 (Execution)

**输入契约（必需）**：一处地的现场信息——来龙（山脉走势）、左右龙虎、案山 / 朝山、水口与来水形态；判定葬事者还需子嗣数、来龙阴阳、罗经测向数据。缺现场目测信息时应先索取，不静默猜。
**注意**：原文多处靠"现场目测"，须实地看再定。

**输出契约**：一份堪舆判断 ＝「结穴五条件核查 + 生 / 情结论 + 穴位位置 + 立向（合净龙、避八煞）+（葬事）龙气 / 分房 +（辨真假）土色结论」。缺"取穴"或"立向"即视为未完成。

1. **判结穴五条件**
   - 完成标准: 逐项核查——①左右有水且汇入明堂出海 ②出水口两侧有砂 ③有近案山 ④有远朝山 ⑤有龙虎环抱；五项齐备才论龙穴，缺项则标注不成穴。
2. **判藏风纳气与生 / 情**
   - 完成标准: 写出该处是否藏风纳气（风能否吹入）；山有无生气、水有情 / 无情。
3. **取穴**
   - 完成标准: 按"上不过眼、下不过心"定出穴位位置；查明来龙阴阳。
   - 判停点: 站位不合法则须上下移动重站，直到合此标准。
4. **定立向**
   - 完成标准: 按罗经二十四山判来龙阴阳，阳龙立阳向、阴龙立阴向（净龙）；核查八煞黄泉（坎龙不立辰向、坤龙不立卯向、震龙不立申向、巽龙不立酉向、乾龙不立午向、兑龙不立巳向、艮龙不立寅向、离龙不立亥向）与八路黄泉来去水，避之为吉。
   - 判停点: 若立向犯八煞黄泉 → 停止该向，改选合净龙之向。
5. **（葬事）定龙气与分房**
   - 完成标准: 用穿山 72 龙测来龙、透地 60 龙定龙气入口，下葬须落"珠宝线"（标"正"的 24 个）；按分房宫位法（青龙长房 / 白虎次房 / 明堂中房）判发福房份，"一条支脉管十年"算年限。
6. **（辨真假穴）土色核验**
   - 完成标准: 取峡中土与穴内土比对颜色，同色为真龙、异色判找错脉；据土色决定泻葬 / 补土。
   - **穴名喝形**（选做）：根据案山/朝山/来龙之外形取象命名（狮子舞绣球、犀牛穴等），同音/方言可灵活取名——传统风水的定性定名环节
   - **泻葬/补土**：地气过旺（如红土）→泻葬；石穴/砂局太好→补土法——原书称此为"保证不弃佳地之补救"

## B — 边界 (Boundary) ★

> **本卡属风水 / 堪舆内容，仅供文化参考，不构成事实判断。**
> **域声明**：本卡属**室外阴宅 / 寻龙点穴体系**，与 `tianji-yangzhai-mingwei`（室内阳宅方位 / 名位相等）**不同域**——前者看室外山水（龙穴砂水、寻穴立向），后者看室内家庭成员方位与阳宅成卦；两者不可互相套用。
> **文化参考属性**：原文多处自称"传说"（如官带笏齐备、龙虎八层好地、贫困之地狐臭等），须如实保留"传说"标注，不得当作客观规律。

### 不要在以下情况使用此 skill

- 取代现代建筑、地质、水文安全评估——选址的安全性问题须走专业勘察。
- 现代高层住宅 / 城市公寓的室内布局——本卡是室外山地龙穴体系，不适用于室内方位问题（室内走阳宅名位卡）。
- 纯名词查询（"八煞黄泉是什么"）——直接给定义，不必走完整执行。

### 作者在书中警告的失败模式

- 误认官星为龙穴（"官心"）：辨假穴须"顺水回头"逆水追源，水从后而来即假穴。
- 只看藏风不看水口：八路黄泉来去水犯之主孤寡。
- 葬在龙背 / 山顶当风处：破藏风纳气，不可葬。
- 立向犯八煞黄泉：最凶，绝不可立项。

### 作者的盲点 / 时代局限

- 原文多处自注为"传说"，须如实保留原标注。
- 大量判断靠现场目测，无量化标准与可复现性；穿山 72 龙逐龙克应原文称"写在后面自己看"，未展开。
- "九曲入明堂出天子"等为体系内断语，缺现代实证。

### 容易混淆的邻近方法论

- **面-山同构**（原文经验类比）：山根=来龙过峡、人中=结穴、嘴巴=明堂、地仓=龙虎——此为经验类比，非可量化规则
- **阳宅也不宜房高于后山**（强龙压主）：原文在堪舆段强调"房子绝对不要盖的比后面的山高"
- `tianji-yangzhai-mingwei` / `tianji-yangzhai-xiongju`——室内阳宅名位；本卡是室外堪舆。**不同域，勿混用。**
