# 六吉星判断规则

## R — 原文 (Reading)

> "六吉星：左辅、右弼、天魁（科甲星）、天钺（科甲星）、文昌、文曲。
> 六亲宫单星主凶。文昌坐命无文曲来会→学而不思书呆子；文昌坐命会文曲→
> 男子文采风流，女子则为桃花。"
>
> — 《天纪》04-紫微斗数笔记 / 05-紫微详解，六吉星段（p13）

## I — 方法论骨架 (Interpretation)

六吉星是紫微盘的"辅助增益层"，分三组、各有专职：
① **左辅 / 右弼**：主"辅助"——它们是给主星（尤其紫微）配的左右手，孤星独守时反而主孤单。
② **天魁 / 天钺**：主"科甲与贵人"——魁钺是贵人星，流年逢之易得提拔、遇贵人。
③ **文昌 / 文曲**：主"科甲、读书、才艺"——文昌偏文笔条理，文曲偏才艺风流。
④ **红鸾/天喜**：主喜庆——男命红鸾=美妻；女命红鸾=贵夫。流年在有人的宫或财帛宫均可结婚（原文与六吉星并列在第5-6页）。
⑤ **三台/八座**：主要辅助天府——天府得三台八座才可解厄制化（原文第5页）。
核心法则有三条，且都是反直觉的：
- **六亲宫单星主凶**：在兄弟/父母/子女/夫妻等六亲宫，若只有一颗吉星"独守"（没有成对或主星相配），主凶（如夫妻宫孤星独坐 → 二婚）。
- **昌曲须成对**：文昌坐命而无文曲来会 → "学而不思"的书呆子；昌曲相会 → 男子文采风流、女子则犯桃花。
- **昌曲化忌**：主考试不中。
- **左辅右弼/三台八座四颗独守完整断语表**：命宫独守=孤独/辅助之才；父母宫孤星=父母单一；夫妻宫孤星独坐=二婚；入福德=最惨；大流年逢孤星=孤单（笔记第13页）
判断顺序：先定位该吉星落在哪一宫 → 再看它是"独守"还是"成对/会照" → 最后按宫位与性别给断语。本卡是辅星层，须与主星、庙旺合看才有意义。

## A1 — 应用示例 (Application Example)

**原书未提供独立标注"六吉星单星主凶"的完整算例**（相关断语散见于命例叙述中）。以下为**合成演练**，用于验证已知规则，非作者经历：

- **输入**: 文昌坐命、无文曲来会。
- **方法执行**: 定位文昌在命宫 → 检查是否有文曲同宫或三方会照 → 判为"单星"。
- **预期输出**: 断为"学而不思 / 书呆子"；**若**会文曲来照 → 分支改为"男子文采风流、女子桃花"。
- **说明**: 本演练严格依 p13 原文规则复算两分支；原书未给出"孤星独守六亲宫"的完整命盘算例，故本卡不虚构结果，仅按规则展示分支。

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-liushaxing`（六煞星）的区别: 本卡是"增益"一侧（吉星），煞星卡是"减损"一侧；两者常成对出现（吉煞同宫要看谁强）
- 与 `tianji-shisi-zhuxing`（十四主星）的区别: 本卡是辅星层，主星卡是属性层；先看主星，再用吉星做加减
- 与 `tianji-miaowang-luoxian`（庙旺落陷）的区别: 六吉星也有亮度，本卡给功能，亮度卡给吉凶强弱；六亲宫"单星主凶"是这组吉星特有的反直觉规则
- 与 `tianji-liuqin-gong`（六亲宫）的区别: 六亲宫卡处理"哪个宫代表哪个亲属"，本卡处理"吉星落在六亲宫且独守时的凶象"；两者常配合

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①吉星名（左辅/右弼/天魁/天钺/文昌/文曲）；②所在宫位；③该星是否"独守"（无成对星、无主星相配、无三方会照）；④性别（判断昌曲会命时要分男女）。**缺失项应先询问**：只问"左辅好不好"而不给宫位与是否独守时，不得直接断吉凶。

**输出契约**：一条"吉星 × 宫位 × 独守/成对 → 结论"记录，字段{吉星名、所在宫、独守还是成对、功能要点、断语、性别分岔}。**约定**：本卡以原书"六亲宫单星主凶"为强制检查项；判断昌曲必先确认是否成对。"独守"须显式核验，不可默认。

1. **确认输入齐备**
   - 完成标准: 吉星名、宫位、是否独守、性别四项到位；缺"是否独守"则先查同宫/三方会照
2. **判断是否六亲宫**
   - 完成标准: 若落在兄弟/父母/子女/夫妻等六亲宫 → 强制走"单星主凶"检查；否则跳过该步
3. **检查独守（判停）**
   - 完成标准: 明确该星是单星独守还是成对/会照
   - 判停点: 若六亲宫且单星独守 → 直接给"主凶"结论（夫妻宫孤星独坐→二婚），并提示该宫六亲有缺陷
4. **套功能与断语**
   - 完成标准: 给该星功能（辅弼=辅助、魁钺=科甲贵人、昌曲=科甲才艺）与落宫断语
5. **昌曲特别分支**
   - 完成标准: 文昌无文曲=学而不思/书呆子；昌曲相会=男文采风流/女桃花；昌曲化忌=考试不中
6. **交棒合看**
   - 完成标准: 提示须与主星及亮度合看；汇总后交 `tianji-ziwei-pandu` 做整体判读，本卡不单独出人生结论

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想知道某颗主星的属性——走 `tianji-shisi-zhuxing`
- 没有宫位、无法判断是否独守时，不得单凭星名断吉凶
- 用户问的是煞星（擎羊/陀罗/火铃/空劫）——走 `tianji-liushaxing`

### 作者在书中警告的失败模式

- **忽略"单星主凶"**：这是六吉星最反直觉的规则；把吉星一律当"好"会漏断六亲宫的凶象
- **不看昌曲是否成对**：把文昌单独坐命直接断"文采好"，漏掉"学而不思/书呆子"的分支
- **把吉星孤立使用**：六吉星须与主星、亮度合看；单独加载无法正确执行（verified 判据 3 不通过即因此）

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **命例为倪师自述批命经验，无第三方验证**；"单星主凶""孤星二婚"等断语解释空间大
- **性别刻板断语**："女子昌曲会命为桃花"等表述带成书年代性别观，现代语境须谨慎
- **紫微详解夹带整理者个人玄学内容**，引用吉星断语须区分来源

### 容易混淆的邻近方法论

- 与 `tianji-liushaxing` 区分: 吉星=增益、煞星=减损；吉煞同宫须比较强弱与庙旺
- 与 `tianji-liuqin-gong` 区分: 六亲宫卡定"宫属谁"，本卡定"吉星在六亲宫独守的凶象"
