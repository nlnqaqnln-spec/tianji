# 六亲宫判断规则

## R — 原文 (Reading)

> 「六亲宫单星主凶。斗数来批六亲不太精准，需配合面相来判断。
> 兄弟宫有化忌：a.兄弟不和；b.兄弟夭折；c.兄弟合伙破财。」
>
> — 倪海厦《天纪》· 原则 p20（六亲宫），源文件 04-紫微斗数笔记 / 05-紫微详解

补充原文要点（同条 p20）：父母宫黯淡无光 → 庶出或螟蛉子；父母宫化禄 → 祖产财禄；
子女宫无主星 + 对宫化忌 → 无子；子女宫化忌 → 无子/与子冲突；
**夫妻宫必须与福德宫一起看**（一好一差 → 夫妻不能长久）；太阳在盘上代表父/夫/子，
太阴代表母；太阳化忌 → 父/夫/子有灾，太阴化忌 → 母亲有灾；女命太阳落陷 → 婚配对象
宜大七岁以上或二婚夫。面相验证优先：眉毛左兄弟右姐妹（断眉→夭折）、左眼袋=儿子右眼袋=女儿、
左额头日角=父亲右额头月角=母亲。

## I — 方法论骨架 (Interpretation)

六亲宫（兄弟/父母/子女/夫妻）判的不是「你自己」，而是你与亲人的关系与缘分。判读有三条铁律：

1. **单星主凶**：六亲宫出现孤星独守（羊陀火铃空劫等煞星，或辅弼台座等吉星单独一颗）→ 主凶。
2. **斗数不精准，面相优先验证**：批六亲本身「不太精准」，凡有面相可核对处，以面相为准——
   眉毛（左兄弟右姐妹，断裂=夭折）、眼袋（左子右女）、额头角（左日角父/右月角母）、
   眼睛一大一小不在一条水平线（庶出/螟蛉子）。
3. **夫妻宫必须合福德宫看**：夫妻宫和福德宫一好一差 → 婚姻不能长久；不能只看夫妻宫就下结论。

- **子女人数推算规则**（笔记第31页原文）：代表儿子的星及其数量——紫微1个、天相1个、贪狼1个、太阳1个、天府1个、武曲1个、天同1个、破军2个、文昌1个、廉贞2个、七杀2个。判断时以子女宫见这些星来加总；化忌=减半或无子。

再叠一层「四化落宫」定具体事项：兄弟宫化忌 → 三义（兄弟不和/夭折/合伙破财）；
子女宫化忌 → 无子或与子女冲突；父母宫化禄 → 得祖产。太阳/太阴的化忌则指向
父/夫/子与母的灾。

- **经脉流注对照（疾厄宫辅助判断）**（笔记第2页）：十二经各有对应十二宫——命宫大肠经、兄弟宫胃经、夫妻宫膀胱经/子宫、子女宫三焦经/小肠/命门、财帛宫胆经、疾厄宫肝经/心包络、迁移宫心经/小肠经、朋友/仆役宫肾经、官禄宫肺经、田宅宫脾胃经、福德宫胆经/肝经、父母宫脾经/三焦经/肺经。可作特定疾病对应的初步筛查——但原书强调须与经脉医师合参，不定论。

## A1 — 应用示例 (Application Example)

### 书中的应用（reported_case，来源 05-紫微详解.md）

**案例 c02 — 民国54年十月二十八辰时男命（半空折翅格）**
- **问题**: 夫妻宫与子女宫判断——婚姻与子嗣。
- **方法的使用**: ① 查夫妻宫：廉贞+贪狼**落陷** → 原文断为「半空折翅格」，30岁左右婚姻大凶；
  ② 合看大限：大限 23–32 落夫妻宫，半空折翅 → 无大运，婚姻不好、无子女、双方战斗不止；
  ③ 查子女宫：太阴化忌 + 日月反背 → 无子、六亲不靠、父母凶。
- **结论**: 婚姻大凶、无子女、六亲不靠。
- **结果（原书交代）**: 流年 32 岁妻子感觉人生乏味选择自杀；大限 33–42 未来十年无大运。
- **化解（原书给出）**: ① 娶二婚妻；② 娶大七岁以上或小七岁的妻子；③ 阳宅调整。
  并引出八字合婚原则：先天婚凶者反而找「八字不合」的人结婚才安全。

**案例 c09 — 民国46年十一月十五午时女命（杀破狼格 + 双丧夫）**
- **方法的使用**: ① 夫妻缘：破军在午入命（英星入庙/杀破狼）→ 女命孤僻孤单，隔角煞 → 离婚象；
  ② 巨门化忌冲太阳（父/夫/子）→ 断夫；③ 面相验证：面大/骨粗/声沙 → 孤独一身；
  眉角黑点凹下 → 33 岁奸门（夫妻宫）有凶。
- **结果（原书交代）**: 33 岁丧夫，44 岁再婚，51 岁再次丧夫（七年一轮）。
- **说明**: 两例均为原书亲述命例，输入/断法链条/结论/结果齐备，非合成演练。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 问「兄弟/父母/子女/夫妻宫怎么看」「我和家人缘分如何」
2. 关心婚姻能否长久、会不会生离死别（夫妻宫 + 福德宫）
3. 关心子嗣（子女宫）、与父母关系（父母宫）、兄弟是否和睦（兄弟宫）
4. 命盘显示某六亲宫化忌，问「这是什么意思」

### 语言信号（中英双写）

- 中文：「兄弟关系怎么样」「子女宫怎么看」「和父母缘分」「夫妻宫化忌」「婚姻好不好」「有没有孩子」
- 英文：`siblings palace` / `children palace` / `spouse palace` / `relationship with parents` / `will my marriage last`

### 与相邻 skill 的区分（初稿）

- 与 `tianji-jiehun-zeou`（结婚择偶）的区别：本卡判「六亲关系现状/缘分」，择偶卡管「跟谁结、
  怎么选、怎么化解婚凶」；婚姻类问题常先本卡后择偶卡。
- 与 `tianji-mianxiang`（面相十二宫）的区别：本卡以斗数盘为主、面相为验证；
  面相卡纯从脸部定位判断。
- 与 `tianji-ziwei-pandu`（三方四正流程）的区别：本卡是其六亲分支，由判读流程调用。

## E — 可执行步骤 (Execution)

**输入契约**
- 必需：命盘十二宫；目标六亲宫内的星曜及其亮度；四化（科权禄忌）落宫；大限所在宫。
- 强建议：面相可观察项（眉毛/眼袋/额头角/眼距）——原文强调面相验证优先，缺此项须说明
  「结论未获面相验证」。
- 缺失四化落宫或亮度时 → 先补齐，不得静默猜值。

1. **定宫位对象** — 明确要判的是哪个六亲宫（兄弟/父母/子女/夫妻）。
   - 完成标准：宫位与所问六亲对应准确。
2. **查单星** — 检查该宫是否有孤星独守（煞星或单颗辅弼台座）。
   - 判停点：若单星独守 → 先标「主凶」，继续第 3 步补充具体义项。
3. **查四化** — 看四化是否落入该宫或其三方。
   - 完成标准：化忌按条义展开（如兄弟宫化忌 → 不和/夭折/合伙破财三义全列）。
4. **夫妻宫专项** — 若判夫妻，**必须**同时看福德宫，且落实到「一好一差→不长久」的合判。
   - 判停点：未取到福德宫 → 不得单独下婚姻结论。
5. **面相验证** — 用紫微十二宫→面相十二宫的完整对照表逐项比对，标注是否相符。
   - 完成标准：输出「斗数结论 + 面相验证结论 + 是否一致」。
   - **完整对照表（紫微十二宫→面相十二宫，一一对应）**：
     | 紫微十二宫 | 面相十二宫 | 面部定位 | 六亲关联 |
     |------------|------------|----------|----------|
     | 命宫 | 印堂 | 两眉之间 | 自我根基 |
     | 父母宫 | 日月角 | 额头左日角(父)、右月角(母) | 父母缘 |
     | 兄弟宫 | 眉毛 | 左眉=兄弟、右眉=姐妹 | 手足缘 |
     | 夫妻宫 | 奸门 | 眼角/鱼尾纹区域 | 婚姻缘 |
     | 子女宫 | 泪堂 | 眼睛下方(左子右女) | 子嗣缘 |
     | 财帛宫 | 鼻 | 鼻子中段 | 财运 |
     | 官禄宫 | 中正 | 上前额 | 事业 |
     | 田宅宫 | 眉眼间 | 眉毛与眼睛之间 | 房产/家宅 |
     | 迁移宫 | 天仓 | 太阳穴区域 | 外出/远行 |
     | 仆役宫 | 下巴 | 下颌 | 下属/交友 |
     | 疾厄宫 | 山根/年寿 | 鼻梁根部至鼻梁中段 | 健康 |
     | 福德宫 | 眉上 | 眉毛上方区域 | 福报/内心 |
   - **关键六亲验证点位**：兄弟宫→眉毛（断眉=夭折/不和）、父母宫→日月角（凹陷/低平=父母缘浅或庶出）、夫妻宫→奸门（纹向下=生离、纹叉+黑斑=死别）、子女宫→泪堂（丰满=子女多、暗黑=子女有灾、凹陷=原书未列征象归为不够丰隆）。
   - **判停点**：面相与斗数一致→增强置信度，标注"面相验证一致"；不一致→标注"面相不一致，可能时辰有误或命盘未开"，不强行解释。
6. **给缓化方向** — 依总纲给地理/人事可调整动作（如阳宅改位、择偶条件调整）。
   - 完成标准：至少一条可执行缓化建议。

**输出契约**
- 结构化输出：`六亲对象 → 宫内星曜/亮度 → 单星判断 → 四化义项 → 面相验证 → 结论 → 缓化动作`。
- 结论用「缘分层次」表述（亲/淡/刑克/生离/死别等），不输出对具体亲人的确定性死亡断言。
- 完成标准：每项可回溯 p20 条目；涉及婚姻必含福德宫合判记录。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 只做星性/格局判断（走 `tianji-shisi-zhuxing` / `tianji-ziwei-geju`）。
- 要给出结婚时机与择偶策略（走 `tianji-jiehun-zeou`）。
- 让步于「六亲注定」的宿命结论——原文明确指出斗数批六亲「不太精准」，且全书总纲为命可化解。

### 失败模式（原书警告）
- 忽略「单星主凶」：六亲宫孤星独守却按常态断吉。
- 夫妻宫不与福德宫合看 → 单宫下婚姻结论，误断。
- 放弃面相验证 → 损失原文最强调的交叉验证通道。

### 作者盲点 / 时代局限
- 「太阳=父/夫/子、太阴=母」的绑定为传统设定；原文自身也承认六亲判断精度有限，
  且 c13 六亲生肖推算法注明「非倪师原书内容，为整理者扩展」，属来源风险项。
- 涉及生死/婚姻的断言不得作为事实性预言使用，related 决策仍须回归当事人自主选择。

### 邻近方法论
- `tianji-jiehun-zeou`（婚配与化解）；`tianji-mianxiang`（面相验证通道）；
  `tianji-sihua`（四化落宫）；`tianji-shengong-huajie`（改运与化忌化解）。
