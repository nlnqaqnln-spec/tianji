# 六煞星判断规则

## R — 原文 (Reading)

> 「六殺星：擎羊、陀罗（羊陀）、火星、铃星（火铃）、天空、地劫（空劫）。
> 天空地劫→生意流年逢之必赔；火星铃星流年遇到→主火厄/个性冲突/口角；
> 陀罗擎羊→主身边看不到的小人，又疾病血光。」
>
> — 倪海厦《天纪》· 原则 p14（六煞星），源文件 04-紫微斗数笔记 / 05-紫微详解

补充原文要点（同条 p14）：疾厄宫见陀罗+擎羊 → 主开刀/见血光；擎羊陀罗落陷更可怕（阴凶看不到）；
羊陀火铃空劫单星独守十年大运且无吉星化解、对宫天府又不能解厄 → 大凶（代表死限）；
面相上讲话时左边眉毛直纹向上 → 两面三刀相（看不到的小人相）。

## I — 方法论骨架 (Interpretation)

六煞星不是六颗各管一摊的星，而是按「出事方式」分成三对，判断时先对号入座：

- **空劫（天空+地劫）**——破财型。主「赔」，尤其是流年逢之做生意的场合必赔。
  地劫独守或在对宫一样是大凶；唯一例外是武曲配地劫（只是破小财）。
- **火铃（火星+铃星）**——冲突型。主火厄、个性冲突、口角，是"急性子招来的火"。
- **羊陀（擎羊+陀罗）**——暗伤型。主身边"看不到的小人"，又主疾病与血光（开刀见血）。
  擎羊陀罗一旦落陷，凶性更重，因为属"阴凶"（当面看不出来）。

定完类别还要定**严重度**两件事：一看是否**落陷**（落陷更凶）；二看是否**单星独守且无化解**
（羊陀火铃空劫任一单星独守十年大运、又有对宫天府解不掉时 → 判为大凶/死限）。所以煞星判断从来不是
孤立做结论，而是「主星 + 庙旺 + 有无吉星」合看之后的加权项。

## A1 — 应用示例 (Application Example)

### 原书未提供六煞星专属命例，以下为合成演练

- **输入**: 某命盘疾厄宫见陀罗 + 擎羊同宫；且两星均落陷；该宫三方无吉星、对宫天府。
- **方法的使用**: 按 u09 三步——① 先归类别：羊陀 → 暗伤（疾病/血光）；② 定严重度：查亮度，
  羊陀落陷 → 严重度上调；③ 查化解：三方无吉星、对宫天府（原文指出天府不可解厄制化）→ 无化解。
- **预期输出**: 判「主开刀/见血光」，并标为严重度「重」；提示核对台面之外的小人因素。
- **说明**: 本条演练严格依 p14 原文规则（疾厄宫羊陀 → 开刀见血光；落陷更凶；单星独守无化解 → 大凶）
  逐步复算，未添加原书未给出的条件；原书未交代该例实际结果，故此项为规则演练而非命例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 命盘里看到擎羊/陀罗/火星/铃星/天空/地劫，问「这几颗星什么意思」「我的煞星重不重」
2. 关心破财、血光、开刀、口角冲突、犯小人等具体凶象来源
3. 流年/大运中撞上煞星，问「今年是不是特别不顺」「会不会有事」
4. 想对照自己的经历（是否开过刀/是否常破财）来验证命盘

### 语言信号（中英双写）

- 中文：「擎羊陀罗怎么看」「火星铃星」「六煞星」「煞星重不重」「会不会破财/血光/犯小人」
- 英文：`what do sha stars mean` / `Qing Yang Tuo Luo` / `malefic stars` / `will I lose money` / `bloodshed`

### 与相邻 skill 的区分（初稿）

- 与 `tianji-miaowang-luoxian`（庙旺落陷）的区别：本卡判「煞星类别与凶象方向」，庙旺落陷卡判
  「亮度如何放大/削弱吉凶」——本卡必须先调用前者取亮度，才能定严重度。
- 与 `tianji-liujixing`（六吉星）的区别：本卡管凶星，六吉星卡管吉星与「单星主凶」的反向规则。
- 与 `tianji-ziwei-pandu`（三方四正流程）的区别：本卡是其判读流程中「煞星层」的内部查表，不单独起头。

## E — 可执行步骤 (Execution)

**输入契约**
- 必需：命盘宫位表（十二宫名）；目标宫中出现的煞星名（擎羊/陀罗/火星/铃星/天空/地劫）；
  各煞星亮度（庙旺得利平闲陷）；该宫三方四正内是否有吉星/主星；对宫星曜。
- 可选：性别、起问事由（破财/健康/人际）。
- 缺失「亮度」或「宫位」时 → 先向用户索要或先走排盘，**不得静默猜值**。

1. **归类别** — 把煞星按三对归位：空劫→破财；火铃→冲突（火厄/口角）；羊陀→暗伤（小人/血光）。
   - 完成标准：每颗煞星都有明确类别归属；未列出的星不得硬塞。
2. **定亮度** — 逐颗查庙旺落陷。
   - 完成标准：标出「是否落陷」；落陷 → 严重度上调一档。
3. **定化解** — 查该宫三方四正是否有吉星、对宫是否可解厄（原文：天府不可解厄制化）。
   - 判停点：若为「单星独守十年大运 + 无吉星化解 + 对宫天府不能解厄」→ 直接判「大凶（死限级）」，
     跳至第 5 步，不再逐项细断。
4. **合主星断象** — 与主星、宫性合看给出具体凶象（如疾厄宫羊陀→开刀血光；财帛宫空劫→赔）。
   - 完成标准：输出「凶象 + 触发场景 + 严重度」三要素。
5. **给缓化方向** — 依全书总纲给出可调整的地理/人事动作，不下确定性断言。
   - 完成标准：至少一条可执行缓化建议；涉及健康/生死时必须附加就医提示。

**输出契约**
- 结构化输出：`煞星 → 类别 → 亮度 → 化解情况 → 凶象 → 严重度 → 缓化动作`。
- 严重度分级约定：轻 / 中 / 重 / 大凶（死限级）。该分级为本卡为落地判断所作的约定，
  原文只区分「凶」与「更凶/大凶」，约定不改原意。
- 完成标准：每一项都能回溯到 p14 原文条目。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 命盘尚无亮度信息时单独断煞星——会漏掉「落陷更凶」这一关键变量。
- 用户要的是主星性格、格局或六亲判断（分别走 shisi-zhuxing / ziwei-geju / liuqin-gong）。
- 把煞星结论当作对个人的确定性预言（如断言死亡、断定必开刀）。

### 失败模式（原书警告）
- 「单星主凶」被忽略：羊陀火铃空劫单星独守大运、无吉星化解 → 原文判大凶/死限，漏看即误断。
- 只数煞星数量、不看亮度与化解，得出过重或过轻的结论。
- 把武曲+地劫当大凶——原文明确此为例外（破小财而已）。

### 作者盲点 / 时代局限
- 原文对「阴凶看不见」「左眉直纹=两面三刀」等面相断语带有强主观性，属文化参考，不宜作事实判断。
- 「死限」类判语属命理推演，不可替代医疗与安全判断。

### 邻近方法论
- `tianji-miaowang-luoxian`（提供亮度，本卡依赖它）；`tianji-liujixing`（吉星侧）；
  `tianji-shisi-zhuxing`（主星侧）；`tianji-ziwei-pandu`（调用本卡的流程）。
