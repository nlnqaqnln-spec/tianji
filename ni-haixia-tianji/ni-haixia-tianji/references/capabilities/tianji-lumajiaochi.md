# 禄存与禄马交驰格

## R — 原文 (Reading)

> "禄存星性：财星，同化禄；禄存在命宫→守财奴型；禄存/化禄与天马同宫→禄马交驰→辛苦赚大钱/巨富。禄马交驰+巨门入庙在命→巨富/豪门宅第。"
>
> — 《天纪》04-紫微斗数笔记 / 05-紫微详解 禄存段（p16）

> "大财星：禄存、化禄、武曲、贪狼。"
>
> — 同上（p16 汇总）

## I — 方法论骨架 (Interpretation)

这条规则解决的是"一个人会不会有大财、财从哪来"里的**财星组合识别**问题。骨架分三层：

- **第一层：认财星**。北斗体系里真正的大财星是四颗——禄存、化禄、武曲、贪狼。其中禄存与化禄同性质（都属于"禄"，主财），但禄存是固定星位、化禄随四化走。
- **第二层：单看禄存**。禄存落命宫 = 守财奴型：会攒钱、守得住，但不一定赚得多；它是"守"的财，不是"闯"的财。
- **第三层：看组合成格**。"禄马交驰"是一个**成格条件**：禄存（或化禄）与天马**同宫**时成立，含义是"辛苦赚大钱"——财要靠跑动、奔波、走动赚来，不是坐着等。这是它和纯禄存（守财奴）的关键差别。
- **第四层：叠加升级**。在禄马交驰基础上，若命宫再有**巨门入庙**（巨门庙旺），则从"辛苦赚大钱"升级为"巨富 + 豪门宅第"——这是原书给出的最高级财富组合。
- **判读顺序不可倒**：先查庙旺（巨门是庙还是陷），再判组合成格，最后才下"巨富"结论。巨门落陷时不但不助财，反主口舌牢狱，不能套用巨富断语。

一句话：**先确认财星，再看禄+马是否同宫成格，最后用巨门庙陷决定要不要升到"巨富"。**

## A1 — 原书案例 (Past Application)

原书未提供以"禄马交驰"为**主题**的独立完整命例。但有一条可作类比的 reported_case 素材：

### 案例 1: 女命巨日同格（c06，reported_case，来源 05-紫微详解.md）
- **出处**: 民国83年正月十九巳时女命（阳女）
- **与本卡的关联**: 该例判为"巨日同格"（太阳+巨门皆庙旺）→ "腰缠黄金穿紫衣，大富巨富，富可敌国"。它演示了本卡第 4 步的关键前提：**巨门必须庙旺**，才与财组合出"巨富"级结论；落陷则判若两格。
- **结论**: 巨门庙旺 + 财星体系齐备 → 大富巨富
- **结果**: 原文以"大富巨富"断；未说明后续独立验证

### 案例 2: 男命紫府同宫 + 七杀朝斗（c10，reported_case，来源 05-紫微详解.md）
- **出处**: 民国40年十一月十五申时男命（阴男）
- **与本卡的关联**: 该例含"巨日格"分支，原书记"如果在命宫→生下来就是豪门宅地之家"，印证本卡"巨门入庙 + 财 → 豪门宅第"的叠加断语。
- **结论**: 巨日格在命宫 → 豪门宅第之家
- **结果**: 原文注明"紫易奇缘注：格局非绝对，需看伤使与化三忌"——提醒巨富级结论仍受其他变量修正

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户命盘里出现禄存 + 天马（或化禄 + 天马）同宫，想知道"这是什么格局、能发财吗"
2. 用户问"我命里有没有大财星 / 我是靠什么赚钱的"
3. 用户命盘禄存在命宫，问"我是守财奴吗 / 我为什么存得住钱却赚不多"
4. 用户问"巨门入庙在命加上禄马交驰是不是巨富"

- "禄马交驰是什么 / 禄存怎么看 / 我有没有大财星"
- "我是守财奴型吗 / 财星落在命宫好不好"
- "巨富格局怎么看 / 巨门入庙加天马"
- "Lu Ma Jiao Chi / Lu Cun / wealth star combination / rich chart"

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-sihua`（四化）的区别: 本卡处理的是**禄存/天马/巨门**的组合规则；四化卡解释"化禄本身在各宫的含义变化"，两者在"化禄+天马"处交叉，需说明本卡专责"成格判断"
- 与 `tianji-ziwei-geju`（格局判断）的区别: 本卡是窄口径的单一财富格局（禄马交驰）；格局卡处理日月反背/半空折翅/桃花格等吉凶格；禄马交驰在体系里是格局卡的一个分支，此处独立列出
- 与 `tianji-shisi-zhuxing`（十四主星）的区别: 主星卡讲巨门"本身"星性（口舌/豪宅），本卡讲"巨门入庙参与财组合"时的效果
- 与 `tianji-miaowang-luoxian`（庙旺落陷）的区别: 亮度卡提供"巨门是庙是陷"的判定标准，本卡消费该判定，不重复定义

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①命盘星曜分布（须含禄存、化禄、天马三颗星各落在哪个宫）；②巨门所在宫及其**亮度**（庙旺得利平闲陷，必需，缺则先索要）；③目标宫位（通常是命宫，也可能是财帛宫）。缺亮度信息不得静默猜值——巨门庙陷决定结论是否升到"巨富"。

**输出契约**：结构化结论，含①识别到的财星清单、②是否成禄马交驰格（是/否+依据宫位）、③若成格则输出财运定性、④若命宫巨门庙旺则加输出"巨富/豪门宅第"升级结论。计算类无需数值，属规则判定，须逐条标注"依据某星在某宫"。

1. **清点财星**
   - 完成标准: 列出命盘中的禄存、化禄、武曲、贪狼各在何宫，标注哪些是"本格相关"（禄存/化禄）
2. **判定禄马交驰成格**
   - 完成标准: 检查是否有"禄存与天马同宫"或"化禄与天马同宫"；有则判**成格**，无则判**不成格**并跳到第 5 步
3. **查巨门亮度（判停）**
   - 完成标准: 查命宫（或目标宫）巨门亮度。**判停点**：若巨门**不庙旺**（得/利/平/闲/陷），《天纪》未给出巨门非庙旺时与禄马的叠加规则——**原文未展开**，应停在"辛苦赚大钱"层，不得输出"巨富"
4. **输出升级结论**
   - 完成标准: 巨门**入庙**且在命 → 输出"巨富 + 豪门宅第"；否则只输出"辛苦赚大钱/巨富"
5. **输出并提示前提**
   - 完成标准: 结论逐条可回溯到"某星在某宫"；提示"辛苦赚大钱"意味着财需靠奔波、走动、多跑动获得（与坐等型财星区分）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 命盘缺亮度/缺天马落宫——无法判成格，应先补齐
- 用户只问"我财运怎么样"这种总问题——应先走 `tianji-ziwei-pandu` 看三方四正总格，本卡只回答"这一格成不成"
- 用户要的是阳宅/择日的财，不属本卡

### 作者在书中警告的失败模式

- 看到禄存就断"大富豪"——禄存单独落命只是"守财奴型"，赚得不一定多
- 看到天马就套禄马交驰——必须禄存**或**化禄与天马**同宫**，不同宫不成格
- 忽略巨门亮度直接断"巨富"——巨门落陷反主口舌牢狱，是最典型的误断

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **格局结论无第三方验证**：巨富级断语来自倪师自述批命经验，无法独立检验
- **"辛苦赚大钱"缺乏量化**：原文未给出"多辛苦"或"多大财"的边界，实际输出易流于模糊
- **时代经济假设**：以传统商业/走动经营（天马=驿马=奔波）为模型，对现代固定薪资或线上收入场景适用性未加讨论——**原文未展开**
- **财星四颗的说法不全**：p16 列"禄存/化禄/武曲/贪狼"为大财星，但未与其他财富格局（如巨日格、水澄桂萼）做统一排序

### 容易混淆的邻近方法论

- 与 `tianji-sihua`（化禄在各宫含义）区分: 化禄卡讲"化禄在财帛/命/父母宫分别什么意思"，本卡讲"化禄与天马同宫时成格"
- 与 `tianji-ziwei-geju`（格局）区分: 本卡是财富格局的单点，格局卡覆盖吉凶全谱
