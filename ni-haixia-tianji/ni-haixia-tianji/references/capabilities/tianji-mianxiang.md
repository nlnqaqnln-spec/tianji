# 面相十二宫判断

## R — 原文 (Reading)

> "面相各宫：子女宫=泪堂(眼睛下方)；官禄宫=中正(上前额)；命宫=印堂(眉毛之间)；
> 迁移宫=天仓；财帛宫=鼻子中间一段；夫妻宫=眼角(奸门)；仆役宫=下巴；命门=鬓角下方(观生死)。"
>
> — 04-紫微斗数笔记 第2/9/12页（p25 / f07 / p41，单元 u16）

## I — 方法论骨架 (Interpretation)

面相是紫微命盘在脸上的"屏幕显示"：脸上十二个区域与紫微十二宫一一对应，因此不必排盘、看一眼即可读出吉凶。核心是**先定位、再看形纹气色、最后定时限**：

> **⭐ 本卡是紫微斗数判读的面相验证通道**：紫微十二宫与面相十二宫一一对应，斗数的夫妻宫结论要在奸门验证、子女宫结论要在泪堂验证、兄弟宫结论要在眉毛验证。如斗数断"兄弟不和"但眉毛完整浓密，则斗数结论存疑——这是原文强调的核心互参原则。
> 
> 完整对照：命宫→印堂、财帛宫→鼻、夫妻宫→奸门、子女宫→泪堂、官禄宫→中正、田宅宫→眉眼间、迁移宫→天仓、仆役宫→下巴、疾厄宫→山根/年寿、福德宫→眉上、父母宫→日月角、兄弟宫→眉毛。
- **定位**：命宫=印堂（两眉之间）、夫妻宫=奸门（眼角）、子女宫=泪堂（眼下）、官禄宫=中正（上前额）、田宅宫=眉眼之间、迁移宫=天仓（太阳穴）、财帛宫=鼻子中段、仆役宫=下巴、命门=鬓角下方（观生死）、父母宫=额头日角（左/父）月角（右/母）、兄弟宫=眉毛。
- **看形纹**：纹路的方向与形态定吉凶——奸门一条纹向下=夫妻生离；纹被切割或有叉+黑斑=死别；颧大有肉=权、皮骨相连=孤权；泪堂丰满=子女多、暗黑=子女有灾。
- **看气色定时限**：黄润=喜事，暗黑=近期劫杀想不开，枯焦=已发生，枯黄=刚发生约两周，青蓝=死。以"下一节气"为观察窗口。
- **与命盘互参**：面相看近期、命盘看一生，两者交叉验证（左眼=太阳/父夫，右眼=太阴/母妻）。

## A1 — 原书案例 (Past Application)

### 案例 1: 女命破军在午（c09，reported_case，面相应部）
- **出处**: 05-紫微详解.md，民国46年十一月十五午时女命（阴女）
- **方法执行**: 先看夫妻宫（奸门）——眉角黑点、凹陷 → 断33岁奸门（夫妻宫）有凶；再看形——面大、骨粗、声沙 → 断孤独一身
- **结论**: 面相两点（奸门凶 + 面大骨粗声沙）与命盘两次丧夫互相印证
- **结果**: 原文记33岁丧夫、51岁再次丧夫；未提供第三方验证

### 案例 2: 男命廉贪在亥（c02，reported_case，面相应部）
- **出处**: 05-紫微详解.md，民国54年十月二十八辰时男命（阴男）
- **方法执行**: 日月反背格局下面相应见"哭脸"（男人哭脸主丧偶），配合奸门纹判断婚姻大凶
- **结论**: 面相比对支持命盘"半空折翅格"婚姻结论
- **结果**: 原文记"流年32岁妻子自杀"；未给独立验证

> 注：另有 c04（山根低、眼睛凸→想不开；无眉→虚伪空壳）、c10（日月角高→父母双全）等面相断法，同属原书案例，此处不逐一展开。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想知道自己/某人的面部特征（痣、纹、凹陷）代表什么
2. 没有生辰、排不了盘，想直接"看相"判断婚姻/财运/近日吉凶
3. 想验证命盘结论（如命盘说婚姻凶，脸上是否印证）
4. 看到某人脸颊/眼角/额头的异常变化（发黑、起纹）想问是否要出事

### 语言信号 (中英双写)

- "我眼角有条纹往下 / 眉毛中间发黑 / 脸上这个痣什么意思"
- "我奸门 / 印堂 / 泪堂 / 天仓 代表什么"
- "帮我看相 / 不看八字只看脸能看出什么 / 最近脸色发灰"
- "face reading / Mian Xiang / what does my shen gong / jian men mean"

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-xingti-fenlei`（形体分类）的区别: **本卡处理宫位/纹路/痣的吉凶**（某宫怎样、某纹朝哪、有无黑斑）；**形体分类处理五形人与三停比例**（木火土金水五形、上中下三停均等与否）。同样"看脸"，一个看"局部标记"，一个看"整体分类"，不重叠
- 与 `tianji-qise-shengsi`（气色生死时限）的区别: **本卡处理结构性标记**（宫位定位、纹路方向、痣斑）；**气色卡处理颜色与时限**（黄润/枯焦/青蓝及"下一节气"窗口）。两者常先后配合：本卡定位 → 气色卡定时限
- 与 `tianji-guanrenshu`（观人术·识小人）的区别: 识小人卡专看眼型异常（四白眼、三角眼、未言先笑）等特征清单；本卡按十二宫逐宫判断
- 与 `tianji-ziwei-pandu`（命盘判读）的区别: 本卡无需排盘、且看"近期"，命盘卡看"一生"；两者互为验证通道

- **⭐ 与 `tianji-xingti-fenlei`（形体分类）的区分（定稿/近邻负例）**：同看一张脸，但问法不同。
  - 问"这颗痣/这条纹/这个宫怎么样"（**点状诊断**）→ 本卡。
  - 问"我是什么形/面型属于哪类/三停比例"（**整体分类**）→ `tianji-xingti-fenlei`。
  - 两者不应同时激活；若用户同时问及，先答宫位诊断再补形体分类。
- **与 `tianji-qise-shengsi`**：本卡看**长期结构**（纹路/痣/形态）；气色卡看**近期时限变化**。
  - ⚠️ **划分（阶段4 修复）**：问「印堂/面部的**颜色、气色、发暗、发黑**」→ 优先 `tianji-qise-shengsi`；
    问「印堂/面部的**纹路、形态、痣**」→ 本卡。例：「印堂发暗是不是不好」→ 气色卡；「印堂有条横纹」→ 本卡。

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①可观察的正脸（照片或面见），②观察目标宫位或用户关注点（不给则全宫扫）。缺清晰面部信息应先索要，不得凭描述猜"某个痣在哪一宫"；宫位难以定位时应先说明定位依据。

**输出契约**：按"部位 → 征象（形/纹/痣/色） → 判断 → 时限（可选）"输出；每条须标注所对应宫位及观察依据，涉及近期凶事须给时间窗口并强制就医免责提示（见 B 段）。

1. **定位十二宫**
   - 完成标准: 依次锁定命宫（印堂）、夫妻宫（奸门）、子女宫（泪堂）、财帛宫（鼻）、官禄宫（中正）、田宅宫（眉眼间）、迁移宫（天仓）、仆役宫（下巴）、父母宫（额头日月角）、兄弟宫（眉毛）
2. **逐宫读形纹**
   - 完成标准: 每宫给出"征象→判断"（如奸门纹向下→生离；纹有叉+黑斑→死别；颧大有肉→权、皮骨相连→孤权）
3. **读气色并判断时限**
   - 完成标准: 若见色变，按四等气色给时限（枯焦=已发生；枯黄≈两周；暗黑=近期；青蓝=死）。**判停点**：若见青蓝色/死神接近征象，停止自行断生死，转 `tianji-qise-shengsi` 并**强制**提示立即就医，不得以面相替代诊断
4. **与命盘/手相互参**
   - 完成标准: 给出至少一条可对照项（夫妻宫↔奸门、兄弟宫↔眉毛、财帛宫↔鼻），标注"命相同参"结论
5. **复述结论**
   - 完成标准: 每条可回溯到"部位+征象"；对反直觉规则（如"眉中有痣不显=草里藏珠兄弟大贵、显露=兄弟夭折"）须明确区分形态

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户想要的是**形体整体分类**（"我属于哪种五形人/三停均不均"）→ 走 `tianji-xingti-fenlei`
- 用户只问脸色/气色随时间的变化与死绝时限 → 走 `tianji-qise-shengsi`
- 用户问的是识人防人的特征清单（三角眼、四白眼）→ 走观人术卡
- 涉及医疗判断（"这痣是不是病变""这块发黑是不是有病"）→ 本卡不做医学诊断

### 与 `tianji-xingti-fenlei`（形体分类）的区分（阶段 4 近邻负例对）

| 维度 | 本卡 tianji-mianxiang | tianji-xingti-fenlei |
|---|---|---|
| 观察对象 | 宫位 / 纹路 / 痣 / 斑 | 五形人形体 / 三停比例 |
| 典型问题 | "奸门纹向下代表什么" | "我是不是土形人 / 三停均不均" |
| 判断单位 | 局部标记（某一宫某一纹） | 整体分类（哪一形、哪一停高矮） |
| 输出 | 该宫吉凶 + 时限 | 先天层次 / 贵贱分类 |
| 反例（不应命中本卡） | "我这体型算木形还是火形" | "我眼角这条纹是啥意思" |

**判定规则**：问题落在"某个具体部位/纹/痣"→本卡；问题落在"整个人属于哪一类/比例" →形体分类卡。

### 作者在书中警告的失败模式

- 单看一处即断（如只看奸门一条纹就断死别）——须多宫互参与命盘互参
- 混淆痣的形态：眉中痣"不显=草里藏珠（大贵）/显露=夭折"，同类征象随形态反转

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **命例全部为倪师自述批命经验，无第三方验证**；面相断语（"此人必丧偶""此人无常"）无法独立核验
- **面相与紫微严格对应的假设未被证明**：为何同命盘者面相各异，原书未解释
- **涉及死亡预判**：原书多处（命门黑=必死、青蓝=死）涉及生死断言，B 段强制声明为文化参考，**不可替代就医，任何身体异常应首先去医院**
- **性别刻板**："女人面大骨粗声沙=死别"等断语带传统性别观，现代语境需过滤
- **紫微详解为民间整理版**，夹带整理者个人玄学内容，与倪师原文风格差异大

### 已知规则缺口（阶段 4 输出评测暴露，如实登记）

- **泪堂（子女宫）只给出“丰满/暗黑”两极，无“凹陷”明文**。原文只列丰满＝子女多、暗黑＝子女有灾；
  遇到“泪堂凹陷”时**不得自行补规则**，应说明“原书未列该征象”，只笼统归为“不够丰隆”并标注依据不足。

### 容易混淆的邻近方法论

- 与 `tianji-qise-shengsi` 区分: 本卡=结构标记（纹/痣/宫位），气色卡=颜色与时限
- 与 `tianji-shouxiang-bagong`（手相八宫）区分: 手相看终身“硬件配置”，本卡看面部“屏幕显示”
