# 庙旺落陷定吉凶规则

## R — 原文 (Reading)

> 「庙、旺、得、利、平、闲、陷。星辰在庙旺为吉，得亮度稍弱于旺，利为小吉，
> 平/闲主无用，陷主凶，殺星在陷大凶。
> 吉处藏凶（吉星丛中煞星落陷）→必凶；凶处藏吉（未落陷的煞星丛中吉星入庙）→平安。」
>
> — 倪海厦《天纪》· 原则 p21（庙旺落陷），源文件 04-紫微斗数笔记 / 05-紫微详解

## I — 方法论骨架 (Interpretation)

紫微斗数里同一颗星，吉凶不是固定的——**亮度决定它的吉凶等级**。亮度分七级，从高到低：

庙 > 旺 > 得 > 利 > 平 > 闲 > 陷

- 庙、旺 → 吉；得 → 比旺弱一点；利 → 小吉；
- 平、闲 → 主「无用」（不好不坏但帮不上忙）；
- 陷 → 主凶；煞星落陷 → 大凶。

本卡真正的价值不在七个字的排序，而在两条**组合法则**，它们优先级高于单星：

1. **吉处藏凶必凶**：一片吉星里如果藏着一颗落陷的煞星 → 整体判凶（一颗陷煞就能翻盘）。
2. **凶处藏吉平安**：煞星丛中，只要煞星「没有落陷」、又有一颗吉星入庙 → 反而平安。

所以判读顺序是：先按亮度给每颗星定吉凶底色 → 再看组合里有没落陷煞星（决定成败）→
最后才回到单星本身的星性（如巨门庙旺=口才好/豪门，落陷=牢狱）。

## A1 — 应用示例 (Application Example)

### 原书未提供庙旺落陷专属命例，以下为合成演练

- **输入 A**: 某宫三颗吉星（文昌、左辅、天钺）同宫，另混入一颗**落陷的擎羊**。
  - **方法的使用**: 先给每颗星定亮度（三吉先按吉处理，擎羊落陷），再套「吉处藏凶」法则。
  - **预期输出**: 判**凶**。理由：吉星丛中存在落陷煞星，触发「吉处藏凶必凶」。
- **输入 B（反向验证）**: 两煞星（擎羊、陀罗）**均未落陷**，中间夹一颗**入庙的吉星**。
  - **预期输出**: 判**平安**。理由：煞未落陷、吉星入庙，触发「凶处藏吉平安」。
- **说明**: 两个演练严格依 p21 两条法则复算，未添加原书未给出的条件；原书未交代对应实例结果，
  故为规则演练而非命例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 问「庙旺落陷怎么看」「这颗星亮不亮」等概念性问题
2. 给出某宫星曜组合，问「这是吉是凶」「为什么吉星多还是不好」
3. 遇到「明明有吉星却说凶」的困惑（正是吉处藏凶法则的场景）
4. 判读任何星曜/格局时，需要先过一层「亮度筛」

### 语言信号（中英双写）

- 中文：「庙旺落陷」「亮度怎么看」「吉处藏凶」「入庙/落陷什么意思」「星亮不亮」
- 英文：`brightness of stars` / `temple vs fallen` / `miao wang luo xian` / `is this star strong`

### 与相邻 skill 的区分（初稿）

- 与 `tianji-shisi-zhuxing`（十四主星）的区别：本卡只给「亮度→吉凶」这一层，
  主星卡给「这颗星是谁、管什么」；两者必须先本卡（定亮度）再主星卡（定星性）。
- 与 `tianji-liushaxing`（六煞星）的区别：本卡提供亮度打分，煞星卡按类别判凶象方向。
- 与 `tianji-ziwei-pandu`（三方四正流程）的区别：本卡是其流程内部的「第一层过滤」，
  由判读流程调用，通常不单独起头。

## E — 可执行步骤 (Execution)

**输入契约**
- 必需：待判星曜列表 + 每颗星的亮度级别（庙/旺/得/利/平/闲/陷）+ 每颗星类别（吉星/煞星/主星）。
- 缺失亮度时 → 先查星曜亮度表或先排盘，**不得猜到「大概旺」**。
- 适用条件：任何单宫吉凶定级场景。

1. **逐星标底色** — 按七级谱给每颗星标吉凶底色。
   - 完成标准：庙旺=吉；得=次吉；利=小吉；平/闲=无用；陷=凶；煞星落陷=大凶。
2. **扫描落陷煞星** — 检查组合内是否存在落陷的煞星。
   - 判停点：**若存在落陷煞星** → 直接判「凶」（吉处藏凶必凶），跳至第 4 步。
3. **反向检查凶处藏吉** — 若无落陷煞星，检查煞星丛中是否有入庙吉星。
   - 完成标准：煞星均未落陷 + 有入庙吉星 → 判「平安」；否则按第 1 步底色综合。
4. **回填单星星性** — 用主星星性修正结论（如巨门庙旺=口才好，落陷=牢狱）。
   - 完成标准：输出「整体吉凶 + 主导原因 + 单星修正」。

**输出契约**
- 结论结构化：`整体吉凶（吉/次吉/小吉/无用/凶/大凶）→ 触发法则（吉处藏凶 / 凶处藏吉 / 常规）→ 依据星曜`。
- 七级谱排序为原书明列，不得自行增删级别；「无用」为原文对平/闲的定性，照原文使用。
- 完成标准：每个结论都能指回亮度谱或两条组合法则之一。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 尚未排盘、没有任何亮度信息时。
- 用户问的是格局整体成败（走 `tianji-ziwei-geju`）或六亲（走 `tianji-liuqin-gong`）——本卡只是其中一层筛。
- 需要精确时间预测时（走 `tianji-dayun-liunian`）。

### 失败模式（原书警告）
- 只看单星亮度、忽略组合有落陷煞星 → 违反「吉处藏凶必凶」，误判为吉。
- 反过来只看煞星数量、忽略「未落陷」这一前提，把本应平安的局判成大凶。

### 作者盲点 / 时代局限
- 七级谱中「得/利/平/闲」的边界在原文中未给量化定义，实操依赖经验，存在主观空间。
- 亮度为静态判定，不能替代对四化（科权禄忌）这一「驱动力」的考量。

### 邻近方法论
- `tianji-shisi-zhuxing`（星性，本卡的下游）；`tianji-liushaxing`（煞星方向）；
  `tianji-sihua`（四化驱动力，优先级高于亮度）；`tianji-ziwei-pandu`（调用本卡的流程）。
