# 命例集：吉格成格

## R — 原文 (Reading)

> "此命是民国83年正月十九巳时生人，阳女。紫微在巳宫→巨门+太阳庙旺为'巨日同格'，腰缠黄金穿紫衣，大富巨富，富可敌国。……武曲贪狼在丑→女命为正格，女中豪杰。"
>
> — 05-紫微详解.md（c06，单元 u24）

> "此命是民国58年三月初二巳时生人，阴男。紫微在午宫→太阳在卯(日照雷门)，太阴在亥(月朗天门)。……明珠出海格（命宫在未→左右日月并明）。……大限32-41在卯见太阳→日照雷明格，大旺大发。"
>
> — 05-紫微详解.md（c07，单元 u24）

## I — 方法论骨架 (Interpretation)

这一组命例是**吉格成格类**的原书实证锚点，覆盖明珠出海、巨日、英星入庙、日丽中天等富/贵格。断法链条固定：
① **认格**——先按结构锁定格局名：巨日同格（太阳巨门皆庙旺）、明珠出海/日月并明（太阳太阴左右同亮，24 小时都明）、日照雷门（太阳在卯入庙）、月朗天门（太阴在亥入庙）、日丽中天（太阳在午）、水澄桂萼（太阴在子）、紫府同宫、七杀朝斗、英星入庙等。
② **验庙旺前提**——吉格全部依赖**庙旺**：如巨日同格须"太阳巨门皆庙旺"才主大富；贪狼在子为旺（武官星带桃花）、在亥为陷（泛水桃花主杀）。
③ **断富贵层次**——巨日＝大富巨富；日丽中天＝十年成格（人生精华段）；紫府/七杀朝斗＝爵禄荣昌；明珠出海＝一世英明、左右逢源。
④ **看落点与大限**——同一格局落不同宫、不同大限结论不同（如巨日格在命＝天生豪门、在父母宫＝继承祖业）；并注意原文的"格局非绝对"提醒（须合看伤使与化忌）。
本卡用法：**当你判出吉格，回这几例对齐断法链条与庙旺前提**，避免把落陷误判成大富。

### 命例 c06: 民国83年正月十九巳时·女命（巨日同格＋日月并明）
- **命盘结构**: 紫微在巳→巨门+太阳庙旺＝巨日同格；太阴在子＝水澄桂萼；日月并明（明珠出海）；武曲贪狼在丑；廉破+右弼孤星在戌
- **断法执行**: 巨日同格（皆庙旺）→ 大富巨富、富可敌国；太阴在子→水澄桂萼（清明、清官）；武贪在丑→女命为正格（女中豪杰）
- **结论**: 大富巨富、女中豪杰、一世荣华
- **结果**: 原文以断法形式给出；具体实际结局原文未说明

### 命例 c07: 民国58年三月初二巳时·男命（月朗天门＋明珠出海）
- **命盘结构**: 紫微在午→太阳在卯（日照雷门）、太阴在亥（月朗天门）；命宫在亥或未；贪狼在子（旺）或在亥（陷）；大限 32-41 在卯见太阳
- **断法执行**: 月朗天门格→清秀聪慧；明珠出海格→24 小时光明、随时识小人；贪狼在子（旺）＝武官星带桃花、在亥（陷）＝泛水桃花；大限 32-41 日照雷明格→正官带、白天上班大旺
- **结论**: 一世荣华、左右逢源；大限 32-41 大旺大发（若上夜班则反背）
- **结果**: 原文以断法形式给出；具体实际结局原文未说明

### 命例 c10: 民国40年十一月十五申时·男命（紫府同宫＋七杀朝斗）
- **命盘结构**: 紫微天府同在申＝紫府坐垣；七杀在寅＝七杀朝斗；破军在午＝英星入庙；太阳在巳+巨门在亥＝巨日格；日月并明（太阳巳+太阴酉）
- **断法执行**: 紫府同宫+七杀朝斗+英星入庙 → 爵禄荣昌；日月并明→一世英明；巨日格若在命宫→生下来就是豪门宅地、在父母宫→继承祖业；面相日月角高→父母双全
- **结论**: 爵禄荣昌、男人发武官威镇边疆
- **结果**: 原文注（紫易奇缘）：名嘴周某波、林青霞父亲（军医）均未死于兵祸 → 格局非绝对，需看伤使与化三忌

### 命例 c12: 民国41年九月二十八丑时·女命（紫贪武官＋日丽中天）
- **命盘结构**: 紫微贪狼在酉（女身男命）+化权（强度×2）；夫妻宫天府；大限 35-44 在午＝日丽中天；巨门在戌+太阳在午入庙
- **断法执行**: 紫贪（武官星）＋化权 → 男人婆、刚强加倍；大限在午日丽中天→十年成格（人生精华期）；巨日会命（命在寅）→主大财
- **结论**: 十年成格、人生精华段；女命在军中文职/技术兵种
- **结果**: 原文记"28 岁结婚→30 岁文昌化忌→丈夫离家出走"；无第三方验证

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①完整命盘（十二宫＋主星＋四化＋大限；含生辰性别阴阳），②问题焦点（格局/大限/富贵层次）。缺命盘先要生辰；**不得凭格局名就断富贵，须先验庙旺**。

**输出契约**：按"认格 → 验庙旺前提 → 断层次（c06/c07/c10/c12 对齐） → 落点宫位 → 大限 → 备注（非绝对）"输出；每条须标注所对齐命例编号与出处。

1. **认格**
   - 完成标准: 按结构锁定格局名（巨日/明珠出海/日照雷门/月朗天门/日丽中天/水澄桂萼/紫府/七杀朝斗/英星入庙）
2. **验庙旺前提**
   - 完成标准: 逐格检查"皆庙旺"等条件；落陷者改判（如巨日落陷→偏房/表里不一；贪狼在亥陷→泛水桃花）
3. **对齐命例断层次**
   - 完成标准: 匹配 c06/c07/c10/c12 中最接近者，写出富贵层次（大富/爵禄荣昌/十年成格/一世荣华）
4. **看落点与大限**
   - 完成标准: 说明同格落在不同宫/大限的差异（命宫 vs 父母宫；大限 32-41 vs 35-44）
5. **加"非绝对"备注**
   - 完成标准: 按 c10 原注提示合看伤使与化忌；不把吉格绝对化为必然结果
   - 判停点: 若关键星曜庙旺信息缺失 → 标"待补庙旺信息"，不硬断富贵

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是**日月反背/六亲不靠** → 走 `tianji-mingli-riyue`
- 用户问的是**杀破狼丧偶/改运/六亲生肖推算** → 走 `tianji-mingli-xiongge`
- 用户要的是**通用批命流程**（总格→六亲→流年）→ 走 `tianji-ziwei-pandu`
- 用户把吉格当"必然大富"认命 → 按 c10 原注提示"格局非绝对"，须合看伤使与化忌

### 作者在书中警告的失败模式

- **忽略庙旺前提**：巨日同格须"皆庙旺"才主大富，落陷则反（偏房/表里不一）
- **把吉格绝对化**：原书自注（c10）名嘴周某波、林青霞父亲均未死于兵祸 → 格局非绝对，须看伤使与化三忌
- **同格不同断**：同一格局落不同宫（命宫 vs 父母宫）、不同大限，结论不同，不可一概而论

### 作者的盲点 / 时代局限

- **命例全为作者自述批命**，无第三方验证；c10 原注已承认对格局"分析过重"
- **吉格断语（大富/富贵）不可独立核验**，且不涉及概率与分布
- 部分内容含**性别刻板**（"男人婆""女中豪杰"等），现代语境应过滤
- **紫微详解为民间整理版**，夹带整理者内容（如 c10 的紫易奇缘注），与倪师原文有差异

### 容易混淆的邻近方法论

- 与 `tianji-mingli-riyue` 区分: 本卡=成格（吉），日月卡=反背（凶）
- 与 `tianji-mingli-xiongge` 区分: 本卡=富贵吉格，凶格卡=丧偶/改运/推算
