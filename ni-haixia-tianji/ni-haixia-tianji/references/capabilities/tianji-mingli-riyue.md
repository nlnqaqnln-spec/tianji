# 命例集：日月反背与六亲不靠

## R — 原文 (Reading)

> "日月反背（白天月亮/夜间太阳为陷）：1.工作披星戴月，晚上比白天忙；2.六亲不靠；3.性情非常刚燥；4.一般都要离开家乡去外地发展，让父母担心——克父母。"
>
> — 04-紫微斗数笔记 / 05-紫微详解（p17，单元 u13/u23）

> "此命是民国54年十月二十八辰时生人，阴男。紫微星在丑宫、命宫在未宫。……夫妻宫廉贞+贪狼落陷→'半空折翅格'，30岁左右婚姻大凶。"
>
> — 05-紫微详解.md（c02，单元 u23）

## I — 方法论骨架 (Interpretation)

这一组命例是"日月反背"类断法的**原书实证锚点**。日月反背＝太阳、太阴皆落陷（紫微在丑必日月反背），断法链条固定：
① **见结构**——先查太阳、太阴是否同时落陷（或"日月反背夹命"：太阳太阴落陷夹在命宫两侧）。
② **落四断**——披星戴月（夜比日忙）、六亲不靠、性情刚燥、离乡克父母。
③ **加成验证**——常与"太阴化忌冲子女宫→无子""对宫化忌冲命→半空折翅"叠加，于是断"无子＋婚姻完蛋＋父母凶"。
④ **化解**——找出凶格后走 u15 化忌化解法（心念/地理改位/象层先应）；婚姻凶者按 u22 择"八字不合"对象。
本卡的用法：**当你判某盘为日月反背类，回这几例对齐断法链条**，保证"六亲不靠/父母凶/婚姻凶"的结论有原书实证支撑，而不是凭空推。

### 命例 c01: 民国50年三月初五戌时·女命（日月反背夹命）
- **命盘结构**: 贪狼在午入命（武官格）、紫微在子对宫；官禄宫七杀+擎羊无化权；财帛宫天钺+化科；夫妻宫廉贞+天府（无科权禄）
- **断法执行**: 日月反背 → 离祖外出、克父母；福德宫 34-43 岁太阳化忌 → 丈夫有劫（寡宿星）
- **结论**: 官无实权、靠一技之长漂泊；夫妻为工薪族、无子；丈夫大劫
- **化解**: 厕所不在房正中、厨房不在西北角可缓"死夫"之劫
- **结果**: 原文以断法形式给出；具体实际结局原文未说明

### 命例 c02: 民国54年十月二十八辰时·男命（半空折翅＋日月反背）
- **命盘结构**: 天相在未守命（佐才、位高无权）；夫妻宫廉贞+贪狼落陷；子女宫太阴化忌+日月反背
- **断法执行**: 廉贞+贪狼落陷＝半空折翅格、中年限 30 岁夭折象；日月反背+太阴化忌 → 无子、六亲不靠、父母凶；大限 33-42 未来十年无大运
- **结论**: 23-32 婚姻大凶、33-42 无子且婚姻完蛋
- **化解**: 娶二婚妻／娶大七岁或小七岁之妻／阳宅调整；先天婚凶者找"八字不合"者
- **结果**: 原文记"流年 32 岁妻子自杀"；未提供第三方验证

### 命例 c03: 民国8年七月十三子时·男命（七杀朝斗＋日月反背）
- **命盘结构**: 紫微在寅、天府同寅，七杀对宫；紫府朝垣+七杀朝斗+天乙拱命，双煞夹命；日月反背（太阳陷亥、太阴陷卯）
- **断法执行**: 日月反背 → 父母凶、父先丧；福德宫武曲入庙 → 个性刚强、武职大利；子女宫巨门+天马 → 车祸+官司
- **结论**: 日月不见光；34 岁流年与小限重叠、武贪格发财经机会 → 投资失败；丈夫（太阳化忌+伤使夹命）服毒自杀
- **结果**: 原文交代了投资失败与自杀结局；无第三方验证

### 命例 c04: 民国44年三月初五·男命（日月反背夹命）
- **命盘结构**: 紫微在卯、命宫在申；天梁在午入庙（武官一品）；日月反背夹命（太阳陷子、太阴陷寅）；右弼独守酉（孤星）；廉贞庙+七杀旺在未；太阴化忌在对宫冲命
- **断法执行**: 日月反背夹命 → 一世辛劳；孤星独守 → 孤单；太阴化忌冲命 → 半空折翅（30 岁左右先天绝症/大灾）
- **结论**: 武官命但一生辛劳孤单；30 岁左右大灾
- **结果**: 原文以规则形式给出；具体结局原文未说明

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①完整命盘（十二宫＋主星＋四化；最好含生辰与性别阴阳），②问题焦点（婚姻/六亲/大限）。缺命盘时应先要生辰或已排好的盘；**不得凭单一句"日月反背"就出结论，须见完整结构**。

**输出契约**：按"结构识别 → 对齐命例（c01/c02/c03/c04） → 断法链条 → 结论 → 化解"输出；每条结论须标注所对齐的命例编号与出处。

1. **识别日月反背结构**
   - 完成标准: 确认太阳、太阴是否同时落陷（或反背夹命）；记录位置与对应宫
2. **对齐命例**
   - 完成标准: 按结构匹配 c01/c02/c03/c04 中最接近者，写出对齐理由
3. **复现断法链条**
   - 完成标准: 依次输出"披星戴月 / 六亲不靠 / 性刚 / 离乡克父母"四断，并按盘补"无子/半空折翅/寡宿"等叠加项
4. **定位大限**
   - 完成标准: 指出大限所在年龄段（如 34-43 太阳化忌），说明触发条件
5. **给化解**
   - 完成标准: 按 u15/u22 给心念/地理/择偶至少两条可执行动作
   - 判停点: 若命盘信息不足以定位大限 → 标"待补生辰/大限信息"，不硬推

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是**吉格成格**（明珠出海/巨日/日丽中天）→ 走 `tianji-mingli-jige`
- 用户问的是**杀破狼丧偶/六亲生肖推算** → 走 `tianji-mingli-xiongge`
- 用户没有命盘、只想问某个单项判法 → 走对应的规则卡（`tianji-sihua` / `tianji-qise-shengsi` 等）
- 用户把命例当"必然结局"来认命 → 按 u01 以果决行原则纠正：命例是断法示范，不是宿命宣判

### 作者在书中警告的失败模式

- 只看"日月反背"四字就下结论，忽略与之叠加的化忌、大限、阳宅（原书每例都是"结构＋大限＋化解"合看）
- 把命例结局当普遍规律（"日月反背一定丧夫"）——原书为个案自述，不构成统计

### 作者的盲点 / 时代局限

- **命例全为作者自述批命**，无第三方验证；同盘者结局各异，原书未解释
- **部分断语带性别刻板**（女命"无夫无子""死夫"），现代语境应过滤
- **涉及死亡/疾病内容**（绝症、自杀、丧夫）属文化记录，不可作确定性断言，健康问题应就医
- **紫微详解为民间整理版**，夹带整理者内容，与倪师原文风格有差异

### 容易混淆的邻近方法论

- 与 `tianji-mingli-jige` 区分: 本卡=反背/不靠（凶向），吉格卡=成格（吉向）
- 与 `tianji-mingli-xiongge` 区分: 本卡=日月反背＋六亲不靠，凶格卡=杀破狼丧偶＋改运＋生肖推算
