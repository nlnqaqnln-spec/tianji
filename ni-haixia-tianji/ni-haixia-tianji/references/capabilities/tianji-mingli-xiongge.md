# 命例集：凶格与六亲推算

> "此命是民国46年十一月十五日午时生人，阴女。破军在午入命=英星入庙格(杀破狼格)，男命发武官，女命主孤单孤僻。隔角煞→离婚象。……33岁丧夫(太阳被巨门化忌冲)。44岁再婚……51岁再次丧夫。"

## I — 方法论骨架 (Interpretation)

这一组命例是**凶格与六亲推算类**的原书实证锚点，覆盖杀破狼丧偶、改运实例、六亲生肖推算。断法链条：
① **认凶格**——破军在午入命＝英星入庙格（杀破狼），男发武官、**女命孤单孤僻**；隔角煞（命宫与夫妻宫"转个弯"）＝离婚象。
② **叠四化断凶事**——如巨门化忌冲太阳 → 丧夫；文昌化忌入福德 → 配偶出走；从结婚到死"七年一轮"。
③ **配阳宅印证**——西北角厕所缺失＝缺丈夫位；儿子睡正西→雷泽归妹卦＝男身女态；大限投资合伙 → 鸡飞蛋打。
④ **改运（c11）**——命带凶时用阳宅名位调整（睡客厅成东宫、父母住西北、父住东北）＋心念改变化解。
⑤ **六亲生肖推算（c13）**——用宫干四化与化忌对冲宫推父母/配偶生肖：三合宫干定生年干、化忌对冲宫定生肖地支、四库/四马之地取位。
⚠️ **来源风险**：c13 明属"整理者扩展，非倪师原书内容"，本卡如实标注，不冒充原文。

### 命例 c09: 民国46年十一月十五午时·女命（杀破狼格＋两次丧夫）
- **命盘结构**: 破军在午入命＝英星入庙格（杀破狼）；隔角煞（命宫午、夫妻辰）；3 岁巨门化忌冲父母宫；33 岁太阳被巨门化忌冲；44 岁迁移宫天喜；51 岁巳宫太阳被冲
- **断法执行**: 英星入庙女命→孤单孤僻；隔角煞→离婚象；巨门化忌冲太阳→丧夫（七年一轮）
- **结论**: 两次丧夫（33 岁首丧、44 岁再婚、51 岁再丧）；52-61 投资合伙鸡飞蛋打
- **阳宅印证**: 西北角厕所缺失丈夫位；儿子睡正西→雷泽归妹卦（男身女态）
- **结果**: 原文交代两次丧夫与再婚年份；无第三方验证

### 命例 c11: 案例第十五例·男命（改运实例）
- **命盘结构**: 紫微天相在辰入命（权科入命）；身宫在财帛化忌；大限 16-25 天梁化禄；33 岁小限在子化忌；住西北角乾位＝雷天大壮卦
- **断法执行**: 权科入命→读书好、宜公务；身宫财帛化忌→当不成老板；财星过早→未成熟接祖业；雷天大壮（未婚住父位）→心理年龄大于实际、喜年长妻
- **结论**: 命中带科但官运财路受限；居位影响婚配偏好
- **改运**: 睡客厅成东宫太子；父母住西北角；父住东北（山天大畜卦）
- **结果**: 原文以断法与化解形式给出；具体实际结局原文未说明

### 命例 c13: 1969 年破军命·男命（六亲生肖推算）
- **命盘结构**: 破军天哭守命、身宫迁移（命身对宫加强）；父母宫天同+右弼（三次者）→父亲二次婚姻；兄弟宫无主星→家中唯一男孩、母亲短寿；夫妻宫庚→太阴化忌在丑
- **断法执行**: 父母宫干癸四化（癸破巨阴贪）→破军化禄在戌＝父亲生肖狗（丙戌 1946）；兄弟宫干辛→巨门化禄在亥＝母亲生肖猪（丁亥 1947）；夫妻宫干庚（庚阳武同阴）→太阴化忌在丑＝妻子生肖羊（丁未 1967，大三岁）
- **结论**: 推出父（狗）、母（猪）、妻（羊）三人生肖及生年
- **来源**: 原文注明"非倪师原书内容，为整理者扩展"
- **结果**: 原文以推算步骤形式给出；无独立验证

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是**日月反背/六亲不靠** → 走 `tianji-mingli-riyue`
- 用户问的是**吉格成格** → 走 `tianji-mingli-jige`
- 用户要的是**六亲宫的通用判断规则** → 走 `tianji-liuqin-gong`
- 用户把"丧偶""孤单"当必然结局 → 按 u01 以果决行纠正，须走化解而非认命

### 作者在书中警告的失败模式

- **单看格局名定凶事**：破军女命主孤，须叠四化（巨门化忌冲太阳）与大限才落"丧夫"，不可只凭格局
- **生肖推算当原文**：c13 明属整理者扩展，须与倪师原文分开，不得冒充原书内容
- **忽略阳宅印证**：凶事须命、运（大限）、阳宅三者合看，单点不成立

### 作者的盲点 / 时代局限

- **命例全为作者自述批命**，无第三方验证；c13 推算方法来源存疑（整理者扩展）
- **断语带性别刻板**（"女命孤单孤僻""两次丧夫"），现代语境应过滤
- **涉及死亡/疾病内容**（丧夫、短寿）属文化记录，不可作确定性断言，健康问题应就医
- **紫微详解为民间整理版**，夹带整理者内容，与倪师原文有差异

### 容易混淆的邻近方法论

- 与 `tianji-mingli-jige` 区分: 本卡=凶格（丧偶/孤单），吉格卡=成格（富贵）
- 与 `tianji-mingli-riyue` 区分: 本卡=杀破狼+推算，日月卡=日月反背+六亲不靠
- 与 `tianji-liuqin-gong` 区分: 六亲宫卡=规则，本卡=命例＋（参考性）推算法
