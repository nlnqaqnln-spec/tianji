# 身宫判断与化忌化解法

## R — 原文 (Reading)

> "身宫主后天：在财帛→私企或自己做老板；在官禄→做官；在迁移→外地发展；身命同宫→先天后天都一样；在夫妻宫→后天被婚姻影响很大；女性身宫在财帛→一定要做职业妇女。"
>
> — 《天纪》04-紫微斗数笔记 / 05-紫微详解 身宫段（p43）

> "化忌的灾戒在戒慎。""做事开始时要有戒心——戒之初；运势巅峰时也要有戒心——戒之盛。""化忌冲命化解：过继给别人养（二姓一生）。""过忌成婚最好。"
>
> — 同上 化忌化解法段（g17）

## I — 方法论骨架 (Interpretation)

本卡把两件相关的事合在一起：**身宫判断（后天往哪走）+ 化忌化解（有凶怎么解）**。骨架如下：

- **身宫＝后天**。命宫管先天，身宫管后天走向。身宫落哪个宫，说明"这个人后天的人生重心会不由自主地偏到那个领域"：在财帛→做老板/经商；在官禄→从政；在迁移→外地发展；在夫妻→被婚姻主导；身命同宫→先天后天一致。有一条硬断语：**女性身宫在财帛→必须做职业妇女**（纯家庭主妇不利）。
- **化解的本质是"改念"，不是"消灾"**。这是倪海厦反复强调、也最易被误解的一点：化解**不靠符咒、买玉、放鱼缸**。化忌不可能被消除，只能被"处理"。
- **化忌化解分三层**（本卡的执行核心）：
  1. **心念层（戒之初 / 戒之盛）**——事情开始时心存戒惧（防微杜渐），运势到顶峰时更要戒惧（防盛极而衰）。原书说"如果在见到气色后第一个节气保持戒慎，再大的灾都可以解"。
  2. **地理层**——改阳宅方位、床位方向（与 `tianji-yangzhai-mingwei` 联动）。
  3. **象层（让灾象先发生）**——提前释放化忌的破坏力，在可控范围内"让象先出现"。化忌冲命的招牌化解是"过继二姓一生""过继成婚"。
- **判别顺序**：先定先天（命宫/四化）→ 再看身宫定后天重心 → 若有化忌，按心念→地理→象三层给化解动作。

## A1 — 应用示例 (Application Example)

### 案例 1: 男命身宫在财帛化忌（c11，reported_case，来源 05-紫微详解.md）
- **出处 / 输入**: 紫微天相在辰入命（权科入命），阳男（案例分析第 6 例）。
- **方法怎么执行**: 身宫在财帛 → 判"后天在私企或自己当老板"；但该宫**化忌** → 修正为"当不成老板，只能打工领固定薪水"；大限 16-25 天梁化禄（财星过早）→ 未成熟就接祖业、学业中断；33 岁小限在子化忌→诸事不顺。
- **结论**: 身宫指示后天方向（经商），但化忌改变了结果（当不成老板）。
- **结果**: 原文以"心想不成、诸事不顺"断；**未说明**后续验证。

### 案例 2: 女命以改运化解自杀格（c08，reported_case，来源 05-紫微详解.md）
- **出处 / 输入**: 廉贞贪狼落陷自杀格女命，同时并存日月并明格（一世荣华）。
- **方法怎么执行**: 命盘同时含自杀格（大凶）与日月并明格（一世荣华）→ 走"改运"路径。
- **结论**: 关键教义是"做人要做听明（听劝）之人，一念之间最凶的格可变最好"。
- **化解（原书三层）**: ①启蒙之道（心念，想开）；②阳宅改后天的运（地理，让念改变）。
- **结果**: 原文以"改运"结论；**未说明**独立第三方验证。

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①命宫与**身宫**所在宫位（缺身宫需先排出）；②化忌所在宫（生年化忌落宫）及其对面是否为命宫（判"化忌冲命"）；③可选：大限/流年化忌位置、可用阳宅信息。缺身宫落宫时不得凭空推后天。

**输出契约**：结构化结论，含①身宫落宫→后天重心判断（含"女性身宫在财帛→必做职业妇女"等硬断语）、②化忌位置性质（是否冲命）、③三层化解动作（心念/地理/象，逐层给可执行项）。每条须标注依据。

1. **定身宫、判后天方向**
   - 完成标准: 指出身宫在何宫，输出对应后天重心（财帛→经商/老板；官禄→从政；迁移→外地；夫妻→婚姻主导；身命同宫→先天后天一致）。
2. **定位化忌、判是否冲命**
   - 完成标准: 指出化忌落宫；若化忌在命宫对宫（迁移宫）→ 判"化忌冲命"；列出受影响的宫位。
3. **给心念层化解（戒之初 / 戒之盛）**
   - 完成标准: 输出两条戒惧动作——起事时戒惧（戒之初）、运盛时戒惧（戒之盛）；提示"戒慎本身即化解"。
4. **给地理层化解（判停）**
   - 完成标准: 给出"改阳宅方位 / 床位方向"动作；**判停点**：若缺可用阳宅信息（不知房屋格局），停在地理层提示，转 `tianji-yangzhai-mingwei` 做方位判定，不得凭空指定方位。
5. **给象层化解并合成**
   - 完成标准: 若为"化忌冲命"，输出原书招牌化解（过继二姓一生 / 过继成婚 / 象层先应）；明确声明化解**不靠符咒、买玉、鱼缸**；三层动作合并输出。

## B — 边界 (Boundary) ★

> **本卡属命理/化解内容，仅供文化参考，不构成事实判断。**

### 不要在以下情况使用此 skill

- 用户只问"命能不能改"这种总纲问题——走 `tianji-sancai-yiguo`。
- 缺身宫或缺化忌位置——先补齐再判。
- 用户期待"花钱买化解物"——应明确纠正，本卡不给此类建议。

### 作者在书中警告的失败模式

- **把化解理解成消灾 / 迷信手段**——原书最重的警告：**化解靠改位 / 改念，不靠符咒、不靠购买风水物品**（不画符念咒、不买玉、不放鱼缸），而在"地理位置的改变 + 人间道意念的改变"。
- 以为化忌可被"消除"——化忌只能被处理（改念/改位/让象先应），不可能凭空消失。
- 只做地理层、不做心念层——原书强调"戒慎"是核心，改位不改念无效。

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **"过继二姓一生""过继成婚"预设宗族结构**：现代社会可行性受限，原书未给现代替代方案——原文未展开。
- **"象层先应"（让灾象先发生）具体操作模糊**：原书以"办头七"等个例示意，缺通用可执行标准——原文未展开；且此类操作若被误解可能诱导危险行为，须严格限定为"象征性、安全化"的处理。
- **可证伪性弱**：化解后若无灾，可归因"戒慎起作用"；若有灾，可归因"戒慎不够"——体系难以证伪。
- **性别断语偏传统**："女性身宫在财帛→必须做职业妇女"带特定时代家庭角色假设，现代需按个体情况过滤。

### 容易混淆的邻近方法论

- 与 `tianji-sancai-yiguo` 区分: 三才卡答"能不能改"，本卡答"具体怎么改"。
- 与 `tianji-yangzhai-mingwei` 区分: 名位卡做方位判定，本卡调用其结果为地理层化解。
