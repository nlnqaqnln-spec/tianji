# 紫微十二宫逐宫可论断事项清单

## R — 原文 (Reading)

> 「十二宫（顺时针排列）：命宫、父母宫、福德宫、田宅宫、官禄宫、朋友宫（仆役宫）、
> 迁移宫、疾厄宫、财帛宫、子女宫、夫妻宫、兄弟宫。」
>
> 「批八字先定三方四正、看他的本宫。……看每个宫都要看三方四正，看有什么星会到，
> 作出综合的批断。」
>
> 「看一个宫如果杀星和吉星同会，杀星的力量会大大降低，如果只有杀星没有吉星，
> 即使是一个小小的杀星也可能会要人性命。」
>
> — 倪海厦《天纪》05-紫微详解：第6-12页（第一章）、第52-100页（第五章·紫微十二宫详解命例）

补充原文总纲（同源第6页）：
后天命格定位：财帛宫→私企从商；官禄宫→公家从政；迁移宫→外出发展。
三方四正：命宫←→财帛宫←→迁移宫←→官禄宫。
宫性批流年：流年在哪个宫，这一年重要事就在该宫领域。

**总原则（散布于各命例中）**：
- 以宫论星的宫性为**第一层过滤**：同一颗星落在不同宫，论断完全不同。
  例如武曲在官禄宫=武职掌权；武曲在财帛宫=财星；武曲在父母宫=父母为武贵。
- **单星独守且无吉星会到 → 大凶**。
- 六亲宫（兄弟/父母/子女/夫妻）单看紫微斗数「不太精准」，**面相验证优先**。

## I — 方法论骨架 (Interpretation)

本卡为 `cap.tianji.ziwei-pandu`（三方四正判读流程）的配套附件，用于**逐宫展开**具体事项判读。

判读流程：
1. 先定四宫框架（命/财/官/迁的三方四正）→ 定人生大方向（打工/经商/从政/外出）
2. 再参照本卡，逐宫展开每个宫「具体可以判断什么」→ 帮助判读者不漏项
3. 六亲宫（兄弟/父母/子女/夫妻）可判断的条目较多，但本身「不太精准」，需面相或阳宅交叉验证

**本卡的核心价值**：把「十二宫」从抽象概念（如"夫妻宫看婚姻"）细化为可操作的判读条目（如"配偶是否死亡=看廉贞组合、太阳化忌+大限冲对宫"）。

## 逐宫清单

### 一、命宫
- **先天命格**：长相、个性、行为模式、一生成败的总轮廓
- **先天富命**：命宫全是财星 → 家财丰厚，生下来就富
- **有无科/权/禄**：命宫无科权禄 = 正才（一辈子打工领固定薪水）；化科 = 有专长才艺（音乐家/画家）；化权 = 天生领导之才；化禄 = 祖业丰厚
- **命宫辅弼配置**：紫微独守无辅弼 → 性情孤独（或为僧道）；左辅/右弼/三台/八座独守 → 生下来就是佐才（助理/参谋/副手）
- **面相验证**：命宫=印堂（悬针/凹陷/黑痣=命中有缺陷）

### 二、兄弟宫
- **有无兄弟**：太阴落陷 = 无兄弟；或兄弟夭折
- **兄弟关系**：化忌 + 凶星 = 兄弟不和（面相：眉毛左叉右叉杂乱）
- **兄弟夭折**：杀星孤守 → 兄弟夭折（面相：左眉断=兄弟夭折，右眉断=姐妹夭折）
- **合伙财运**：与兄弟合伙能否成功/破财（与朋友宫判断逻辑类似：吉星多=合伙大吉；杀星多=合伙必败）
- **兄弟富贵程度**：看兄弟宫星性 → 武曲入兄弟宫 = 兄弟为武贵

### 三、父母宫
- **生身父母**：日月反背 → 克父母（感情好才「克」得到，心甘情愿付出但对对方并无好结果）；黯淡无光 → 庶出/螟蛉子（养子，需注意不说破，因本人可能不知真实身世）
- **父母是否有财**：化禄 → 有祖产财禄供子女花用；巨日格 → 父母有钱、祖业大
- **父母职业**：武曲+破军+化科+化权 → 父母为武将且文笔好（能文能武）
- **父母吉凶**：日月角（面相，左日角=父右月角=母）下陷=已亡，黑黑暗暗=重病；太阳化忌 → 父亲有灾；太阴化忌 → 母亲有灾
- **与父母感情**：巨门星 = 口舌争执；天同星 = 感情很好

### 四、夫妻宫
- **配偶性格**：看夫妻宫主星星性（廉贞/天府=温和正派；天相=温和能忍；巨门=口舌争执）
- **婚姻品质**：**必须合福德宫一起看**——夫妻宫好但福德宫差 → 夫妻关系不会好、不能长久
- **生离死别**（廉贞组合的三种致命格）：廉贞+七杀 → 半路死亡/路上出现意外（「半路埋尸」）；廉贞+破军 → 水中作冢/河海遇难；廉贞+贪狼 → 横夭/先天疾病/自杀/遗传病/抑郁症
- **配偶职业类别**：「以宫论星」——同星在夫妻宫即配偶为该职业方向。武曲入夫妻宫 → 配偶从事武职（军人/警察/法院）
- **配偶贵贱**：红鸾入男命 → 必招美妻；红鸾入女命 → 必有贵夫
- **二婚/离婚**：左辅/右弼/三台/八座独守夫妻宫 → 二婚命（一定会离婚）；女命夫妻宫太阳落陷 → 配二婚夫或嫁大七岁以上者
- **婚期判断**：红鸾/天喜相会=喜庆成婚；流年走到某宫皆可能结婚（走到夫妻宫=直接因缘；走到父母宫=父母之命媒妁之言；走到财帛宫=生意往来互生情愫）
- **配偶健康状况**：眼角黑黑暗暗=重病或大凶（将发生未发生之时，大限到了）；流年化忌冲夫妻宫=配偶有灾
- **二婚与八字合婚原则**：先天夫妻宫婚凶者（半空折翅/巨门化忌等），反而不宜找「八字合」的人结婚；应找「八字不合」者，或以二婚妻/大七岁妻化解
- **面相验证**：面部夫妻宫（眼角/奸门）：一条纹向下=妻不贤/生离；二三条上翘=妻贤/夫妻和睦；十字纹=十年不好；多条鱼尾纹=桃花

### 五、子女宫
- **有无儿子**：子女宫空宫 → 看对宫：对宫有太阳/天梁（男星）=主生男孩；对宫有化忌=无子；太阴化忌+日月反背=无子
- **儿子数量**：从命宫中星颗数可知（但同年同月同日生人需夫妻合参）
- **儿子相貌像谁**：父母各自命中有二子，则夫妻共有四子；儿子脸孔像妈妈则多健康（儿子像爸爸/女儿像妈妈）；像爸爸易夭折需警惕
- **儿子夭折预警**：子女宫杀星带化忌=子女必死；儿子动作神态像大人者易夭折（善知人意/动作老成）
- **子女是否在身边**：日月反背+子女宫 → 子女会远离身边在外地发展
- **子女职业方向**：子女宫星性对应子女职业（巨门落陷=牢狱；巨门庙旺=校长/人师）
- **领养可能**：左眼袋（面相）=儿子：青黑干枯皱皱=丧子（暗黑=将发生/枯黄干黄=刚发生两周左右）；右眼袋 = 女儿
- **面相验证**：泪堂（子女宫）的缺陷直接对应子女吉凶；眼袋油黄如珍珠黄=以儿女为荣；左小右大=有女无子；眼袋有黑点=为子女担忧操心
- **阳宅调解**：东宫为客厅+未生子前住此=生不到儿子；已生子后住入=儿子很少回家（像客人）

### 六、疾厄宫
- **疾病部位精确定位（经脉流注）**：肺寅大卯胃辰宫、脾巳心午小未中、申胱酉肾心包戌、亥焦子胆丑肝通（看哪个宫杀星最多/最差 → 对应器官病变）
- **疾病部位精确定位（体型分布）**：中宫=肚脐、午未=头、巳=右肩/申=左肩、辰酉=右左胸、卯戌=右左胁、寅亥=右左足、子丑=男人精宫/妇人子宫
- **发病时间**：有病但何时发 → 看流年（流年杀星/化忌入该宫位时发作）
- **具体病种举例**：七杀在疾厄宫 → 痔疮；擎羊陀罗 → 体内看不到的肿瘤/癌症
- **用象取病（日月反背在疾厄宫）**：太阳在亥宫落陷 + 疾厄宫 → 眼睛视力不好（晚上怎能看到太阳？=已看不见）
- **面相交叉验证**：耳朵黑黑暗暗/枯黄 = 肾脏病（如尿毒症）；命门处黑黑的 = 必死

### 七、仆役宫（朋友宫）
- **合伙成败**：杀星太多=合伙做事业必败；吉星多=合伙大吉
- **合适合伙时机**：看流年，流年财星入住=大吉
- **朋友类型**：天马星入朋友宫 → 为朋友奔波劳累；天机星 = 平和的朋友；空耗星多（羊陀火铃空劫化忌）→ 朋友变仇人
- **合伙结果细节**：火星在朋友宫 → 合伙闹翻大打出手再遇巨门=上法院打官司
- **识人/小人面相**（朋友宫判读须配合观人术）：语无伦次未言先笑=心里有毒计；眼珠闪动=心术不好；四白眼=横死/杀人；三角眼=心存诡计；命门处有突骨跳动=反骨/汉奸；望神=眼神要正（眼睛越细越长越好/笑起来一条缝=大智慧）

### 八、田宅宫
- **祖产大小**：山林突出（面相）=祖业很大（结合风水看是哪条地脉/哪一代得到）
- **置产吉凶**：田宅宫状态决定能否买到好房产/建房是否顺利
- **官司是非**：田宅宫亦主家宅官司
- **房屋坐向**：从田宅宫的五行方位判断房屋朝向
- **家中火灾官司**：太阳星反背在亥宫+田宅宫 → 房屋有火灾（用象：家里晚上怎能看到太阳？=火灾）；以流年来定何年何月发生
- **家庭成员吉凶**：大限走田宅宫时「这十年主要说的是家」——家中谁出事看田宅宫里有什么四化（太阳化忌=父/夫/子有灾；太阴化忌=母/妻/女有灾；大限流年冲对宫者定具体）
- **财富库藏**：田宅宫和天府为命盘「二库」——库中要见禄（禄存/化禄：禄存是固定钱=薪水；化禄是薪水以外获得的财）

### 九、官禄宫
- **职业路径**：官禄宫=公家从政；财帛宫=私企从商（先天命格定位）
- **当官/经商/技术**：权星入住=当官；财星权星同入官禄宫=分管财政的官员（如银行行长）；科星在官禄=考公务员或走专业技术路；财帛宫有化权/权星=自己做生意当老板
- **职位高低**：紫微星+七杀星同入官禄宫=可当官且有权；紫微/天府在官禄宫（即使不在命宫）=能当官大吉
- **实权有无**：七杀+擎羊无化权=当官无实权/当小官；杀星入官禄宫=当官肯定不好
- **流年判断**：太阳庙旺（白天上班）=大旺大发；太阳陷地=白天晚上都忙，到头一场空
- **官禄宫的地支吉凶**：紫微+破军在命丑宫 + 武曲七杀一定在酉 → 日月反背 → 如果官禄宫正好在辰=太阴化忌 → 此人不能当官
- **当官的其他维度**：身宫在官禄宫=后天自然而然地去做官

### 十、财帛宫
- **固定薪水vs做生意**：有科权禄或财星=有能力做生意/自己当老板；财帛宫无科权禄=只能帮人打工领固定薪水（正财）
- **理财能力与小气程度**：禄存=小气（固定小薪水守财）；化禄=悭吝守财奴；禄存+巨门庙旺同宫=巨富（豪门宅地）
- **合伙财运**：流年逢天空+地劫星=肯定赔钱
- **财富来源**：财帛宫天府+禄存=后天工资收入（身宫在财帛）；后天之财（财星会到官禄宫/迁移宫=后天自己赚到的）
- **财富多少**：二库（田宅+天府）中见禄=库中有钱；命宫+父母宫+田宅宫都不见禄=先天无财/贫困家庭
- **做生意的必备条件**：化权加化禄或财星会到命宫/十年大运权禄会到=代表他会做生意
- **面相验证**：鼻头=财帛宫；鼻子大颧骨大相呼应=财权很大；鼻子大颧骨小=自己有钱；鼻子小颧骨大=替人管财；鼻头成两片骨+按有尖锐感=破财象

### 十一、迁移宫
- **外出vs本地发展**：身宫在迁移宫=后天自然外出去外地；紫微独坐迁移宫=人在外地孤军奋斗；紫微+辅弼=外地遇贵人（比本地好很多）
- **帝王/贵人**：紫微在迁移宫+辅弼 → 天子身旁遇贵人，如带兵打仗后封官加爵
- **外出吉凶**：化科在迁移宫=科甲/名气在外地；天仓（面相迁移宫）下陷=夫妻缘分浅/情感不稳定
- **迁移宫的三方四正关系**：迁移宫是命宫的对宫→若迁移宫化忌从对宫冲命宫，杀力量最大

### 十二、福德宫
- **一世福禄（总评估）**：福德宫为一辈子的福禄、财运、事业总纲；福德宫差=一辈子活得很累
- **一子送终/半空折翅**：从福德宫可批出特殊格局（半空折翅=30岁左右先天绝症/灾祸）
- **女命孤单**：武曲+七杀在福德宫+女命=孤单/离祖/异乡发迹；紫微独守福德宫（女命）=一世孤单
- **男命事业**：武曲+七杀在福德宫+男命=武职大利（若武星会文昌则为教官/老师）；商人则劳多功少（纯权利无禄）
- **婚姻能否长久**：夫妻宫好但福德宫差=夫妻关系不好/不能久长（原因：一世福禄不够，撑不住好姻缘）
- **科权禄对福德宫的影响**：辅弼台座独守福德宫=很惨（孤星一世没有享受福禄的机会）

## A1 — 应用示例 (Application Example)

### 示例一：夫妻宫的具体判读流程
**场景**：用户问「我的婚姻怎么样？会不会离婚？」

**逐宫展开**：
1. 查夫妻宫本宫主星 → 定配偶基本性格
2. 查夫妻宫三方四正有无科/权/禄 → 有=配偶有才能/有权/命中有财；无=配偶为正才（打工领固定薪水）
3. **交叉查福德宫**→ 夫妻宫好但福德宫差=婚姻不能长久；夫妻宫差但福德宫好=配偶差但自己能撑住
4. 查廉贞组合 → 判断是否有「生离死别」的危险格：廉贞+七杀=半路出事；廉贞+破军=水中遇难；廉贞+贪狼=先天疾病/自杀
5. 查太阳是否化忌 → 化忌冲夫妻宫=丈夫有灾/丧夫
6. 查辅弼台座是否独守夫妻宫 → 是=二婚（一定会离婚）
7. 查大限是否落在夫妻宫 → 这十年重点在婚姻：「半空折翅格」在中年大限遇夫妻宫=30岁左右婚姻大凶
8. 面相验证：眼角纹路（一条向下=生离/二三条上翘=和睦）、眼角是否黑暗（重病/大凶将临）

### 示例二：财帛宫具体判读
**场景**：问「我这辈子能发财吗？」

1. 查财帛宫/命宫有无科权禄 → 有科=靠一技之长；有权=自己当老板；有禄=祖业/会做生意
2. 查二库（田宅+天府） → 是否见禄（禄存/化禄）；库中见禄=存得住财；库空=赚多少散多少
3. 查是否有「日月反背」在财帛宫 → 太阳在亥陷地=做生意不行，「白天晚上都忙，到头一场空」
4. 查禄存是否有巨门庙旺同宫 → 是=巨富格局
5. 查身宫是否在财帛 → 后天自然会去赚钱
6. 面相验证：鼻头=财帛宫（狮鼻/悬胆鼻=大富；鼻大+手软如绵=大富；鼻紧看不到孔=小气鬼）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个能力卡？

1. 问「我的命怎么样」→ 先用 `tianji-ziwei-pandu` 定四宫框架，再参照本卡逐宫展开细节
