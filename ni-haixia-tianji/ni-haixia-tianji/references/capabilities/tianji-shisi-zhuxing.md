# 十四主星星性判断

## R — 原文 (Reading)

> "紫微（阳）星性：北斗星君，帝星，代表文武官带、贵人、正财（固定收入），解厄、制化
> （凶星遇到紫微，逢凶化吉）。"
>
> — 《天纪》04-紫微斗数笔记 / 05-紫微详解，紫微星段（p01）

> "巨门星性：凶星，代表口舌，是非，官司，牢狱，也代表豪宅大院；落陷代表牢狱；
> 庙旺代表口才好。"
>
> — 《天纪》04-紫微斗数笔记 / 05-紫微详解，巨门星段（p11）

> "七杀入命：目大、性急、多疑、性刚。破军入命：孤僻、体瘦、不重利。
> 贪狼入命：身材魁梧，毛发比较多。主桃花星。"
>
> — 《天纪》04-紫微斗数笔记 / 05-紫微详解，杀破狼对比段（p12）

## I — 方法论骨架 (Interpretation)

十四主星是紫微盘的"基本属性层"：每颗星告诉你这个人的禀赋、职业取向、长相趋势与落宫含义。判断骨架分三层，顺序不可颠倒：
① **先定亮度**：任何一颗主星，先查它在所在宫位是庙旺还是落陷——同一颗星亮度不同，吉凶可以反转（巨门庙旺=口才好/豪门，落陷=牢狱）。亮度这一层交给 `tianji-miaowang-luoxian`。
② **再断星性**：星的基本属性（紫微=帝星解厄、天机=文官正财、太阳=武官贵人、武曲=财星王、天同=人和解厄、廉贞=次桃花武官、天府=温和佐才、太阴=文官正财、天梁=食神文武、天相=佐才、巨门=口舌/豪宅），以及坐命的面相特征与在各宫的含义。
③ **再看组合与格局**：单星不足以断，须看同宫伙伴与三方四正会照——紫微要会左辅右弼才算真吉，杀破狼三方必会主劳耗与财。
本卡是"查表"而非"算命"：它是 `tianji-ziwei-pandu`（判读）与 `tianji-dayun-liunian`（流年）在执行时的内部查表工具，单独一颗星不构成完整任务。

- **太阳落陷各宫断语全表**（笔记第12页）：
  — 田宅宫：房子有火灾
  — 父母宫：与父亲死别
  — 夫妻宫：与丈夫死别（女命）
  — 子女宫：儿子远离不在身边
  — 疾厄宫：眼疾
  — 财帛宫：不适合做生意当老板，空忙

## A1 — 应用示例 (Application Example)

### 案例 1: 女命贪狼在午入命（c01，reported_case）
- **出处**: 05-紫微详解.md，民国 50 年三月初五戌时女命（阴女）
- **方法执行**: 读"贪狼在午"——按 p12，贪狼在午为火贵（武官星）而非泛水桃花；再查亮度（午宫入庙）→ 定性为武官格；天魁同宫 → 文武双全
- **结论**: 贪狼在午（非亥子）→ 武官格、有生杀之权（非桃花命）；官禄宫七杀+擎羊无化权 → 当官无实权
- **结果**: 原文记大限 34-43 太阳化忌 → 丈夫有劫；未提供第三方验证

### 案例 2: 女命破军在午入命（c09，reported_case）
- **出处**: 05-紫微详解.md，民国 46 年十一月十五午时女命（阴女）
- **方法执行**: 按 p12，破军在午庙旺 → 英星入庙格；同一句断语"男命发武官，女命主孤单孤僻"→ 依性别分岔
- **结论**: 破军午宫入庙：男发武官一品，女命反主孤单孤僻（同一星性因性别反转）
- **结果**: 原文记 33 岁丧夫、44 岁再婚、51 岁再次丧夫；未提供独立验证

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 问"紫微星是什么意思 / 贪狼是什么星 / 太阳代表什么"
2. 想知道某颗主星坐命的性格或长相特征（"天同坐命是不是很温和"）
3. 想知道某颗主星落在某个宫代表什么（"巨门在夫妻宫会怎样"）
4. 问"杀破狼是不是很凶 / 我是不是武官格"
5. 判读命盘时需要对每一颗主星做星性查表（作为下游流程的内部调用）

### 语言信号 (中英双写)

- "紫微星 / 天机 / 太阳 / 武曲 / 贪狼 是什么意思"
- "X 星坐命什么性格 / X 星入夫妻宫/财帛宫代表什么"
- "杀破狼是不是凶 / 我是不是武官格 / 主星星性"
- "what does Zi Wei / Tian Ji / Tan Lang star mean / main star nature"

### 与相邻 skill 的区分（定稿，含阶段4修复）

- **与 `tianji-miaowang-luoxian`（庙旺落陷）的区别（阶段4 修复——防混淆）**：
  - 问「某星**是什么性质/代表什么**」→ **本卡**（星性层）。
  - 问「某星**在陷位/庙旺是什么意思**」「这颗星此处是吉是凶」→ **`tianji-miaowang-luoxian`**（亮度层）。
  - ⚠️ 凡是问句里出现「庙旺 / 落陷 / 陷位 / 亮度 / 吉还是凶」→ **一律先转亮度卡**，本卡不单独下吉凶结论。
  - 本卡只回答「星性是什么」，不负责回答「这个亮度下是吉是凶」。
- 与 `tianji-ziwei-pandu`（三方四正判读）的区别: 判读卡定框架与顺序，本卡是被它调用的逐星查表；用户一般不会单独说"只用主星规则"
- 与 `tianji-liujixing` / `tianji-liushaxing`（六吉/六煞）的区别: 本卡是十四"主星"，吉煞卡是辅星层；主星定属性，辅星做加减
- 与 `tianji-ziwei-geju`（格局）的区别: 本卡逐星，格局卡把多颗星打包成高确定性判断（如紫府坐垣、七杀朝斗）

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①要判断的主星名（十四主星之一）；②该星所在宫位；③该星在该宫的亮度（庙/旺/得/利/平/闲/陷）；④若是组合（杀破狼、廉贞+七杀等）须给出同宫或三方会照的伙伴星。**缺失项应先询问**：只给"贪狼"不给宫位与亮度时，不得直接断吉凶。

**输出契约**：一条"星 × 亮度 × 宫位 → 结论"的记录，字段为{星名、所在宫、亮度、星性要点、坐命/落宫含义、性别分岔（如有）}。**约定**：本卡以原书"亮度优先"为口径——先查亮度定吉凶底色，再读星性；组合判断须显式列出伙伴星，不得只凭单星下结论。

1. **确认输入齐备**
   - 完成标准: 星名、宫位、亮度、伙伴星（如有）四项到位；缺亮度则先转 `tianji-miaowang-luoxian` 定亮度
2. **先定亮度吉凶底色**
   - 完成标准: 标出庙旺（吉）/落陷（凶）/中间档；对亮度敏感星（巨门、杀破狼、廉贞）特别标注反转风险
3. **查该星星性**
   - 完成标准: 给出该星的核心属性（官带/财星/桃花/佐才/解厄等）与坐命特征
4. **套宫位含义**
   - 完成标准: 给"该星落该宫"的具体含义（如巨门落父母宫=豪门大院；武曲落夫妻宫=夫妻同行）
   - 判停点: 若涉及吉煞叠加或**致死性断语**（如廉贪落陷自杀格、廉破横死），不在本卡下结论，转 `tianji-ziwei-geju` 与 `tianji-miaowang-luoxian`
5. **组合与三方会照**
   - 完成标准: 列出同宫/会照伙伴星，给出组合判断（杀破狼、紫微+左辅右弼、机月同梁等）
6. **交棒判读流程**
   - 完成标准: 逐星记录汇总后交 `tianji-ziwei-pandu` 做整体判读，本卡不单独输出人生结论

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- ⚠️ **不要把"某星是什么意思"排除在本卡之外**（阶段4 修复）：用户问「贪狼星是什么星」「巨门是什么」这类**基础星性查询**，正是本卡的主要用途，应当激活并回答星性。
  （原稿曾写"不适用于纯术语查询"，导致盲测漏触发，已删除该排除条款。）
- 若只问「某星在陷位/庙旺怎么样」而无星性问题 → 转 `tianji-miaowang-luoxian`。
- 用户只有一颗星、没有宫位与亮度就想知道"好不好"——单星无亮度无法定性，先补输入
- 用户要的是整盘结论（事业/婚姻）——那是判读（`tianji-ziwei-pandu`），本卡是内部查表
- 用户问的是六吉/六煞/飞星四化——那是 `tianji-liujixing` / `tianji-liushaxing` / `tianji-sihua`

### 作者在书中警告的失败模式

- **不看亮度就断星性**：原文反复强调同一颗星庙旺/落陷反转（巨门、廉贞、贪狼、杀破狼）；跳过亮度直接断，是最常见误判
- **以单星定全局**：倪师要求紫微须会左辅右弼方吉、杀破狼须看会吉会煞；单星即下结论属断章取义
- **忽略性别分岔**：同一星性对男女断语不同（破军在午男发武官、女主孤单），漏掉性别会误读

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **命例全为倪师自述批命经验，无第三方验证**；星性断语解释空间大，不准时可归因面相/阳宅
- **案例性别角色刻板**：如"女身男命活得很累""女人得武官星为暗权"等表述带成书年代（1994）的传统性别观，现代语境需重读
- **紫微详解夹带整理者个人玄学内容**，与倪师原文风格差异大，引用星性时须区分来源

### 容易混淆的邻近方法论

- 与 `tianji-miaowang-luoxian` 区分: 亮度=吉凶底色的第一层过滤，星性=属性；先亮后性
- 与 `tianji-ziwei-geju` 区分: 本卡逐星，格局卡做多星组合的成格判定
