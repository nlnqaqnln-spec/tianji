# 手相八大宫位判断

## R — 原文 (Reading)

> "手掌后天卦分布（统一看左手）：明堂要平广，凹下去能停水为最吉，绝不能突出。
> 乾(父母/祖宗)：饱满丰隆→祖上风水好；平/凹陷→与父母相克。
> 坎(祖业)：饱满→祖业兴旺；凹陷→白手起家。艮(田宅/兄弟)：饱满→田宅/兄弟多。"
>
> — 04-紫微斗数笔记 / 05-紫微详解 第13页（p29 / f14，单元 u20）

> "震(妻)：饱满→妻贤；凹陷→妻不贤/身体不好/过世。巽(财禄)：饱满→财禄兴盛；凹陷/横纹多→破财。离(官禄)：饱满→官星大。坤(子媳)：饱满→子媳贵；扁平→无子媳；暗黑→损夫。兑(朋友下属)：饱满→朋友下属贵；扁平→所交朋友不好。"
>
> — 05-紫微详解 第13页（f14，单元 u20）

## I — 方法论骨架 (Interpretation)

手相是紫微命盘的"硬件配置"：把左手掌按九宫八卦切成八宫加中宫（明堂），每一宫钉死绑一个命运维度，于是不用排盘、看一眼掌心就能给出一张"索引式体检表"。
核心三步：
① **定位**——明堂在掌心，八宫环绕：乾（父母/祖宗）、坎（祖业）、艮（田宅/兄弟）、震（妻）、巽（财禄）、离（官禄）、坤（子媳/夫妻）、兑（朋友/下属）。统一看左手。
② **判断标准统一**——同一个口诀走遍八宫：**饱满丰隆凸起＝吉／兴**；**平、凹陷、扁平＝不吉／缺**；巽宫再叠一条"凹陷或横纹多＝破财"；坤宫再叠"暗黑＝损夫"。中宫明堂要**平广、凹下去能停水**（绝不能突出）。
③ **附加纹形**——天柱纹（掌中贯向中指的事业/玉柱纹）主科甲、越细越好；手纹多深＝心机狠，纹少＝憨厚，透手背＝破祖业；女手见筋见骨＝旺夫，男手软如棉＝多福。
一句话：**同一套"饱满 vs 凹陷"标尺，逐宫读出父母、祖业、田宅、妻、财、官、子、友八个维度的强弱**。它的价值是给紫微命盘提供一个不依赖排盘的独立印证通道。

## A1 — 原书案例 (Past Application)

原书未提供单以手相断命的完整命例，本卡采用**合成演练**（按原书规则可复算，明确标记）：

### 合成演练 1: 巽宫凹陷 + 横纹多
- **输入**: 左手巽宫（财禄）凹陷，且横纹多。
- **方法执行**: 按 f14 "巽（财禄）凹陷/横纹多→破财" 直接落判断，再核对其余七宫的饱满/凹陷作为佐证。
- **预期输出**: 财禄宫破财之象；继续逐宫核对，若坎宫也凹陷→白手起家而非祖业丰厚，两宫互证"需靠自身奋斗"。

### 合成演练 2: 震宫凹陷
- **输入**: 左手震宫（妻）凹陷。
- **方法执行**: 按 f14 "震（妻）凹陷→妻不贤/身体不好/过世" 落判断；再提示用面相（奸门/鱼尾纹）与命盘夫妻宫交叉验证。
- **预期输出**: 妻缘不吉之象；标注需命相同参。

> 说明：以上为标记清楚的合成演练，用于演示"逐宫核对"的操作方式，不代表作者亲历或现实结果。原书手相内容为规则清单，本身未附手相命例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 摊开手掌问"我这条纹/这一块鼓起来代表什么"
2. 没有生辰、排不了盘，想靠手相先看一眼财、官、婚
3. 想用手相印证命盘结论（命盘说婚姻凶，手上震宫是否也凹陷）
4. 观察到自己/对方手掌某处突然凹陷、暗黑、横纹变多

### 语言信号 (中英双写)

- "我手掌这里鼓 / 这里凹 / 巽宫在哪 / 明堂要怎么样"
- "看手相 / 事业线 / 天柱纹 / 手上这条线什么意思"
- "手软如棉好不好 / 女人手见筋见骨"
- "palm reading / hand reading / what does this line on my palm mean / Ming Tang"

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-mianxiang`（面相十二宫）的区别: **本卡看手掌八宫**（乾坎艮震巽离坤兑的饱满/凹陷）；**面相卡看脸的十二宫与纹痣气色**。两者是两条并列的"看图"通道，常互参
- 与 `tianji-sihua` 中手相征象（化禄：女手见筋见骨/男手软如棉）的区别: **本卡处理八宫结构**（哪一宫饱满哪里凹陷）；化禄手相只借"手软/见筋见骨"作为**化禄的佐证**，不逐宫定位
- 与 `tianji-ziwei-pandu`（命盘判读）的区别: 本卡无需排盘、看终身"硬件"；命盘卡需生辰、看完整十二宫

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①左手掌清晰照片或当面观察（统一定左手，若只有右手须先声明并说明差异风险）；②观察目标宫位或用户关注点（不给则八宫全扫）。缺清晰掌纹图像时应先索要，不得凭模糊描述猜"某宫是否饱满"。

**输出契约**：按"宫位 → 卦象 → 征象（饱满/凹陷/横纹/暗黑） → 判断 → 互参建议"输出；每条须标注所据口诀来源。涉及妻/子/父母等六亲与生死类断语须附文化参考声明。

1. **摆正手掌、定位明堂与八宫**
   - 完成标准: 先定中宫明堂，再依序锁定乾/坎/艮/震/巽/离/坤/兑八宫位置（统一左手）
2. **读明堂**
   - 完成标准: 判"平广、能停水"为吉；若突出则记为不吉
3. **逐宫对照口诀**
   - 完成标准: 每宫输出"征象→判断"（乾凹陷→与父母相克；艮扁平→兄弟稀少；坤暗黑→损夫等）；巽/坤须检查附加条件（横纹、暗黑）
4. **读天柱纹与手纹辅助**
   - 完成标准: 检查掌中天柱纹（贯中指、越细越好）、手纹多少与深浅，给出心性/科甲一条判断
5. **交叉验证**
   - 完成标准: 至少给出两条可对照项（震宫↔夫妻宫/奸门；巽宫↔财帛宫；乾宫↔父母宫/额头），标注"命相同参"结论

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是**面部**纹、痣、气色 → 走 `tianji-mianxiang`
- 用户问的是**整体形体分类**（五形人、三停）→ 走 `tianji-xingti-fenlei`
- 用户问的是**某颗星的四化在手相上的征象**（化禄→手软/见筋见骨）→ 走 `tianji-sihua`
- 涉及医疗判断（手掌发麻、指甲病变、手部肿胀）→ 本卡不做医学诊断，应建议就医

### 作者在书中警告的失败模式

- 单手单宫即断（只看巽宫凹陷就断破财），忽略右左差异与命盘互参
- 把"女人手见筋见骨"直接套成"旺夫"或"大富"——原书两处措辞不同（一作旺夫、一作大富），应如实并列，不择一硬断

### 作者的盲点 / 时代局限

- **手相与紫微严格对应的假设未被证明**：为何同命盘者手纹各异，原书未解释
- **断语不可独立核验**：所有手相断法为作者自述经验，无第三方统计
- **性别刻板内容**："震宫凹陷→妻不贤/过世""坤宫暗黑→损夫"等带传统性别观，现代语境应过滤并避免用于评价他人
- **涉及生死类断语**（如震宫凹陷→过世）：属文化记录，不可作确定性断言，健康问题应就医

### 容易混淆的邻近方法论

- 与 `tianji-mianxiang` 区分: 本卡=手掌八宫（硬件），面相卡=面部十二宫（屏幕）
- 与 `tianji-qise-shengsi` 区分: 本卡看终身结构，气色卡看短周期颜色与时限
