# 四化面相/骨相/手相征象

## R — 原文 (Reading)

> "我们的眼睛、鼻子、这个颧骨很大，像一个烟斗一样连到耳朵……这个地方长的是权，但是这个颧部有肉，最忌讳的是皮骨相连，有的人颧很大，但是没有肉，是骨头和皮连在一起，这种就叫做孤权，尤其是女孩子要是这样的话，一辈子孤单。"
>
> — 01-天机道【天纪/10星座】星座节（xz2-01，单元 u35）

> "有的人有科没有权，这个犀牛骨就扁扁的，眼睛在这里，眼睛很大，眉毛短短的，这就是师爷，就是做参谋。"
>
> — 01-天机道【天纪/10星座】星座节（xz2-02，单元 u35）

## I — 方法论骨架 (Interpretation)

四化（科、权、禄、忌）在命盘上是"驱动力"，在脸上、骨上、手上则是**可直接读出的征象**——把 u06（四化）与 u16/u20（面相/手相）打通，让四化从抽象概念变成看得见的标记。
四个通道：
① **化权＝颧部（骨）**。合格正权：颧骨大且"像烟斗一样连到耳朵"，颧部**有肉**。凶态"孤权"：颧很大但**无肉、皮骨相连**——女命成孤权即主一辈子孤单。差别只在"肉"之有无。
② **化科＋化权对比＝犀牛骨**。眉骨后方整块凸出的骨头叫犀牛骨，掌权（化权）：凸＝可统兵做将；**有科无权**者犀牛骨扁扁的，配眼大、眉短＝"师爷相"，只能做参谋/佐才。
③ **化禄＝手相**。女命手伸出枯枯干干、见筋见骨 → 大富；男命手软如棉 → 大富（原文此处两性皆归"大富"）。
④ **化忌＝"挤"**。化忌之相：头大、五官挤在一起 → 一辈子想不开。反例（想得开之相）：眉毛打开、眉位高、两眉之间（印堂）很宽 → 大开大合、有担当有魄力；再配"耳比眼高＋眉恰在额眼中间"＝非常之相，非富即贵。
一句话：**在脸上/骨上/手上找四化的落点，用"有肉无肉、凸与扁、挤与开阔"这几组可见对比，反推这个人命盘上的权、科、禄、忌**。

## A1 — 原书案例 (Past Application)

原书未提供以四化面相断命的完整命例，本卡采用**合成演练**（按原书规则可复算，明确标记）：

### 合成演练 1: 颧大无肉（孤权）
- **输入**: 某人颧骨很大，但颧部无肉、皮骨相连；性别女。
- **方法执行**: 按 xz2-01——同为"颧骨大"，先查"有没有肉"：无肉皮骨相连＝孤权（非正权）。
- **预期输出**: 孤权；女命→一辈子孤单之象。再核对是否有"烟斗连耳"与颧部有肉（有肉则翻回正权）。

### 合成演练 2: 犀牛骨扁＋眼大眉短（师爷相）
- **输入**: 某人眉骨后方骨块扁扁的，眼睛大、眉毛短。
- **方法执行**: 按 xz2-02——犀牛骨扁＝无权；配眼大眉短＝有科无权。
- **预期输出**: 师爷相，只能做参谋/佐才，不主统军。若犀牛骨凸起则改为"有权、可统兵"。

> 说明：以上为标记清楚的合成演练，用于演示"有肉无肉/凸与扁"的对比判法；原书四化面相为规则类条目，未附命例与结果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到某人颧骨特别大/无肉，问代表什么
2. 命盘已知有化权/无权，想从脸上验证
3. 问"我是不是师爷命/参谋型"，或"Why do I look 出力不掌权"
4. 观察到自己或他人头大五官挤，问性格与运势

- "颧骨大 / 颧大无肉 / 皮骨相连 / 孤权是什么"
- "犀牛骨 / 眉骨突出 / 师爷相 / 有科无权"
- "手软如棉 / 手见筋见骨 / 头大五官挤 / 想不开"
- "cheekbones / power face / Si Hua face reading / why does my face look 挤"

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-mianxiang`（面相十二宫）的区别: 面相卡按**十二宫定位**（奸门=夫妻、印堂=命宫）逐宫读纹痣气色；**本卡不按宫位，而按四化落点**（颧=权、犀牛骨=科权、手=禄、五官挤=忌）反向印证四化
- 与 `tianji-sihua`（四化判读）的区别: 四化卡处理**命盘宫位上的科权禄忌**（在官禄/财帛/夫妻宫的含义）；**本卡处理四化在身体上的可见征象**（脸/骨/手上的落点）。一个是盘、一个是相，二者互为验证
- 与 `tianji-shouxiang-bagong`（手相八宫）的区别: 手相八宫按**手掌九宫**逐宫判断；本卡只借"手软/见筋见骨"作为**化禄**的佐证

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①可观察的正脸/手部图像或面见，②待验证的四化项（权/科/禄/忌，或"看整体四化"）。缺清晰图像应先索要；若不指明四化项则四项全扫。

**输出契约**：按"四化项 → 身体通道（颧/犀牛骨/手/五官） → 征象 → 判断"输出；每条须对比正反形态（有肉 vs 无肉、凸 vs 扁、挤 vs 开阔）；涉及"一辈子孤单/想不开"类断语附文化参考声明。

1. **定位四化通道**
   - 完成标准: 明确权→颧部、科权→犀牛骨、禄→手相、忌→五官分布
2. **查颧部（权）**
   - 完成标准: 先判"颧是否大"，再判"有无肉"——有肉＋烟斗连耳＝正权；无肉皮骨相连＝孤权；女命孤权须标注"主孤单"
   - 细化：颧与鼻三平高度=掌财权（可调动国库级钱财）；颧大鼻小=副手财权（经理级）
3. **查犀牛骨（科/权）**
   - 完成标准: 凸＝有权（可统兵）；扁＋眼大眉短＝师爷相（有科无权、只做参谋）
   - 手相辅助查科：天柱纹（由手掌直通中指根）=有才艺之科（与命盘化科互参）
4. **查手相（禄）**
   - 完成标准: 女命见筋见骨、男命软如棉＝大富；如实并列（不与其他卡的"旺夫/多福"择一硬断）
5. **查五官分布（忌）**
   - 完成标准: 头大五官挤＝想不开；眉高眉宽印堂开阔＝想得开；配"耳比眼高＋眉在额眼中间"＝非富即贵
6. **汇总与互参**
   - 完成标准: 给出四化的身体征象小结，并标注可与命盘四化所在宫交叉验证

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是**按十二宫**定位某部位吉凶 → 走 `tianji-mianxiang`
- 用户要的是**命盘上**科权禄忌在十二宫的含义 → 走 `tianji-sihua`
- 用户要的是**手掌八宫**逐宫判断 → 走 `tianji-shouxiang-bagong`
- 涉及医疗（头大、面部骨骼异常、手部病变）→ 本卡不做医学诊断

### 作者在书中警告的失败模式

- 只凭"颧大"就断权，忽略"有无肉"这一关键分水岭（同为大颧，有肉=权/无肉=孤权，结论相反）
- 把"手软如棉/见筋见骨"跨卡混用：原书在其星座节统一说"都是大富"，而手相卡分别说"多福/旺夫"，不应混说

### 作者的盲点 / 时代局限

- **"相由心生、念改则相改"的因果未论证**：原文强调改念可改相，但未给验证
- **断语不可独立核验**：四化面相为作者自述经验，无第三方统计
- **性别刻板内容**偏多（"女孩子孤权一辈子孤单"），现代语境应过滤，不得用于评价他人
- 本条与 u16/u20 存在部分重复，已由提取者如实标注

### 容易混淆的邻近方法论

- 与 `tianji-sihua` 区分: 四化卡=盘上宫位含义，本卡=身上可见征象
- 与 `tianji-mianxiang` 区分: 面相卡按十二宫，本卡按四化落点
