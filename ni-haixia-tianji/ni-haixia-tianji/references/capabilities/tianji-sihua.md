# 四化（科权禄忌）判读规则

## R — 原文 (Reading)

> "科权禄忌四化为主，无需计算飞星。化科：a.科名金榜题名 b.声名远播；
> 化权：a.官印 b.性情刚直；化禄：a.钱财 b.悭吝；化忌：a.劫杀 b.自身想不开。"
> "科权禄忌四化为主，无需计算飞星。四化是变化的驱动力。"
>
> — 《天纪》04-紫微斗数笔记 第1-3页（p15 / f08 / g03）

## I — 方法论骨架 (Interpretation)

紫微斗数里星曜只是"载体"，四化才是"引擎"。同一个宫位有没有动力，取决于里面坐着的是化禄、化权、化科还是化忌。
- **化科**：两义——科名（考试、文笔、才艺、为人师表）与声名远播。落在官禄宫=适合考试/教师/公职；落在财帛宫=有技术专长。
- **化权**：两义——官印（实权）与性刚（主见强）。落命宫=先天领导之才；落官禄=掌实权最佳；落夫妻=配偶性刚；落财帛=私企掌权。
- **化禄**：两义——钱财与悭吝（守财）。落财帛=自己会做生意；落命宫=祖业丰厚；落父母=父母从商。
- **化忌**：两义——外部劫杀（官司、横祸）与自己想不开。落兄弟=不和/夭折/合伙破财；落福德=一生不顺；落财帛=事倍功半；化忌在对宫冲命=半空折翅大凶。
- **太阳化忌=父/夫/子有灾；太阴化忌=母亲有灾**（太阳/太阴的化忌与六亲绑定是核心断语）
- **化科+化忌同宫=屠夫命**（笔记第34页原文明确）
下判读结论时**先看四化在哪一宫，再看星曜**；本体系只取生年（及大限流年）四化，不飞宫飞星。

## A1 — 原书案例 (Past Application)

### 案例 1: 男命紫相在辰权科入命（c11，reported_case）
- **出处**: 05-紫微详解.md，案例分析第十五例（阳男）
- **方法执行**: 读生年四化——权、科入命，判断"命中带科、读书好"；再本身宫位置落财帛宫且带化忌
- **结论**: 命带科权 → 适合公务体系；身宫在财帛但化忌 → 虽想做老板，实则当不成老板，只能领固定薪水
- **结果**: 原文记大限16-25天梁化禄（财星过早）→ 尚未成熟即接祖业、学业中断；未给独立验证

### 案例 2: 女命破军在午两次丧夫（c09，reported_case）
- **出处**: 05-紫微详解.md，民国46年十一月十五午时女命（阴女）
- **方法执行**: 追踪不同大限/流年的四化——33岁巨门化忌冲太阳（父/夫/子）→ 断丧夫；51岁巳宫太阳再被冲 → 断二次丧夫；大限52-61巨门化忌在交友宫 → 断合伙投资破财
- **结论**: 四化落宫/落线位置变化，直接对应各阶段吉凶事件
- **结果**: 原文记"33岁丧夫、44岁再婚、51岁再次丧夫，七年一轮"；未提供第三方验证

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 问"我官禄宫化权是什么意思 / 财帛宫化禄好不好"
2. 想知道自己这一生"权、钱、名、灾"分别来自哪
3. 大限或流年遇到化忌，问"这十年是不是不好 / 化忌对冲有什么影响"
4. 想知道自己的事业方向走官还是走商

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-ziwei-pandu`（三方四正判读）的区别: 判读卡先定"看哪几个宫"，本卡专责四化落宫的逐项含义；判读卡先跑、本卡随后
- 与 `tianji-shisi-zhuxing`（十四主星）的区别: 本卡处理"变化的驱动力"，星性卡处理"基本属性"；先四化后星曜
- 与 `tianji-dayun-liunian`（大运流年）的区别: 本卡给出四化本身含义，时间推算由该卡执行
- 与 `tianji-mianxiang`（面相十二宫）的区别: `xz2` 征象把四化"读"到脸上（颧=化权、鼻=化禄），本卡停留在命盘层面；两者互补

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①命盘四化清单（哪个天干化科/权/禄/忌 + 落在哪一宫），②适用层级（生年 / 大限 / 流年）。只问"四化什么意思"而不给落宫时，先索要落宫，不得泛泛作答；缺壬干/癸干等四化表时须先确认所用四化表口径。

**输出契约**：按"化 + 宫"给两义中的适用义，输出格式为「宫位 × 四化 → 结论 + 依据」，并对化忌给出严重度分级（本宫/对宫冲/叠加煞星）。涉及吉凶不要只给符号，须落到"财/权/名/灾"四类之一。

1. **明确四化来源与层级**
   - 完成标准: 标出是生年四化还是某大限/流年四化；列全科权禄忌四笔及其落宫
2. **逐笔套"宫位 × 四化"对照**
   - 完成标准: 每笔给出一条主结论，从该化的两义中选与宫位匹配的那一义（如化权落命=领导之才、落夫妻=配偶性刚）
3. **判定方向（事业/财）**
   - 完成标准: 由官禄、财帛两宫的四化组合给出"走官/走商/技术专长"方向（命有科无权→适合佐才参谋；官禄化权→最佳当官格）
4. **处理化忌（判停）**
   - 完成标准: 分级——①本宫化忌②对宫冲命（半空折翅级）③叠加煞星落陷（更凶）。**判停点**：若化忌在对宫冲命，直接给"大凶需化解"结论并转 `tianji-shengong-huajie`，不在此卡展开化解
5. **复述并交叉验证**
   - 完成标准: 结论可回溯到"某化+某宫"；提示可用面相征象参证（颧=化权、鼻=化禄、五官挤=化忌）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只想知道某颗主星的星性（走 `tianji-shisi-zhuxing`）
- 命盘未排（无宫无化），本卡无输入
- 用户问的不是命盘层面的四化，而是外部的"运气好坏"直觉判断

### 作者在书中警告的失败模式

- **引入飞星**：倪师明确"无需计算飞星"，若自行叠加宫干飞化、层层计算，会偏离本体系口径
- **把四化当单纯吉凶符号**：化禄也代表小气、化忌也代表自己想不开，不是"禄=纯好事、忌=纯坏事"
- **跳过四化先看星**：看到财星在财帛就断"有钱"，漏掉"无禄无权只能算正财（固定薪水）"

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **命例全部为倪师自述批命经验，无第三方验证**；四化断语的准确性无法独立核验，且解释空间大（不准可归因面相/阳宅）
- **四化表口径依赖**：不同流派生年四化表已有差异，原书未附完整四化表，使用时须固定口径
- **紫微详解夹带整理者个人玄学内容**，与倪师原文风格差异大，叠加四化判断时须区分来源
- **时代局限**："官禄宫化禄=贪官或掌财权（不太好）"等断语带成书年代的价值判断，现代语境需重新解读

### 容易混淆的邻近方法论

- 与 `tianji-ziwei-pandu` 区分: 判读卡定框架，本卡读动力；两者顺序为先判读框架、再四化
- 与 `tianji-ziwei-geju`（格局）区分: 化忌冲命是"半空折翅格"的成立条件之一，格局卡做整体成格判定，本卡只给化忌这一变量
