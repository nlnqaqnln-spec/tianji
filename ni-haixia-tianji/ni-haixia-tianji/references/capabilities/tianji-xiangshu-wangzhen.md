# 相术总结：疾厄望诊细则

## R — 原文 (Reading)

> 「苦冷者死」什么叫苦冷?如果这个印堂的部分整个冰掉了，甚至于摸下去有点水水的感觉，这是相书上面的疾厄宫。……重病的时候整个印堂的地方都青冷掉。
>
> — 01-天机道【天纪/09归纳总结】1.相术总结（第28020行起，xz01，单元 u34）

> 「色黑为劳」你看那个人脸上黑黑暗暗的，就是「劳症」……还有相书上面讲，色黑是无欲，已经没有性欲了，无法行房事。
>
> — 01-天机道【天纪/09归纳总结】1.相术总结（xz02，单元 u34）

## I — 方法论骨架 (Interpretation)

这是全书相术的**逐条望诊细则总表**（原文 53 条），把"看脸"从粗筛升级为可逐条核对的清单。核心是把望诊分为三类，逐条比对：
① **色**（气色/面色）——印堂冰掉青冷＝苦冷主死；脸上黑黑暗暗＝色黑为劳；面色发灰＝坐牢/刚出狱；眉毛下发红（冬天）＝红鸾星动；印堂横纹＝有痛或事业停滞；鼻头突黄＝横财。
② **形**（部位/骨相/纹路）——三白眼/四白眼＝杀人犯眼；鸟啄嘴＝可共患难不可共享乐；鼻如灶门＝破祖业；狮鼻/悬胆鼻＝大富；皮骨相连＝孤坐；天罗纹（额角网状）＝太太过世；螟蛉子＝鼻上一竖纹；鼻上横纹＝车祸；水死纹＝鼻头 )( 纹；日角陷主丧父、月角陷主丧母（左眉额=日角/父，右眉额=月角/母；日月角都挺起来是好；高者先丧）；郎君面（脸油光光无皱纹→格局不好/不够脚踏实地，区别于正常油光）；眉下一圈黑→心术不正（窄窄淡淡一条卧蚕下方横着的黑色）；沙薄烟罩的死前气色（脸上变成红色但毛孔呈青色→"牛鬼蛇神已经进来了"）；蒸笼头→太急躁做不了将官（头易出汗，只能干校官干不了将官）；小便散开/直流（小便散开=大富大贵/源于练提肛肺气往下；小便直流=贫穷到老）。
③ **行为/神态**——未言先笑＝心生毒计；言简刚中＝君子；哭天抢地（头红而印堂不白）＝假哭小人；鸭步（禹步）＝大富；善巫之人＝唇不蔽齿、舌舔唇口。
作用是当 u17（四等气色）给出"粗筛"后，本卡提供 **53 条逐部位细则**，让疾厄/凶事判断可逐项落条。原文多处同时提醒**把"时运"与"望诊的疾病"分开**——眉毛下发红是姻缘不是痔疮，面色发灰是牢狱不是肾病。

## A1 — 原书案例 (Past Application)

> 以下均为原书案例（xz 条目，reported_case），原书作为"判据范例"引用，未交代实际后续者已注明。

### 案例 1: 印堂发黑陪人洗肾者（xz03）
- **来源**: 相术总结 xz03（01-天机道）
- **方法的使用**: 陪尿毒症病人洗肾者自己印堂发黑 → 按"印堂发黑主横死"判——出事的不是病人而是陪护者
- **结论**: 将要出车祸死掉；人死前约两周可见气色，看到后翻黄历找最近节/气，从当天算起第七天前后为异动窗口
- **结果**: 原文作为"死前可先看气色"的例证；实际后续原文未说明

### 案例 2: 脸上枯老 + 杀星落陷 + 绝日（xz 三杀叠加，见 ce16/ce18）
- **来源**: 05-紫微详解 第23-24页
- **方法的使用**: 12月25日立冬、17日见某人面部枯老 → 枯老为将发生之色 → 查流年见诸多杀星相会且落陷 → 查下一节气前一天为绝日
- **结论**: "此人死定了"——多凶叠加判为无解
- **结果**: 原文作为判死标准范例；命主精确日期原文只作"死定了"，未给

> 注：其余 50 余条（四白眼、鸟啄嘴、狮鼻、天罗纹、螟蛉子纹、鸭步等）均为原书逐条望诊细则，同属本单元素材，此处不逐一展开。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 观察到自己/他人某处异常（印堂冰/发灰、眼周一圈黑、鼻上纹、额角网状纹）问代表什么
2. 已用四等气色粗筛后，想更细地"逐条对照"某个部位
3. 想区分"这是病还是命/时运"（如眉毛下发红是不是痔疮）
4. 文化考据：某个相书断语的准确出处与表述

### 语言信号 (中英双写)

- "印堂很冷/发灰 / 眼周一圈黑 / 鼻上有横纹 / 额角网状纹"
- "是不是有病 / 这是病还是相 / 色黑是什么 / 苦冷者死"
- "四白眼/三白眼 / 鸟啄嘴 / 狮鼻 / 悬胆鼻 / 鸭步"
- "face diagnosis / complexion reading / dark shen gong / is this a bad omen"

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-qise-shengsi`（四等气色时限）的区别: 气色卡处理**颜色 + 时间**（黄润/枯焦/枯黄/青蓝及"下一节气"窗口）；**本卡处理逐部位的 53 条望诊细则**（某部位某纹某形对应什么）。二者是"粗筛 → 逐条核对"的先后关系，本卡更细、更杂
- 与 `tianji-mianxiang`（面相十二宫）的区别: 面相卡按**十二宫定位**读纹痣；本卡不按宫位，而按"色/形/行为"三大类混杂逐条列举
- 与 `tianji-guanrenshu`（识小人）的区别: 识小人卡专列**人际防范特征**（未言先笑、四白眼、左眉直纹）；本卡范围更广，含大量疾厄/生死/婚姻望诊

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①可观察的正脸图像或面见，②观察到的具体特征（部位＋征象，如"印堂：青冷"、"眼周：一圈横黑"）。缺清晰信息应先索要，不得凭模糊描述硬套某条。

**输出契约**：按"部位 → 征象 → 对应条目（编号） → 判断 → 分类（病/命/时运） → 时限（如原文给出）"输出；每条须标注来源条目；**凡涉及疾厄、生死类条目，必须分类标注"命理/时运"并强制附医疗免责（见 B 段）**。

1. **录入征象并归类**
   - 完成标准: 将观察归入"色 / 形 / 行为神态"三类之一
2. **逐条比对**
   - 完成标准: 命中具体条目并写出编号与原文判断（如"色黑＝劳症/无欲"；"印堂横纹＝有痛或事业停滞"）
3. **判"病 or 命"**
   - 完成标准: 按原文提醒明确区分——时运类（眉毛下发红＝红鸾）与疾病类（面色发灰＝牢狱、非肾病）分开落条，不得互相替换
4. **给时限或标"未展开"**
   - 完成标准: 原文有时间的（如横死约两周、从节气起第七天）照录；原文未给的如实标"原文未给出时限"
5. **输出并强制免责与转介**
   - 完成标准: 结论含"文化参考"声明；**见疾厄/生死类征象时强制提示就医**，不得以相术替代诊断（见 B 段）

**判停点**：若用户描述的是真实身体症状（持续疼痛、消瘦、发黄、水肿、情绪危机等），**停止相术推演，转为强制就医建议**。

## B — 边界 (Boundary) ★

### ⚠️ 强制医疗免责（本卡必写，不可省略）

> 本卡全部内容为**传统相术文化记录**，**仅作文化参考**。文中"苦冷者死""印堂发黑主横死""面色发灰"等断语，与疾病、寿命之间**没有经过验证的因果关系**，**不可替代就医**，**绝不做确定性死亡断言**。任何面相观察都不能替代专业医疗诊断与治疗；**若本人或家人有健康疑虑，请立即就医**。绝不可用本卡内容劝阻、延误或替代诊治。原文亦反复强调"把时运与望诊的疾病分开"，可见其本身并非医学诊断。

### 不要在以下情况使用此 skill

- **真实身体症状/健康焦虑** → 立即建议就医，不做相术推演（本卡免责优先）
- 用户流露轻生念头（"想不开"相关）→ 转心理援助
- 用户要的是**颜色与时限的粗筛** → 走 `tianji-qise-shengsi`
- 用户要的是**按十二宫的定位** → 走 `tianji-mianxiang`
- 用户要的是**人际防范特征清单** → 走 `tianji-guanrenshu`

### 作者在书中警告的失败模式

- **不分时运与疾病**：把"眉毛下发红（红鸾动）"误当疾病、把气色当纯医学——原文多次提醒分开
- **误判部位来源**：面色发灰是牢狱象，不可说成"肾脏有问题"；眼袋浮肿不可一律说成水肿病
- **照本宣科吓人**：原文多处"希读者遇之必力求其变局"，本意求变而非宣判

### 作者的盲点 / 时代局限

- **医疗条件变化使生死预判失效**：原文的"重病死亡"预判基于 1994 年前的条件；现代 ICU、急救、慢病管理下准确性大幅降低
- **不可验证性**：53 条均为作者自述经验，无第三方统计；预测不准可用"相没看对"解释——不可证伪
- **大量性别/道德污名化条目**（"心术不正""善巫之人""非处女相"等）：以长相给人贴道德标签，现代语境必须过滤，禁止用于评价他人
- **原文未展开**：多条（xz01/02 等）的"时限""cautions"原文未给，本卡如实标注，未补造

### 容易混淆的邻近方法论

- 与 `tianji-qise-shengsi` 区分: 气色卡=颜色+时限（粗筛），本卡=53 条逐部位细则（细分）
- 与 `tianji-guanrenshu` 区分: 识人卡=人际风险特征，本卡含疾厄/生死/婚姻等更大范围
