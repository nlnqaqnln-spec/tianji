# 小六壬占断

## R — 原文 (Reading)

> "以左手食指/中指/无名指测心血来潮的事或单一事情：大安→一周左右看到结果；留连→事情停止不前/此行不利；速喜→立竿见影马上看到；赤口→有第三者介入/是非；小吉→两周后看到结果；空亡→代表凶。"
>
> — 《天纪》04-紫微斗数笔记 / 05-紫微详解 小六壬段（p37）

> "用法：以当下农历月/日/时的三个数字，从寅位(大安)开始按顺序在左手食指/中指/无名指上数，落在哪宫即为答案。"
>
> — 同上（p37）

## I — 方法论骨架 (Interpretation)

小六壬（俗称诸葛马前课）是一条**轻量、即时的占断流程**，只用来测"心血来潮的单一件小事"，不做人生大判断。骨架如下：

- **六个宫、六句口诀**：大安（吉，一周左右见结果）、留连（停滞不前 / 此行不利）、速喜（吉，立竿见影马上见）、赤口（第三者介入 / 是非）、小吉（吉，两周后见结果）、空亡（凶）。
- **取数**：用**当下的农历月、日、时**三个数字作为输入（如农历三月、初五、午时 = 3、5、7）。
- **落宫**：从**寅位（大安）**起数，按"月 → 日 → 时"三次在左手食指/中指/无名指的六格上依次点数，落到哪一格就是答案。这一步是纯机械数数，顺序不能错。
- **应期**：宫位自带时间信息——大安约一周、小吉约两周、速喜立见；留连主停、赤口主是非、空亡主凶，三者都不主快。
- **用途边界**：只测单一、临时的小事；重大决策不属于它（走人间道 64 卦）。它是一把"顺手一问"的轻工具，不是决策依据。

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-jinqian-gua`（金钱卦起课）的区别: 金钱卦用竹筒六铜板摇卦成六爻卦，需配合卦义与六神断；小六壬只用农历月日时三个数、在手上数六格，流程更轻、结论更直接。二者是不同起课体系。
- 与 `tianji-rendao-64gua`（人间道 64 卦）的区别: 64 卦面向**重大决策**（该进该退、处境分析）；小六壬只面向**单一小事**，不可用于重大决策。
- 与 `tianji-liushen-zhanguan`（六神占断）的区别: 六神卡是"形→象→神"的通用观察语法（测字/观人/风水）；小六壬是固定六宫的独立口诀占法。两者在"六"这个数字上易混，但方法与用途不同。
- 与 `tianji-dayun-liunian`（大运流年）的区别: 大运流年靠命盘推算长期趋势；小六壬是即席占断，与命盘无关。

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①**农历**月、日、时三个数字（须明确告知用户用农历，公历须先换算；缺任一数字须先索要）；②所问之事须为"单一、当下心血来潮的小事"（若为重大人生决策，应转 `tianji-rendao-64gua`）。不得静默以公历替代农历。

**输出契约**：结构化结论，含①三数（月/日/时）、②落宫名与口诀、③吉凶定性、④应期（大安≈1 周、小吉≈2 周、速喜立见；留连/赤口/空亡不主快）、⑤必要免责。须展示"从寅位起数、按序落宫"的过程以便复核。

1. **确认输入为农历并收齐三数**
   - 完成标准: 明确月/日/时三个数；若用户给公历先换算为农历；缺数先索要。
2. **校验事项为"单一小事"**
   - 完成标准: 事项属心血来潮的单件事 → 继续；若为重大决策 → **判停**，转 `tianji-rendao-64gua`。
3. **按口诀落宫**
   - 完成标准: 从寅位（大安）起 → 按"月→日→时"顺序在六格上数；每步落到对应宫；逐步展示过程（六宫固定循环：大安→留连→速喜→赤口→小吉→空亡→回大安）。
4. **查口诀、定吉凶与应期**
   - 完成标准: 落宫对应——大安（吉/一周）、留连（停滞/不利）、速喜（吉/立见）、赤口（是非/第三者）、小吉（吉/两周）、空亡（凶）；输出吉凶 + 应期。
   - 原文补充用例：速喜→寻物/失窃类事项立见（可用此场景快速试算）；留连→签约/出行不利
5. **输出结论并加免责**
   - 完成标准: 给出落宫、定性、应期；声明"仅供文化参考，不构成事实判断"，不用于重大决策或替代专业意见。

## B — 边界 (Boundary) ★

> **本卡属术数占断内容，仅供文化参考，不构成事实判断。**

### 不要在以下情况使用此 skill

- 重大人生决策（婚姻 / 事业 / 投资的去留）——应转人间道 64 卦或相应专卡，不可用小六壬替代。
- 用户给的是公历日期且不愿换算——先换算，不得直接当农历数。
- 用户想测他人隐私或用于操控 / 欺诈——拒绝。

### 作者在书中警告的失败模式

- **把轻工具用于重决策**——小六壬只测心血来潮的小事，用于人生大事属误用。
- **顺序错乱**——必须"月→日→时"依次从寅位起数，顺序错则落宫全错。
- **非农历取数**——用公历数字入占会得到错误宫位。

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **原书无小六壬算例**：无具体落宫示范与验证，可复算性靠口诀本身，实际准确率无法检验——原文未展开具体算例。
- **主观性强**：属文化参考类占法，不构成事实判断，须显式声明。
- **应期表述模糊**："一周左右""两周后"缺精确边界，且不同版口诀对宫义略有差异，本卡以原书 p37 表述为准。

### 容易混淆的邻近方法论

- 与 `tianji-jinqian-gua` 区分: 起课工具不同（手指数格 vs 六铜板摇卦）。
- 与 `tianji-liushen-zhanguan` 区分: 小六壬是固定六宫口诀占法，六神是取象观察语法，同名"六"但体系不同。
