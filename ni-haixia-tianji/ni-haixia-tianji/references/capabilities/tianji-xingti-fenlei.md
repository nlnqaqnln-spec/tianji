# 三停与五形人形体分类

## R — 原文 (Reading)

> 「上停(发髻到眉毛)、中停(眉毛到鼻子)、下停(鼻子到下巴)。三庭相等主贵。下停太短→寿命太短。」
> 「木形：瘦高；火形：干红瘦小；土形：厚重/头圆脚方/手掌厚重；金形：白白方方；水形：圆圆的角度都圆。南人北相/北人南相→非富即贵。」
>
> — 04-紫微斗数笔记 第7页（五形人，单元 u18）

## I — 方法论骨架 (Interpretation)

这套方法解决一个**前置问题**：在看任何具体面相细节（纹路、痣、气色）之前，先给对方做一次**整体层次分类**——把一个人归到「三停比例」和「五行形体」两个坐标系里。

两种分法：

**① 三停分比例**（纵向上中下三段）
- 上停＝发髻到眉毛（原文别处对应少年运 15-30 岁）
- 中停＝眉毛到鼻子（中年运 31-50 岁）
- 下停＝鼻子到下巴（晚年运 51 岁以后）
- 判读：**三停均等＝上上等的相、主贵**；上中停长而下停短属「正常」；**下停太短＝晚年不好、寿命较短**。

**② 五形分形体**（横向五行归类）
- 木形＝瘦高；火形＝干红瘦小；土形＝厚重、头圆脚方、手掌厚重；金形＝白白方方；水形＝圆、每个角度都圆。
- 判读核心是**「纯度」**：越纯越贵，混杂不纯者平常。
- **反相法则**：南人北相（南方人高大魁梧）或北人南相（北方人精干）→ 非富即贵。
- 旁证特征：手软如棉、正面不见耳、五官开阔、走路龙行虎步、声如洪钟 → 大贵相；五官紧凑 → 容易想不开。

一句话：这是**面相判断的分诊台**——先定「你这人整体属于哪一档、哪一形」，再去谈具体宫位与纹路。

## A1 — 书中的应用 (Past Application)

> 原书未提供独立的三停/五形命例（无具体人物、无断语结果）。以下为**合成演练**，按 p26/p27/f21 原文规则复算，不冒充作者经历。

### 合成演练 1: 三停比例的判断
- **输入（问题）**: 一个求测者，相貌为上停（额）与中停（眉鼻）都较长，下巴明显偏短。
- **方法执行**: 量三停比例 → 上中长、下停短 → 查规则：「上中停长下停短属正常」；再确认下停是否「太短」。
- **结论/预期输出**: 若仅属正常比例 → 不主凶；若下停**过短** → 判「晚年不好、寿命较短」，对应限在 53-62（出处 xz32）。
- **来源**: p26 / xz32（合成演练）

### 合成演练 2: 五形人归类
- **输入（问题）**: 某人个头不高、身形厚重、头圆、脚方、手掌厚。
- **方法执行**: 对照五形标准 → 厚重 + 头圆脚方 + 手掌厚 → 归**土形**；再评纯度（是否掺杂其他形）。
- **结论/预期输出**: 若为纯土形 → 「非富即贵」，判为贵格、命运层次偏厚；若杂而不纯 → 降为平常。
- **来源**: p27 / f21（合成演练）

**标注**: A1 全部为合成演练；原书三停/五形段落未附具名命例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **初见面相/照片做整体判断**：「帮我看看这个人面相整体怎么样（先别抠细节）」
2. **对比两人层次**：「这两个人谁面相更好/更有贵气」
3. **自我评估先天层次**：「我这体型/脸型属于哪种人」「我下巴短是不是晚年不好」
4. **面相判断的前置步骤**：「看面相要从哪儿看起」
5. **考据**：「什么是三停」「五形人怎么分」「南人北相是什么意思」

- "三停 / 上停中停下停 / 五形人 / 木形火形土形金形水形"

### 与相邻 skill 的区分（初稿）

- **与 `tianji-mianxiang`（面相十二宫）的区别（阶段 4 必验的近邻负例对）**：
  - **本卡**处理**形体整体分类**——五形归类（木火土金水）与三停**比例**（上中下三段的长短均衡）。输出的是「这个人属于哪一形、三停是否均等」的整体层次。
  - **`tianji-mianxiang`** 处理**具体宫位/纹路/痣的吉凶**——面相十二宫（命宫印堂、夫妻宫奸门、财帛宫鼻子……）以及各宫上的纹路、痣、气色对应的吉凶。
  - 判别口径：问「整体是什么形/三停是否均等」→ 本卡；问「这个部位的纹路/痣代表什么」→ `tianji-mianxiang`。
- 与 `tianji-qise-shengsi`（气色）：本卡是**静态、先天**分类；气色是**动态、短周期**信号。

- **⭐ 与 `tianji-mianxiang`（面相十二宫）的区分（定稿/近邻负例）**：同看一张脸，但层级不同。
  - 本卡输出**整体分类**：五形归属（木火土金水）、三停比例、南人北相/北人南相 → 断"先天层次"。
  - `tianji-mianxiang` 输出**宫位吉凶**：印堂/奸门/泪堂等具体宫位的纹路与痣 → 断"某方面吉凶"。
  - 判据：问题里出现"什么形/面型/三停"→ 本卡；出现"哪个宫/这颗痣/这条纹"→ `tianji-mianxiang`。

## E — 可执行步骤 (Execution)

**输入契约**（必需字段）：
- `三停测量`（三选一或量化：均等 / 上中长下停短 / 下停太短）
- `五形特征`（枚举可多选：瘦高 / 干红瘦小 / 厚重头圆脚方手掌厚 / 白白方方 / 圆润各角度都圆）
- `地域体貌反差`（枚举：南人北相 / 北人南相 / 无）
- 可选：`旁证特征`（手软如棉 / 正面不见耳 / 五官开阔 / 龙行虎步 / 声如洪钟 / 五官紧凑）
- 缺失关键项（如看不到全身形态）时：明确告知「形体分类需全身或半身照，仅凭脸部只能做有限判断」，不得静默猜值。

**步骤**：

1. **量三停比例**
   - 完成标准：输出上/中/下停相对长短（均等 / 上中长下短 / 下停太短）。
   - 分支：均等 → 记「上上等，主贵」；下停太短 → 记「晚年不好、寿短（限 53-62）」；上中长下短 → 记「正常」。

2. **归五形**
   - 完成标准：给出主形（木/火/土/金/水），并标注是否有兼形（如土兼金）。
   - 判停点：若五形特征互相冲突、无法判定主形 → 输出「形体混杂，属平常相」，不强行归类。

3. **评纯度**
   - 完成标准：给出「纯 / 偏纯 / 混杂」三档；纯度高 → 「非富即贵」，混杂 → 「平常」。

4. **套用反相法则与旁证**
   - 完成标准：若命中南人北相/北人南相 → 标注「非富即贵」；逐条核对旁证特征并列出。

5. **汇总整体层次**
   - 完成标准：输出「三停结论 + 主形 + 纯度 + 反相/旁证命中」四栏合并的整体判定。

**输出契约**（结构化）：
- `三停结论` / `主形（含兼形）` / `纯度档位` / `反相法则命中` / `旁证特征清单` / `整体层次结论`
- 完成标准：各字段非空；结论只给「层次分类」，不越界到具体纹路吉凶（那属 `tianji-mianxiang`）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **需要具体宫位/纹路/痣的吉凶**时（如「他奸门有纹代表什么」）→ 用 `tianji-mianxiang`，本卡只做整体分类。
- **需要近期吉凶/时限**时 → 用 `tianji-qise-shengsi`。
- **以形体给他人贴命运标签**用于招聘、婚配、评价等现实决策——见下方歧视风险。

### 作者在书中警告的失败模式

- **不评纯度就下结论**：五形的关键是「越纯越贵」，只认形不认纯度会误判。
- **只凭脸部做形体分类**：三停/五形本需全身形态（身形、手脚、体态），仅凭脸部照片信息不足。

### 作者的盲点 / 时代局限（据 BOOK_OVERVIEW 批判）

- **面相歧视风险（重点）**：「南人北相非富即贵」「五官紧凑容易想不开」等，把可变量（身材、地域）与不可验证的命运直接挂钩，具有**污名化与地域/体貌歧视风险**。可用于自我文化兴趣，**不得**用于评价、筛选、歧视他人。
- **性别刻板**：形体分类常用于「女身男命」等表述，带传统性别观念（BOOK_OVERVIEW 已标）。
- **不可证伪**：「三停均等主贵」无统计数据支撑，属经验断言，且预测不准时可归因于「看得不够细」。
- **「比例」无依据**：上上等/正常/太短的界线是口头判定，无客观阈值。

### 容易混淆的邻近方法论（阶段 4 验证重点）

- **`tianji-mianxiang`**：同为面相，但**层级不同**——本卡＝整体形体分类（五形/三停比例）；`tianji-mianxiang`＝具体宫位/纹路/痣的吉凶。二者为**近邻负例对**：若阶段 4 无法稳定区分（用户问整体→误入宫位卡，或问纹路→误入本卡），本卡应回退为 router 而非独立入口。
- `tianji-qise-shengsi`：动态 vs 静态信号之别。
