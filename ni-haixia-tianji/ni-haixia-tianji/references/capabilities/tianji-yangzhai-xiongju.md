# 阳宅凶局识别与以卦化解

## R — 原文 (Reading)

> "解此局惟水火既济卦可成，可令其脱胎换骨。"（坎卦段）
> "困之于人大矣……一、体弱多病，限不过三十岁。二、性刚烈，独行独断。三、婚事不成，多有阻滞。四、财禄不守，只有一线生机，故从商必凶。解之唯大过可也。"（泽水困段）
>
> — 03-地脉道 第贰拾柒页（坎卦化解段）；第叁拾叁页（泽水困段）

## I — 方法论骨架 (Interpretation)

地脉道不只判吉凶，还给每个凶卦配了一条出路。流程是四步：先用名位判断锁定当前成立的
**凶卦**（如次子居震=水雷屯、父居坤=天地否、母居离=地火明夷、三女居坎=泽水困），
认出该卦的危害清单；再查**化解卦**——每个凶卦原文都指定了一个对治卦（坎卦→水火既济、
困卦→泽风大过、随卦→巽为风），这是"以卦解卦"；第三步**改方位**，让当事人搬到化解卦对应的
九宫位置；最后**等变局**，配合流年或在某个家庭事件（如长兄成婚）后局自消。

化解的原理不是消灭凶象（不可能），而是"**换位=换念**"——人换到不同方位后想法自动改变，
行为随之改变，命运被改写。原文对化解的合法性有强约束：靠的是改位与心念，不是符咒、法器
或风水摆件。同时要记住命+运+宅三才联动——阳宅凶卦只有在命上本有灾信号、大限流年又配合时
才真正"成灾"，时间尺度约三字成灾（少则三月、多则三年）。

## A1 — 应用示例 (Application Example)

**原书给出完整照例（原书案例，含成立条件+凶象+化解卦）。**

- **输入**：三女居坎位（正北）。
- **方法怎么执行**：
  1. 识别：三女（兑身份）入坎位 → 内外卦相叠 → 得**泽水困**卦；
  2. 断凶象：按原文四项——①体弱多病、寿不过三十；②性刚烈独断；③婚事不成多阻滞；④财禄不守、从商必凶；
  3. 选化解卦：原文指明"解之唯大过可也"→ 泽风大过；
  4. 改位动作：让当事人移出坎位、改住化解卦对应方位。
- **结果说明**：原文明确给出成立条件与对应化解卦，但**未说明改位后的实际应验结果**（未说明）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 家中已出现具体凶象（成员重病/婚事屡败/持续破财），想排查是否与住位有关。
2. 已判出某个凶卦（如天地否/泽水困），问"有没有办法化解/往哪个方位搬"。
3. 想知道某个凶卦的危害到底有哪些、严重到什么程度。
4. 对比"改位化解"与"买风水物品化解"到底哪个是本体系的做法。

## E — 可执行步骤 (Execution)

**必需输入**：当事人身份（父/母/长男/长女/次子/三女等）＋实际所居方位（八卦位）；可选：命盘灾信号、当前大限流年、居住时长。缺身份或方位则应先询问。

1. **识别凶卦**
   - 完成标准：写出卦名（如水雷屯/天地否/地火明夷/山地剥/泽水困）并列出原文对应危害清单。
   - 判停点：若所判之卦不在已知凶卦清单内，或身份/方位无法定位 → 停止，标注"该局超出本卡覆盖/信息不足"。

2. **选定化解卦**
   - 完成标准：查表给出该凶卦的指定化解卦——已知化解链路：坎卦→水火既济、困卦→泽风大过、随卦→巽为风、涣卦→巽为风（风卦可立解）；原文未给出化解卦的凶卦，须写「原文未展开化解卦」。
   - 完成标准：核实化解卦是否在原文中确有此对应，不自造配卦。
   - 注意：部分卦明确不适用地理化解——如雷水解卦「出家为唯一可解之人事手段」——遇此类标注「不适用地理化解/需特殊人事手段」。

3. **改位动作**
   - 完成标准：给出目标方位（搬到化解卦对应九宫位）与一句"换位=换念"的原理说明；动作须可判断是否执行。

4. **用三才校验并附变局说明**
   - 完成标准：核对命上是否有灾信号、大限流年是否配合（三字成灾）；写出该局可能的变局条件（如成婚后局消）与时间尺度（约三月—三年）。

**输出契约**：一条链路 = 「凶卦名 + 危害清单 + 化解卦 + 改位方位 + 三才校验 + 变局条件」；缺化解卦或缺改位方位即视为未完成。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- **现代公寓/租房/小户型不适用传统多代同住前提**：本框架依赖"家庭成员按八卦身份各据一方位"的户型前提；单身独居、合租、开间/一居室、无法确定九宫中心的情形不能建立有效卦局，勿强行套用。
- 当事人已确诊疾病/正在就医时，改位建议不得替代治疗——本卡不构成医疗建议。
- 纯名词查询（"泽水困是什么卦"）无需走执行步骤。

### 作者在书中警告的失败模式

- 只认凶卦不去化解，或反过来"住了凶宅就一定出事"——原文强调命+运+宅三才缺一不成灾。
- 用买风水物品/画符/请法器替代"改位换念"（原文明确否定的化解路径）。
- 忽略变局时间窗口，把静态卦当永久判决。

### 作者的盲点 / 时代局限

- 依赖传统多代同住、成员齐全的居住模型，对现代城市居住形态解释力有限。
- 卦-凶象-化解的对应出自传统术数体系，缺现代实证；应作文化框架而非事实断言。
- 部分凶卦原文只给"化解卦"而**未展开完整改位步骤与应验结果**，遇此类情况须如实标注"原文未展开"，不补造。

### 容易混淆的邻近方法论

- `tianji-yangzhai-mingwei`——常规名位判断，本卡是凶局排障；两者共用"内卦外卦"但仍为不同任务。
- 传统风水化解手段（摆件/罗盘/水法）——本卡的化解是"以卦解卦+改位换念"，与摆设类手段不同。
