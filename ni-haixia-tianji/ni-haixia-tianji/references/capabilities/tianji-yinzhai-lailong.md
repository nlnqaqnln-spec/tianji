# 阴宅来龙朝向与命盘五行匹配

## R — 原文 (Reading)

> "如果祖父来的时候，我们知道戍宫祖父是葬的位置，正好是你的命里面，戍向正好是祖父的宫…所以我们的八字命格的，曾祖父、曾祖母最好跟他们本身承受的风水的来龙是相生的，或者是比肩的。"
>
> — 01-天机道 斗数延伸 / 测龙段（f20）

## I — 方法论骨架 (Interpretation)

这是把**阴宅风水**与**命理**接起来的匹配框架：不是单看一块地好不好，而是看那块地"承不承受得住"某位祖先（及后代）的命格。设定上是"内外卦 + 五行 + 阴阳"三层：

- **八卦内外卦设定**：来龙（山势走向）＝外卦，朝向（穴口面向）＝内卦；内外卦相叠成六十四卦之一，以此判吉凶。
- **来龙五行**：按十二地支取五行——寅卯＝木，巳午＝火，申酉＝金，亥子＝水，辰戌丑未＝土。
- **命盘宫位五行对应**：紫微十二宫中某宫对应墓主祖先关系（如戌宫＝祖父），取该宫的五行属性与来龙五行做比较：**属性相同＝比肩（吉、相合）；属性相生（如土生金）＝吉；属性相克＝凶**。
- **阴阳匹配**：阳生阳、阴生阴为好；阳配阴 / 阴配阳则不好，作为叠加结论。
- **反向扩展**：框架还可由命盘**逆推**往前几代祖先所承受的风水来龙属性（属体系内推演）。

## A1 — 应用示例 (Application Example)

**合成演练（原书未提供完整案例）。** 依据 verified.md u28 的 walkthrough 输入构造，按原文规则可复算：

- **输入 / 问题**：来龙属**木**；对应墓主的星宫属**水**。问"来龙与命盘匹配与否"。
- **方法怎么执行**：
  1. 由来龙所在十二地支取五行 → 木（寅 / 卯）；
  2. 由命盘定位对应祖先宫，取其五行 → 水（亥 / 子）；
  3. 做五行比对：水生木。
- **结果说明**：水生木＝相生 → 判**吉**，输出"来龙与命宫相生，匹配良好"的结论。此为按原文反推"木"来龙与"水"宫相生的**可复算演练**，**非原书亲历案例**；原文未提供实际案例，也不给出应验结果，故不冒充作者经历或现实结果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 直系祖先（祖父母 / 曾祖父母）安葬，问"这块地的来龙朝向跟我命盘合不合""葬了对我好不好"。
2. 已有命盘宫位信息与一处来龙朝向，想按五行比肩 / 相生 / 相克判断吉凶。
3. 想由自己的命盘**反推**前几代祖先所葬风水来龙的大致属性。
4. 已在做堪舆（寻穴立向），想再加"与命主五行匹配"这一层校验。

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-kanyu-longxue`（堪舆学）的区别: 堪舆卡是**室外风水平面技法**（龙穴砂水、取穴立向）；本卡是在会堪舆的基础上做**来龙-命盘的五行动态匹配**，属"命理 × 风水"的交叉判断。用户单独问"怎么看风水"→堪舆卡；问"来龙和我命盘合不合"→本卡。
- 与 `tianji-sancai-yiguo`（三才与以果决行）的区别: 元命题卡讲"命+运+宅三才联动"的总规则；本卡是阴宅层面的具体匹配技法。阶段 3 回填定稿。

## E — 可执行步骤 (Execution)

**输入契约（必需，前提强）**：①准确的命盘（紫微十二宫，尤其目标祖先对应宫的五行）；②准确的来龙五行（十二地支）与朝向；可选：阴阳匹配信息。
**缺失处理**：缺"命盘宫位-祖先对应"或"来龙地支"任一项 → 应先索取；本卡的前提是两侧都有可比的五行值，缺一侧则无法匹配，**不得静默猜值**。

**输出契约**：一条匹配结论 ＝「内外卦名 + 来龙五行 + 命宫五行 + 五行关系（比肩/相生/相克）+ 吉凶结论 + 阴阳匹配」。缺"来龙五行"或"命宫五行"即视为未完成。

1. **确立内外卦**
   - 完成标准: 来龙定为外卦、朝向定为内卦，并写出叠加所得卦名。
2. **取来龙五行**
   - 完成标准: 由来龙所在十二地支写出五行（寅卯木 / 巳午火 / 申酉金 / 亥子水 / 辰戌丑未土）。
3. **取命盘宫位五行**
   - 完成标准: 定位墓主祖先对应宫（如戌宫＝祖父），写出该宫五行。
   - 判停点: 若无法确定"宫位-祖先对应"，停止并标注"命盘宫位-祖先对应缺失，无法匹配"。
4. **五行比对定吉凶**
   - 完成标准: 按规则判——同＝比肩（吉）；相生＝吉；相克＝凶；写明判定依据。
   - 判停点: 若两侧五行信息不足任一，停止，不臆断。
5. **阴阳匹配校验**
   - 完成标准: 判阳生阳 / 阴生阴为佳、阳配阴 / 阴配阳为不佳，作为叠加结论。
6. **（选做）反向扩展**
   - 完成标准: 如需反推前几代祖先来龙属性，按命盘宫位逆推，并标注为体系内推演。

## B — 边界 (Boundary) ★

> **本卡属风水/命理内容，仅供文化参考，不构成事实判断。**

### 不要在以下情况使用此 skill

- 无法确定"命盘宫位-祖先对应"时——本卡可执行性**强依赖准确宫位-祖先对应**，对应关系不成立时结论无效，不得强行套用。
- 现代城市公墓、无明确来龙朝向的安葬环境——来龙朝向信息不可得时本卡不适用。
- 取代现代殡葬、法律、家族财产相关实务判断。

### 作者在书中警告的失败模式

- 忽略前提：宫位-祖先对应不准时仍强行匹配（本卡最典型的误用）。
- 只看五行不看阴阳：只判相生相克、漏掉阳配阴 / 阴配阳的匹配问题。
- 把匹配结论当成对葬事的唯一判据，忽略堪舆主干的结穴 / 立向核查。

### 作者的盲点 / 时代局限

- **前提过强**：需同时具备准确命盘宫位-祖先对应与来龙朝向，现实中往往缺失。
- "某宫＝某祖先""来龙五行"均为传统术数设定，缺现代实证。
- 原文用口语举例说明，**未给出完整照例与应验结果**；原文未展开的细节须如实标注，不补造。

### 容易混淆的邻近方法论

- `tianji-kanyu-longxue`——室外风水主干；本卡是来龙-命盘匹配的交叉层。
