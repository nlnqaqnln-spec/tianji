# 紫微格局判断（日月反背/半空折翅/桃花格）

## R — 原文 (Reading)

> "日月反背（白天月亮/夜间太阳为陷）：1.工作披星戴月，晚上比白天忙；2.六亲不靠；3.性情非常刚燥；4.一般都要离开家乡去外地发展，让父母担心——克父母。"
>
> — 《天纪》04-紫微斗数笔记 / 05-紫微详解 格局段（p17）

> "半空折翅格：命宫在巳或亥宫，廉贪落陷在对冲命宫，天罗地网，大限在中年（30岁左右），中年横夭。……化解法：过继给别人养（二姓一生）。"
>
> — 同上（p18）

> "红鸾天喜在父母宫/朋友宫/兄弟宫主偏房格；天喜红鸾在凶星所在宫相会→婚姻不成；天喜/红鸾在福德宫→主多婚。"
>
> — 同上（p19）

## I — 方法论骨架 (Interpretation)

"格局"是紫微斗数里比单星、比宫位更高一层的判断单位——它不看某颗星单独的意思，而是看**一组星在特定宫位组合下形成的固定公式**。因为成格条件明确，所以命中率高、结论硬。本卡管三类格局：

- **日月反背（凶）**：太阳与太阴双双落陷（紫微在丑未必成此格）。后果固定四条：工作昼夜颠倒、六亲无靠、性情刚燥、离乡克父母。它是"不见光"的格局，核心是六亲与性情层面受损，不是直接断死。
- **半空折翅（大凶，可化解）**：命宫在巳或亥、廉贞贪狼**落陷在对宫冲命**、且三方四正无吉星化解。后果是中年（约30岁）横凶。**关键在化解法**：①过继给别人养（"二姓一生"，改姓氏归属）；②未婚前睡东宫、脚朝紫微天府的方位（借解厄星制化）。这是全书少数"凶格给出明确化解路径"的例子之一。
- **桃花格/偏房格（中性偏凶）**：核心看**红鸾天喜落宫**——在命宫/夫妻宫为吉；在父母宫/朋友宫/兄弟宫=偏房格；在福德宫=多婚；若与凶星同宫相会=婚姻不成。它判断的是婚姻形态与成败，不是财运。
- **机月同梁格**："定为吏也"——天机/太阴/天同/天梁四星会合，主公家单位工作；有科权禄会到，才宜从商（笔记第49页）
- **府相会命格**：天府/天相分别位于财帛/事业宫，与命宫三足鼎立→天生辅佐之人才（笔记第24页）
- **雄宿朝元格**：廉贞孤星独守申或寅入命，利军人和商人，但后期会毁在桃花上（笔记第14页）
- **判读铁律**：先查成格条件是否**全部满足**，再断后果；不满足条件的相似盘不算此格。断凶格时必须同时给出原文的化解法（尤其半空折翅）。

## A1 — 原书案例 (Past Application)

### 案例 1: 男命半空折翅格与化解（c02，reported_case，来源 05-紫微详解.md）
- **出处**: 民国54年十月二十八辰时男命（阴男），紫微在丑、命宫在未
- **方法执行**: 命宫在未（天相守命）→ 三方四正见夫妻宫廉贞贪狼**落陷** → 判为半空折翅格；子女宫太阴化忌 + 日月反背
- **结论**: 大限23-32（夫妻宫）婚姻大凶；大限33-42 未来十年无大运
- **化解（原文给出）**: ①娶二婚妻（离过婚的）；②娶大七岁以上或小七岁的妻子；③阳宅调整。八字合婚原则：先天婚凶者找"八字不合"的人结婚才安全
- **结果**: 原文记"流年32岁妻子感觉人生乏味选择自杀"；未提供独立第三方验证

### 案例 2: 男命日月反背夹命 + 半空折翅（c04，reported_case，来源 05-紫微详解.md）
- **出处**: 民国44年三月初五未时男命（阴男），紫微在卯、命宫在申
- **方法执行**: 日月反背夹命（太阳陷子、太阴陷寅）→ 一世辛劳；太阴化忌在对宫冲命 → 半空折翅格（30岁左右先天绝症/大灾）
- **结论**: 双格叠加：日月反背（六亲不靠、一世辛劳）+ 半空折翅（中年大限）
- **化解**: 原文以"孤星独守""庙旺落陷差异"等断法展开，未在此例另给化解细节
- **结果**: 原文未明确交代后续实际结果

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户命盘被批出"半空折翅"，来问"这是什么、严重吗、有没有救"
2. 用户问"我日月反背是不是命不好 / 为什么我离家在外、跟家人不亲"
3. 用户问"我红鸾天喜在父母宫，是不是婚姻不好 / 会不会多婚"
4. 用户问"我这盘算什么格局"但目标明确指向吉凶格而非总格方向

### 语言信号 (中英双写)

- "半空折翅是什么 / 我是不是半空折翅 / 这格有救吗"
- "日月反背好不好 / 我为什么六亲不靠 / 命里不见光"
- "红鸾天喜在哪一宫 / 偏房格 / 会不会多婚"
- "Ziwei pattern / Ban Kong Zhe Chi / half-wing / 格局成不成"

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-ziwei-pandu`（三方四正判读）的区别: 判读卡输出"总格方向"（官/商/本地/外地）这类软结论；本卡输出"成不成格"的硬判定与化解法。实际使用中判读卡先定位四宫，再移交本卡做格局判定
- 与 `tianji-jiehun-zeou`（结婚择偶）的区别: 本卡里的"桃花格/偏房格"只**判定婚姻形态**；婚姻凶象的具体**择偶与化解策略**（选八字合/不合、嫁大七岁等）由择偶卡执行
- 与 `tianji-liuqin-gong`（六亲宫）的区别: 日月反背的"六亲不靠"是格层面的整体断语；六亲宫卡是逐宫（兄弟/父母/子女/夫妻）的细断
- 与 `tianji-lumajiaochi`（禄马交驰）的区别: 本卡覆盖吉凶全谱格局；禄马交驰是财富单点格，已独立成卡

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①命宫所在地支宫位；②命宫对宫（迁移宫）的主星及**亮度**；③三方四正是否有吉星（左辅右弼/天魁天钺/文昌文曲等）；④红鸾、天喜所在宫位；⑤太阳、太阴所在宫及亮度。缺亮度或缺红鸾天喜落宫时先索要，不得静默猜值。

**输出契约**：结构化结论，含①命中格局名（可多个并存）、②成格依据（逐条列满足的条件）、③后果断语（按原书）、④若为半空折翅/日月反背等有化解法的格局，必须附原文化解步骤。每条须标注"依据某星某宫某亮度"。

1. **查日月反背**
   - 完成标准: 检查太阳、太阴是否双双落陷（或紫微在丑/未）；是则记"日月反背格"并列出四条后果；判有无"日月反背夹命"（命宫两侧日月均陷）
2. **查半空折翅**
   - 完成标准: 逐条核对——命宫是否在巳/亥？对宫是否廉贪**落陷**？三方四正是否**无吉星**？三条**全部满足**才成格
   - 判停点: 若对宫廉贪为庙旺，则不构成半空折翅，停止本格判定（庙旺=积富，是相反结论）
3. **给出化解（半空折翅/日月反背必做）**
   - 完成标准: 半空折翅 → 输出"过继二姓一生""未婚睡东宫脚朝紫府"两条化解；日月反背 → 输出"离乡外出发展有利"的方向指引
4. **查桃花格/偏房格**
   - 完成标准: 定位红鸾天喜落宫——《父母/朋友/兄弟宫》→偏房格；《福德宫》→多婚；《与凶星同宫》→婚姻不成；《命宫/夫妻宫》→吉。输出对应结论
5. **合成输出**
   - 完成标准: 若多格并存，按严重度排序（半空折翅 > 日月反背 > 桃花格），逐格给依据与化解；提示格局非绝对，需与三方四正/四化合看

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想问"我这辈子方向"——先走 `tianji-ziwei-pandu`，本卡只答"成不成某个格"
- 命盘缺关键亮度信息——无法判成格，先补齐
- 用户要的是具体某一宫的含义（如"父母宫怎么看"）——走六亲宫卡，不套格局

### 作者在书中警告的失败模式

- 条件不全就断格——半空折翅必须"巳/亥命 + 对宫廉贪落陷 + 三方四正无吉星"三条齐全，缺一不可
- 断凶格不给化解——原书每个凶格都配化解法，只报凶不给出路违背"以果决行"
- 看到红鸾天喜就断良缘——落宫不同判若两格，在福德宫反主多婚

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **格局非绝对，原书自己承认**：c10 案例中"紫易奇缘注"明确写道名嘴周某波、林青霞父亲（军医）均未死于所断兵祸格，须"看伤使与化三忌"——故"中年横夭"类断语不可作为绝对预言
- **"过继二姓一生"的化解**依赖特定家族结构，现代社会可行性受限，原文未讨论现代替代方案——**原文未展开**
- **桃花格涉及婚姻形态的判语偏传统**：偏房/多婚等表述带旧时代一夫多妻语境，现代需过滤
- **命例无第三方验证**，断语准确率无法独立检验

### 容易混淆的邻近方法论

- 与 `tianji-ziwei-pandu` 区分: 判读卡定方向，本卡定格局吉凶
- 与 `tianji-jiehun-zeou` 区分: 本卡判"婚姻形态"，择偶卡给"择偶与化解策略"
