# 紫微斗数排盘全流程

## R — 原文 (Reading)

> "1.润月生人以下个月为论；2.子时生人：23:00-0:00为晚子时，日子按前一天算；
> 0:00-1:00为早子时，日子按第二天算。"
> "命局按六十甲子纳音算：水2局/木3局/金4局/土5局/火6局。阳男阴女顺行大运；阴男阳女逆行大运。"
>
> — 《天纪》04-紫微斗数笔记 第6-8页（p40 / p19）

> "批命流程：先看总格→六亲→流年。命好不如限好。十年大运为主，小流年为辅。"
>
> — 《天纪》04-紫微斗数笔记 第6-8页（f19）

## I — 方法论骨架 (Interpretation)

排盘是把"出生时刻"翻译成"十二宫星图"的确定性入口流程，口径一旦错则全盘错位。骨架分五步：
① **定盘基**：以年柱为重（斗数重年柱，不同于子平重日柱），先把年柱定位好。
② **边界口径**：润月生人视作下一个月；23:00-24:00 出生的晚子时按前一天算，00:00-01:00 的早子时按第二天算。
③ **定局数**：按六十甲子纳音取局——水二局、木三局、金四局、土五局、火六局。
④ **安紫微星再布诸星**：由局数与农历生日定位紫微星，再依次排十四主星、六吉六煞、四化，落入十二宫。
⑤ **定大运方向**：阳男阴女顺行、阴男阳女逆行，几局即从几岁起十年大运。
排盘的产出不是结论，而是"可信的输入"；判读交给下游流程。它的全部价值在于统一边界口径，避免同一个人在不同流派手里排出不同的盘。

## A1 — 应用示例 (Application Example)

**原书未提供完整的端到端排盘算例**（原文只给规则，未附"某生辰→整盘星曜位置"的逐步推演）。以下为**合成演练**，用于验证已知规则，非作者经历：

- **输入**: 某年农历润二月、23:30 出生、男命。
- **方法执行**: ①润月按下月计 → 出生月视作三月；②23:30 属晚子时 → 日子按前一天算；③查年柱纳音定局数（如木三局则 3 岁起运）；④阳男 → 大运顺行；⑤由局数与日数安紫微星，再布诸星。
- **预期输出**: 农历月=次月；时=晚子时（日退一日）；局数=按纳音；起运=3 岁、顺行；给出各步大限宫位。
- **说明**: 本演练严格依 u04 原文规则（润月/子时/纳音/顺逆）复算；因原书未给出紫微星定位的完整起例表，第 ④ 步的逐星落宫在本卡标为"原文未展开"，不得凭空补齐。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 提供了生辰，问"帮我排个紫微盘 / 帮我排命盘"
2. 生辰处于边界（润月、临近午夜），问"我润月生的算哪个月 / 23 点半生算哪天 / 子时怎么算"
3. 想知道自己的"五行局 / 水二局木三局是什么意思 / 几岁起运"
4. 自己排过盘但与别人排的不一致，问"为什么两张盘不一样 / 哪个对"
5. 想确认大运是顺行还是逆行

### 语言信号 (中英双写)

- "帮我排盘 / 排命盘 / 怎么排紫微斗数"
- "润月怎么算 / 子时算哪天 / 晚子时早子时"
- "我是什么局 / 水二局木三局 / 几岁起运 / 大运顺逆"
- "cast a zi wei chart / how to plot my birth chart / leap month rule / late zi hour"

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-ziwei-pandu`（三方四正判读）的区别: 本卡只负责"把盘正确地排出来"，判读卡负责"读这张盘"；排盘是判读的前置步骤，通常被判读流程内部调用，不单独作为结论输出
- 与 `tianji-dayun-liunian`（大运流年）的区别: 本卡只定"起运岁数与顺逆"这一排盘参数，具体每十年落在哪个宫、当年流年怎么走由该卡推
- 与 `tianji-sizhu-minggua`（四柱命卦）的区别: 本卡是紫微斗数体系；四柱命卦是"没有紫微盘时"的另一套独立排盘体系，两者不同源
- 与 `tianji-faxuan-dingshchen`（发旋定时辰）的区别: 出生时辰不确定时，先用发旋卡反推时辰，再回到本卡排盘

## E — 可执行步骤 (Execution)

**输入契约（必需）**：①出生年、月、日、时（农历或可换算的公历）；②性别；③月是否为润月（须显式确认，不可默认按普通月）。缺失任一项应先询问，**不得静默猜时辰或猜润月**。若用户不知准确时辰，先转 `tianji-faxuan-dingshchen` 或如实标注"时辰不确定，盘可能有偏差"。

**输出契约**：一份排盘参数清单——{润月折算后的月份、早晚子时口径与折算日、年柱、纳音局数（水2/木3/金4/土5/火6）、紫微星所在宫、十四主星+六吉六煞+四化落宫表、起运岁数、大运顺逆}。**约定**：本卡采用原书"润月按下月、晚子时退一日"口径，是流派约定而非唯一标准，输出时须注明所用口径；原书未规定紫微星定位的完整起例，涉及逐星落宫时须标注"原文未展开"或以所用软件的安星规则为准并声明。

1. **确认并规范化输入**
   - 完成标准: 年/月/日/时/性别/是否润月六项齐备；润月已按"下月"折算并留痕
2. **处理子时边界**
   - 完成标准: 明确标出早子时（00:00-01:00，按次日）或晚子时（23:00-24:00，按前一日），并写出折算后的日
3. **定年柱与纳音局数**
   - 完成标准: 给出年柱；由纳音得出局数（水2/木3/金4/土5/火6）
4. **安紫微星并布诸星**
   - 完成标准: 依局数与农历生日定位紫微星，排十四主星、六吉六煞、四化入十二宫
   - 判停点: 若原书未给出足够起例无法确定性落宫 → **停止自动补齐**，标注"原文未展开"，转用挂牌口径并声明
5. **定起运与顺逆**
   - 完成标准: 依局数定起运岁数（几局几岁起运）；依性别阴阳定顺行/逆行（阳男阴女顺、阴男阳女逆）
6. **交付并交棒**
   - 完成标准: 输出完整排盘参数清单 + 口径声明；**判停点**：排盘完成后不在此卡下判读结论，转 `tianji-ziwei-pandu`

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是"这盘怎么看/事业怎么样"——那是判读（`tianji-ziwei-pandu`），本卡只排不读
- 用户根本没有可靠出生时间，且不愿提供——排盘无可靠输入，不得硬排
- 用户想要的是"没有紫微盘时用易经起卦"——走 `tianji-sizhu-minggua`

### 作者在书中警告的失败模式

- **口径不统一**：倪师反复强调润月/子时的固定处理；若自行改口径（如润月按本月、晚子时按次日），会导致整盘宫位偏移，全盘皆错
- **重日柱而非年柱**：斗数以年柱定位紫微星，若套用子平"重日柱"的习惯会排错

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **假设出生时辰精确到"时"**：原书默认时辰准确，且润月/子时无歧义；现实中很多人出生时辰不确定（该假设 BOOK_OVERVIEW 明确列为"未被证明的假设"）
- **未附完整安星起例**：原文给出的是规则要点，紫微星定位等起例表"原文未展开"，本卡不代为补齐
- **流派口径差异**：润月/子时在不同流派有不同约定，原书口径只是其一，输出须声明所用口径

### 容易混淆的邻近方法论

- 与 `tianji-ziwei-pandu` 区分: 排盘=建输入，判读=出结论；先排后读
- 与 `tianji-sizhu-minggua` 区分: 一个是紫微斗数排盘，一个是四柱转易经卦，体系不同
