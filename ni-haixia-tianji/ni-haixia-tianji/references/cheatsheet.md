# 决策规则速查 — 《天纪》（天机道·人间道·地脉道·紫微斗数）

| 能力 | 一句话规则 |
|---|---|
| 三才平衡与以果决行（命可化解的总纲） | 命只占1/3，地理+人事占2/3——任何命理结论都必须转成"可调整的方位或行为"。 |
| 阳宅名位相等判断 | 用家庭成员身份×卧室方位查六十四卦——名位相等则吉，不等则凶，改位即改运。 |
| 紫微斗数三方四正判读流程 | 先锁命-财帛-迁移-官禄四宫看方向，再看四化定动力，最后看大运流年定时。 |
| 面相十二宫判断 | 脸上十二宫对应紫微十二宫——先定位宫位，再看纹路与形态断吉凶。 |
| 气色判断与凶事时限 | 四等气色（黄润/黑暗/枯萎/青蓝）对应不同时限——黄润主喜、黑暗主劫、枯青主死。 |
| 观人术·识小人 | 君子难进易出、庸才易进易出、小人易进难出——配合面相特征清单识别。 |
| 三停与五形人形体分类 | 五形（木瘦高/火干红/土厚重/金白方/水圆）+三停均等主贵——越纯越贵。 |
| 人间道六十四卦逐卦解读 | 先定位当前处境的卦与时，再取对应爻的"该怎么做"——观象悟辞而后决行。 |
| 四柱命卦排法（八字转终身卦） | 天干地支取数→阳数和阴数分加→按25/30归约→定上下卦→得先天/后天/流年卦。 |
| 阳宅凶局识别与以卦化解 | 识别凶卦→选定化解卦→改位换念，把"知凶"变成"可执行改位"。 |
| 紫微斗数排盘全流程 | 润月按下月、晚子时算前一日、纳音定局数、阳男阴女顺行——排盘口径统一。 |
| 四化（科权禄忌）判读规则 | 先找科权禄忌落宫，再看其在本宫的含义变化——四化决定动力方向。 |
| 十四主星星性判断 | 每颗主星先看庙旺落陷，再断星性——紫微解厄/天机文官/太阳武官/武曲财星/廉贞次桃花… |
| 六吉星判断规则 | 左辅右弼主辅助、魁钺主科甲贵人、昌曲主才艺——六亲宫单星独守主凶。 |
| 六煞星判断规则 | 空劫主破财、火铃主火厄口角、羊陀主隐小人血光——落陷更凶。 |
| 庙旺落陷定吉凶规则 | 七级亮度看吉凶——庙旺得利平闲陷；吉星丛中煞星落陷必凶，反之平安。 |
| 十年大运与小流年推算 | 命好不如限好——十年大运看三方四正为主，小流年看本宫对宫为辅。 |
| 禄存与禄马交驰格 | 禄存/化禄与天马同宫=禄马交驰，主辛苦赚大钱；叠加巨门入庙为巨富。 |
| 紫微格局判断（日月反背/半空折翅/桃花格） | 有确定成立条件的格局——半空折翅主中年横凶（可过继化解）、日月反背主六亲不靠。 |
| 六亲宫判断规则 | 兄弟/父母/子女/夫妻宫各有断法，夫妻宫必须与福德宫合看——斗数+面相双通道。 |
| 身宫判断与化忌化解法 | 身宫定后天走向；化忌化解分三层——心念戒慎、地理改位、象层先应。 |
| 手相八大宫位判断 | 掌上八宫（乾父母/坎祖业/艮田宅/震妻/巽财禄/离官禄/坤子媳/兑朋友）饱满则吉。 |
| 六神占断与灵机取象 | 一切形、动、声都能归入六神——青龙直贵、勾陈停滞、腾蛇弯曲、玄武偷盗、白虎凶险、朱雀口舌。 |
| 结婚择偶与婚姻凶象化解 | 一世夫妻命选八字合的、二婚命反选八字不合的；女命太阳落陷宜嫁大七岁以上或二婚夫。 |
| 命例集：日月反背与六亲不靠 | 四则日月反背命例的完整断法链条，供类比参考。 |
| 命例集：吉格成格（明珠出海/巨日/英星入庙/日丽中天） | 四则吉格命例，含庙旺前提与成格条件。 |
| 命例集：凶格与六亲推算 | 三则命例（杀破狼丧偶/改运/六亲生肖推算）。 |
| 小六壬占断 | 大安一周见结果、留连停滞、速喜立见、赤口是非、小吉两周、空亡凶。 |
| 发旋反推出生时辰 | 子午卯酉偏左居中、寅申巳亥偏右、辰未戌丑两个以上。 |
| 阴宅来龙朝向与命盘五行匹配 | 来龙为外卦、朝向为内卦，与墓主星宫五行比肩/相生/相克定吉凶。 |
| 金钱卦起课法（六铜板起卦） | 竹筒六铜板摇5-6下，人头为阳、数字为阴，由下往上记六爻成卦。 |
| 六神占断应用法（面部定位/口诀/形之辨识） | 面部六神方位+辨识口诀+各神占断口诀——看神不看形。 |
| 堪舆学（龙穴砂水与立向） | 结穴五条件、朝山取穴"上不过眼下不过心"、八煞黄泉、穿山72龙与透地60龙。 |

| 四化（科权禄忌）的面相/骨相/手相征象 | 化权=颧部（皮骨相连为孤权）、有科无权=师爷相、化禄=手相、化忌=五官挤在一起。 |
