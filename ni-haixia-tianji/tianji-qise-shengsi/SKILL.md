# 气色判断与凶事时限

## R — 原文 (Reading)

> 「黄润主喜事；黑暗如有灰尘一般主劫杀或想不开；枯萎色（头发干枯无光、脸无反射）主肾衰竭将死；青蓝色主死。……看到气色后第一个节气通常就是劫杀发生的日期。」
>
> — 倪海厦《天纪》，04-紫微斗数笔记 第2/23-24页（单元 u17）

> 「苦冷者死……重病时整个印堂青冷掉。」
>
> — 01-天机道【天纪/09归纳总结】1.相术总结（第28020-28347行，单元 u34）

## I — 方法论骨架 (Interpretation)

这套方法把「看脸色」从玄谈变成一套**带时限的观察协议**：气色不只用来看吉凶，更用来推「事情已经发生 / 正在发生 / 即将发生」。

核心分四层：
① **颜色定性**：黄润＝喜事（升官、进财、嫁娶）；黑暗如蒙尘＝劫杀或想不开；枯萎色（发枯、面枯无水光）＝重病将死；青蓝色＝将死。
② **时限定量**：枯焦＝已发生；枯黄＝刚发生、最长两周；暗黑＝将发生。看到气色的当下，翻黄历找最近的节/气，**下一个节气就是观察窗口的上限**（原文另有一处表述为「从节气当天起第七天」异动）——所以这是「观察窗口」，不是「死亡日期」。
③ **部位定位**：印堂（命宫/疾厄）＝当下吉凶；印堂青冷发黑＝重病或牢狱；奸门（夫妻宫）黑黑暗暗＝配偶重病、三年内大凶；命门（鬓角下方）黑＝生死；鼻头像突然发亮＝横财。
④ **叠加升级**：单看一个气色只是提示；当「命盘凶格 + 阳宅死位（西北/西南厨房）+ 面现枯色 + 遇死绝日（四离四绝八天）」同时出现时，原文判为「在数中难逃」——这是**四重叠加**才是最强信号，任何单一项都不构成结论。

一句话：气色是「时间戳」，越枯越暗表示事发得越近；叠的凶兆越多，可信度越高。

### 案例 1: 印堂发黑陪人洗肾者（横死预兆）
- **来源**: 相术总结 xz03（01-天机道）
- **问题**: 一个人陪尿毒症病人去洗肾，自己的印堂却是黑色的
- **方法的使用**: 按「印堂发黑主横死」判——不是病人有问题，而是**陪护者**本人将出车祸
- **结论**: 主横死（意外/横祸/凶杀）
- **结果**: 原书作为「人死之前两个礼拜可以看到气色」的例证引用；实际后续原文未说明。

### 案例 2: 丈夫住西南角 + 奸门黑（配偶大凶）
- **来源**: ce13（05-紫微详解 第9页）
- **问题**: 眼角（奸门/夫妻宫）黑黑暗暗
- **方法的使用**: 判为「重病或大凶，将要发生还未发生」；叠加中年丧偶三相（中停短 / 面大骨粗声沙 / 奸门乱纹黑点），三条具一即成格
- **结论**: 三年内大限必到；鱼尾纹只一条向下＝生离，有叉＋黑暗或印堂发白＝已死
- **结果**: 原书以规则形式给出，未说明具体命主结局。

### 案例 3: 脸上枯老 + 流年杀星落陷 + 绝日（三杀叠加）
- **来源**: ce16 / ce18（05-紫微详解 第23-24页）
- **问题**: 12月25日立冬，17日见到某人面部枯老
- **方法的使用**: 枯老＝将发生之色 → 查流年见诸多杀星相会且落陷 → 查下一个节气前一天为绝日
- **结论**: 「此人死定了」——三凶叠加判为无解之局
- **结果**: 原书作为判定「死兆」的标准范例；命主具体日期原文只说「此人死定了」，未给精确日期。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **⚠️ 医疗场景绝对优先**：凡用户描述的是真实身体症状（脸色发黄、发青、消瘦、水肿、乏力等），**必须先建议就医**。此卡所有内容仅为传统文化观察，**不可替代就医**，**不做确定性死亡断言**，不得用来劝阻或延误诊治。
- 心理危机场景：若用户流露轻生念头（原文「想不开」相关），立即转向心理援助，不做气色推演。
- 用本卡去恐吓他人或自我暗示（「印堂黑＝我要死了」这种推论本身违反原文的叠加原则）。

### 强制免责声明（本卡必写）

> 本卡关于「生死」的内容属于传统相术文化记录，**仅作文化参考**。气色变化与疾病、寿命之间没有经过验证的因果关系。原文所谓「死绝日预判」在现代医疗条件下大幅失效（见盲点）。任何面相观察都不能替代专业医疗诊断与治疗。若本人或家人有健康疑虑，请立即就医。

### 作者在书中警告的失败模式

- **单点定论**：看到黑气色就直接断死，忽略「四重叠加」条件——原文明确「单有其一未必死，叠加则必死」。
- **不分时运与疾病**：把「眉毛下发红（红鸾动）」误当疾病、把气色当纯医学——原文多次提醒「把时运与望诊分开」。
- **照本宣科吓人**：原文多处「希读者遇之必力求其变局」，本意是**求变**而非宣判。

### 作者的盲点 / 时代局限（据 BOOK_OVERVIEW 批判）

- **医疗条件变化使「死绝日预判」失效**：书中「重病死亡」的预判基于 1994 年前的医疗与社会条件；现代 ICU、急救、慢病管理下这类预判的准确性大幅降低。
- **不可验证性**：所有命例均为作者自述，无第三方统计；预测不准时可用「你面相没看对」解释——不可证伪。
- **「比例假设」无依据**：三才各 1/3 属口头断言，本卡涉及的叠加权重同样缺机制论证。
- **面相/气色歧视风险**：以脸色（多为后天可变量，如熬夜、疾病、情绪）对人做命运定性，存在污名化风险，须避免用于评价他人。
