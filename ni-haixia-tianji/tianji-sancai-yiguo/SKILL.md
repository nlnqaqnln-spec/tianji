# 三才平衡与以果决行

## R — 原文 (Reading)

> "天命占1/3，地理占1/3，人事占1/3。算命的意义：地理+人事>天命。"
> "灾厄的化解不是画符念咒，也不是买风水物品，而在地理位置、人间道意念的改变。"

>

## I — 方法论骨架 (Interpretation)

倪海厦把"一个人会怎样"拆成三股力量各占三分之一：天生带来的命（紫微命盘读出的结构）、
住的地方（阳宅方位）、以及自己怎么想怎么做（人间道行为）。关键结论不是"命由天定"，
而是**后两股加起来（2/3）可以压过第一股（1/3）**，所以算命的目的不是宣判，而是找可改的把手。

"以果决行"是配套的决策方式：常规思路是分析原因再推结果，倪师反过来——先用盘/卦/象
把"可能的果"看清楚，再拿这个果来倒推"现在该怎么走"。所以任何命理结论都不能停在
"你命里有灾"，必须再往下落到两条可执行动作上：一是**地理**（改床位/房间方位），
二是**人事**（改行为与心态）。1/3 不是精确数学，而是"命运有调整空间、但要三条腿联动"
的操作性隐喻；化解的载体是方位与意念，不是符咒、玉器或摆件。

  4. 说明边界：两招合起来最多改写 1/3 天命，不能承诺"必解"。

**必需输入**：任一命理结论或处境描述（如"官禄宫化忌""最近诸事不顺"）＋当事人可调整的现实条件（能否改住址/房间/座位/行为）。缺"可调整条件"时应先询问，不静默假设。

2. **不落在天命上收尾**
   - 完成标准：检查是否有"命中注定所以没办法"式结论；若有，改写为可执行项。

3. **产出地理与人事两条动作**
   - 完成标准：地理给出一条方位/位置类动作；人事给出一条行为/心态类动作；每条须可判断是否做到。
   - 判停点：若任一条给不出具体动作 → 本卡输出降为参考性说明，并标注"原文未展开具体做法"。

4. **附边界声明**
   - 完成标准：明确写出"地理+人事最多改写天命这 1/3，不承诺必解"，并声明不替代医疗/法律/财务专业决策。

**输出契约**：一段结论 = 「天命读数」+「地理动作」+「人事动作」+「边界声明」四要素齐备；缺任一要素视为未完成。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 需要专业裁量的问题（确诊病情、法律纠纷、投资/税务决策）——**本卡不可用于替代专业医疗/法律决策**，只能作为当事人自我反省的辅助框架。
- 纯信息查询（"三才是哪三才"这类名词问题）不需要走执行步骤。

### 作者在书中警告的失败模式

- 把"地理+人事>天命"当成"随便改改就一定翻盘"，忽略三才必须联动、缺一不成。
- 用买风水物品/画符/请法器替代真正的改位与改念（原文明确否定此类化解）。

### 作者的盲点 / 时代局限

- 「1/3」更像修辞而非可验证的比例，不具量化意义，勿当公式代入。
- 该体系建立在传统命理/风水世界观上，缺现代实证支持；"方位改念"的因果链未经科学检验，宜作文化框架而非事实断言。
- 原文对"人事"部分着墨较少，操作细则多要依赖人间道六十四卦补足（见 u29），本卡单独使用时人事动作可能偏薄。

### 容易混淆的邻近方法论

- `tianji-yangzhai-xiongju` 的"以卦化解"：那是具体的改位技术，本卡是它背后的合法性基础与总转译规则，并非同一件事。
