# 紫微斗数三方四正判读流程

## R — 原文 (Reading)

> "批命流程：总格→六亲→流年。先看命宫三方四正，再看科权禄忌所在，再批流年大运。"
> "三方四正：命官----财帛官----迁移官----官禄官。宫性：批流年，例流年在财帛，主一年重要在财帛上。"
>
> — 《天纪》04-紫微斗数笔记 第1页（f04 / f10）

## I — 方法论骨架 (Interpretation)

紫微斗数有十二个宫位，逐宫乱看会立刻淹死在几十颗星里。倪海厦的做法是先搭一个固定框架再往里填内容：
- **第一步锁定"三方四正"**：把命宫、财帛宫、官禄宫、迁移宫这四个宫当成一个整体——命宫与财、官两宫构成等边三角（三方），再各自加上正对面的宫（四正）。这四个宫决定一生的"总格方向"（是走官还是走商、本地还是外地）。
- **第二步看宫性**：每个宫自带一个"主题"，不看星也能先定性——流年走到财帛宫，当年大事在钱；走到迁移宫，当年有驿马（不必等天马星）；走到夫妻宫，当年大事在婚姻。
- **第三步看四化**：在四宫框架内读科权禄忌落在哪一宫，判断动力来源（详见 `tianji-sihua`）。
- **第四步才落到星曜与大小限**：十年大运看三方四正为主，小流年只看本宫与对宫为辅。顺序不可倒——先框架、后四化、最后流年，否则会被星的细节带偏。

## A1 — 原书案例 (Past Application)

### 案例 1: 女命贪狼在午入命（c01，reported_case）
- **出处**: 05-紫微详解.md，民国50年三月初五戌时女命（阴女）
- **方法执行**: 先锁命宫（贪狼在午）→ 读三方四正：官禄宫七杀+擎羊且无化权，财帛宫天钺+化科，夫妻宫廉贞+天府无科权禄 → 再读四化（34-43岁太阳化忌落在福德宫）
- **结论**: 贪狼午宫为武官星（非桃花格）；官禄无实权，财帛靠一技之长漂泊在外，夫妻为工薪族且无子，大限34-43丈夫有劫
- **结果**: 原文以"无子、离祖外出、克父母"断；未说明后续验证

### 案例 2: 男命天相在未守命（c02，reported_case）
- **出处**: 05-紫微详解.md，民国54年十月二十八辰时男命（阴男），紫微在丑
- **方法执行**: 命宫在未（天相守命，位高无权的佐才）→ 三方四正见夫妻宫廉贞贪狼落陷 → 四化：子女宫太阴化忌
- **结论**: 判为"半空折翅格"，大限23-32（夫妻宫）婚姻大凶
- **结果**: 原文记"流年32岁妻子感觉人生乏味选择自杀"；未提供独立第三方验证

### 与相邻 skill 的区分 (初稿)

- 与 `tianji-ziwei-paipan`（排盘）的区别: 排盘负责把生辰变成十二宫；本卡负责在排好的盘上做判读，输入是已完成排盘的命盘
- 与 `tianji-sihua`（四化）的区别: 本卡先定"看哪几个宫"的框架，四化卡专责科权禄忌的宫位含义；实际使用中本卡先跑、四化卡随后
- 与 `tianji-ziwei-geju`（格局）的区别: 格局是四宫锁定后的具体成格判定，本卡只输出方向性总格结论
- 与 `tianji-dayun-liunian`（大运流年）的区别: 本卡给出判读顺序中的时间层位置，具体的十年/一年推算由该卡执行

- 与 `tianji-ziwei-paipan`：排盘是**前置步骤**，本卡是判读流程（依赖关系）。
- 与 `tianji-sizhu-minggua`：两套独立体系。有完整生辰要精细十二宫盘 → 本卡；无紫微盘或用易经卦象 → `tianji-sizhu-minggua`。
- 与 `tianji-rendao-64gua`：本卡从命盘读"一生的果"；人间道从当前处境取卦得"当下该如何进退"。

## E — 可执行步骤 (Execution)

**输入契约（必需）**：一张已排好的十二宫命盘，须含①十二宫宫名与位置、②各宫星曜（含亮度庙旺落陷）、③生年四化落宫、④性别与阴阳（顺逆）。缺四化落宫或缺命盘本身应先索要，不得静默猜值。若只有生辰无盘，先转 `tianji-ziwei-paipan`。

**输出契约**：结构化判读结论，含①总格方向（官/商/自由业/专业技术 + 本地/外地）、②四宫逐宫要点、③关注宫位提示、④当日/当年方向提示。每项须给"依据宫位+星曜/四化"。

1. **锁定四宫**
   - 完成标准: 明确指出命宫、财帛宫、官禄宫、迁移宫各在哪个地支宫位，标出各自对宫
2. **读宫性、定总格方向**
   - 完成标准: 从命宫与官禄宫给出"官星还是财星/正财还是偏财"的方向判断；给本地/外地结论（迁移宫有主星或吉星→外出有利）
3. **读四化落宫**
   - 完成标准: 列出科权禄忌四化各落在哪一宫，指出动力来源与障碍来源（细节转 `tianji-sihua`）
4. **叠加十层时间（判停）**
   - 完成标准: 十年大运只取三方四正、小流年只取本宫+对宫；**判停点**：若目标是"当年具体事"，第2-3步完成后可停在流年层，不必展开全部六亲宫
5. **输出结论并交叉验证**
   - 完成标准: 每条结论可回溯到"某宫+某星/某化"；提示可用面相/手相互参（夫妻宫→奸门、兄弟宫→眉毛）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 命盘尚未排出（缺十二宫结构）——本卡不做排盘
- 用户只想要某一宫的单点答案（如"夫妻宫化忌什么意思"）——直接走对应专卡，不必跑全流程
- 用户明确要算命盘以外的问题（阳宅、择日）——不属于本卡

### 作者在书中警告的失败模式

- "每宫都看一遍"导致信息过载——倪师明确简化流程，只重点看三方四正，不逐宫铺开
- 顺序颠倒：跳过总格直接看流年，会把十年趋势误读为一年的吉凶
- 误用飞星：本体系"四化为主，无需计算飞星"，自作飞星会偏离口径

### 作者的盲点 / 时代局限（见 BOOK_OVERVIEW 批判）

- **命例全部为倪师自述批命经验，无第三方验证**——本卡的"结论正确性"无法被独立检验；预测不准时可用"面相不对/阳宅没调好"解释，体系难以证伪
- **时辰假设**：全程假设出生时辰精确到两小时一段，且润月/子时无歧义，现实中很多人时辰不确定
- **男女角色刻板**：案例多带"男为乾刚、女为坤柔"的传统性别假设，现代语境需过滤
- **排盘准确性外挂**：本卡默认输入命盘正确，若上游排盘出错，全盘判读连锁失效

### 容易混淆的邻近方法论

- 与 `tianji-ziwei-paipan` 区分: 排盘=造盘，本卡=读盘
- 与 `tianji-shisi-zhuxing`（十四主星）区分: 星性卡回答"这颗星什么意思"，本卡回答"先看哪几个宫、按什么顺序"
